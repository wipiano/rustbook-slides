Chapter 12 · 12.2 Reading a File

A sample file to search

Now we add functionality to read the file specified in the file_path argument. First we need a sample file to test it with: a small amount of text over multiple lines with some repeated words. Create a file called poem.txt at the root level of your project and enter Emily Dickinson’s poem “I’m Nobody! Who are you?”

Listing 12.3: A poem by Emily Dickinson makes a good test case. — poem.txt

I'm nobody! Who are you?

Are you nobody, too?

Then there's a pair of us - don't tell!

They'd banish us, you know.

 

How dreary to be somebody!

How public, like a frog

To tell your name the livelong day

To an admiring bog!

With the text in place, edit src/main.rs and add code to read the file, as shown in Listing 12.4.
