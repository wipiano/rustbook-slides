Grouping configuration values

We can take another small step to improve parse_config. Two signs show we don’t have the right abstraction yet:

  1. We return a tuple, but then immediately break that tuple into individual parts again.
  2. The config part of parse_config implies that the two values we return are related and are both part of one configuration value. We don’t currently convey this meaning in the structure of the data, other than by grouping the two values into a tuple.

Instead, we put the two values into one struct and give each of the struct fields a meaningful name. Doing so makes it easier for future maintainers of this code to understand how the different values relate to each other and what their purpose is.
