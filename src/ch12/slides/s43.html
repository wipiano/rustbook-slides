Splitting code into a library crate

Our minigrep project is looking good so far! Now we split src/main.rs and put some code into src/lib.rs. That way, we can test the code and have a src/main.rs file with fewer responsibilities.

We define the code responsible for searching text in src/lib.rs rather than src/main.rs, which lets us (or anyone else using our minigrep library) call the searching function from more contexts than our minigrep binary. First, we define the search function signature, with a body that calls the unimplemented! macro; the signature is explained when we fill in the implementation.

Listing 12.13: Defining the search function in src/lib.rs — src/lib.rs

pub fn search<'a>(query: &str, contents: &'a str) -> Vec<&'a str> {

    unimplemented!();

}

The pub keyword designates search as part of our library crate’s public API. We now have a library crate that we can use from our binary crate and that we can test!
