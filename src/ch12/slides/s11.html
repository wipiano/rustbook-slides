Chapter 12 · 12.2 Reading a File

Reading the file with fs::read_to_string

Listing 12.4: Reading the contents of the file specified by the second argument — src/main.rs

use std::env;

use std::fs;

 

fn main() {

    // --snip--

    println!("In file {file_path}");

 

    let contents = fs::read_to_string(file_path)

        .expect("Should have been able to read the file");

 

    println!("With text:\n{contents}");

}

  • First, a use statement brings in a relevant part of the standard library: we need std::fs to handle files.
  • In main, the new statement fs::read_to_string takes the file_path, opens that file, and returns a value of type std::io::Result<String> that contains the file’s contents.
