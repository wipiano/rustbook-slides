Chapter 12 · 12.5 Working with Environment Variables

PowerShell, and the case-insensitive result

In PowerShell, you need to set the environment variable and run the program as separate commands:

PS> $Env:IGNORE_CASE=1; cargo run -- to poem.txt

This makes IGNORE_CASE persist for the remainder of your shell session. It can be unset with the Remove-Item cmdlet:

PS> Remove-Item Env:IGNORE_CASE

We should get lines that contain to that might have uppercase letters:

Are you nobody, too?

How dreary to be somebody!

To tell your name the livelong day

To an admiring bog!
