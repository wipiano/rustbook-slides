Improving the error message

We add a check in new that verifies the slice is long enough before accessing index 1 and index 2. If it isn’t, the program panics and displays a better error message.

Listing 12.8: Adding a check for the number of arguments — src/main.rs

impl Config {

    // --snip--

    fn new(args: &[String]) -> Config {

        if args.len() < 3 {

            panic!("not enough arguments");

        }

        // --snip--

    }

}

Like Guess::new in Listing 9.13, which called panic! for an out-of-range value, we check that args has at least 3 items, so the rest of the function can assume this condition has been met. With fewer than three items the condition is true, and panic! ends the program immediately.
