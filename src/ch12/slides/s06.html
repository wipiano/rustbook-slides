Chapter 12 · 12.1 Accepting Command Line Arguments

Collecting into a vector, and a first run

On the first line of main, we call env::args and immediately use collect to turn the iterator into a vector containing all the values it produces. Because collect can create many kinds of collections, we explicitly annotate the type of args to specify that we want a vector of strings.

Remark. Although you very rarely need to annotate types in Rust, collect is one function you do often need to annotate, because Rust isn’t able to infer the kind of collection you want.

Finally, we print the vector using the debug macro dbg!. Running the code first with no arguments:
