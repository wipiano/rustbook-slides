Chapter 12 · 12.1 Accepting Command Line Arguments

Reading the argument values with std::env::args

To read the values of the command line arguments we pass to minigrep, we need the standard library function std::env::args. It returns an iterator of the command line arguments passed to minigrep. Iterators are covered fully in Chapter 13; for now you only need two details:

Definition 12.2 (Iterator). A value that produces a series of values. Calling the collect method on an iterator turns it into a collection, such as a vector, which contains all the elements the iterator produces.

Listing 12.1 reads any command line arguments passed to minigrep and collects the values into a vector.

Listing 12.1: Collecting the command line arguments into a vector and printing them — src/main.rs

use std::env;

 

fn main() {

    let args: Vec<String> = env::args().collect();

    dbg!(args);

}
