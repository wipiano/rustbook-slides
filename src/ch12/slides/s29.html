A better message — but still a panic

With these extra few lines in new, running the program without any arguments again gives:

$ cargo run

   Compiling minigrep v0.1.0 (file:///projects/minigrep)

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.0s

     Running `target/debug/minigrep`

 

thread 'main' (6023776) panicked at src/main.rs:26:13:

not enough arguments

note: run with `RUST_BACKTRACE=1` environment variable to display a backtrace

This output is better: we now have a reasonable error message. However, we also have extraneous information we don’t want to give to our users.

Remark. Perhaps the technique of Listing 9.13 isn’t the best one here: as discussed in Chapter 9, a call to panic! is more appropriate for a programming problem than a usage problem. Instead we use the other technique from Chapter 9 — returning a Result that indicates either success or an error.
