Chapter 12 · 12.3 Refactoring to Improve Modularity and Error Handling

What Listing 12.14 changes

  • A use minigrep::search line brings the search function from the library crate into the binary crate’s scope.
  • In run, rather than printing out the contents of the file, we call search, passing config.query and contents as arguments, and use a for loop to print each line returned from search that matched the query.
  • This is also a good time to remove the println! calls in main that displayed the query and the file path, so that the program only prints the search results (if no errors occur).

Remark. The search function collects all the results into a vector it returns before any printing happens. This could be slow to display results when searching large files, because results aren’t printed as they’re found; Chapter 13 discusses a possible fix using iterators.

Whew! That was a lot of work, but it’s now much easier to handle errors and the code is more modular; almost all our work will be done in src/lib.rs from here on. Next we use this modularity for something difficult with the old code but easy with the new: we’ll write some tests!
