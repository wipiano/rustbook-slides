Calling Config::build and handling errors

Returning an Err lets main handle the Result and exit cleanly. To print a user-friendly message we update main, and implement the nonzero exit code by hand instead of relying on panic!.

Listing 12.10: Exiting with an error code if building a Config fails — src/main.rs

use std::process;

 

fn main() {

    let args: Vec<String> = env::args().collect();

 

    let config = Config::build(&args).unwrap_or_else(|err| {

        println!("Problem parsing arguments: {err}");

        process::exit(1);

    });

 

    // --snip--

}
