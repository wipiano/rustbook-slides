process::exit and a friendlier error

A new use line brings process from the standard library into scope. The closure run in the error case is only two lines: we print the err value and then call process::exit, which stops the program immediately and returns the number that was passed as the exit status code.

Definition 12.4 (Nonzero exit status). A convention by which a program signals to the process that called it that the program exited with an error state.

This is similar to the panic!-based handling of Listing 12.8, but we no longer get all the extra output. Great! This output is much friendlier for our users:
