Chapter 12 · 12.1 Accepting Command Line Arguments

Saving the argument values in variables

Next we save the two argument values in variables so that we can use them throughout the rest of the program.

Listing 12.2: Creating variables to hold the query argument and file path argument — src/main.rs

use std::env;

 

fn main() {

    let args: Vec<String> = env::args().collect();

 

    let query = &args[1];

    let file_path = &args[2];

 

    println!("Searching for {query}");

    println!("In file {file_path}");

}

The program’s name takes up args[0], so we start at index 1: a reference to the first argument (the string to search for) goes in query, and one to the second (the file path) in file_path.
