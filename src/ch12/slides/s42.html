Handling errors returned from run in main

We check for errors with a technique similar to the one used with Config::build in Listing 12.10, with a slight difference:

fn main() {

    // --snip--

 

    println!("Searching for {}", config.query);

    println!("In file {}", config.file_path);

 

    if let Err(e) = run(config) {

        println!("Application error: {e}");

        process::exit(1);

    }

}

  • We use if let rather than unwrap_or_else: run returns () on success, so we only care about detecting an error — there is no value to unwrap.
  • The bodies are the same in both cases: we print the error and exit.
