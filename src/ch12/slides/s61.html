Chapter 12 · 12.5 Working with Environment Variables

Case-insensitive search via an environment variable

We improve the minigrep binary with an extra feature: an option for case-insensitive searching that the user can turn on via an environment variable.

Definition 12.7 (Environment variable). A named value set in the user’s environment (for example, a terminal session) that a program can read to configure its behavior.

We could make this feature a command line option and require users to enter it each time they want it to apply. By making it an environment variable instead, users set it once and have all their searches be case insensitive in that terminal session.

Writing a failing test for case-insensitive search

We add a new search_case_insensitive function to the library, called when the environment variable has a value. Following TDD, the first step is again a failing test: a new test for the new function, and our old test renamed from one_result to case_sensitive to clarify the differences between the two tests.
