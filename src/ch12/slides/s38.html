Chapter 12 · 12.3 Refactoring to Improve Modularity and Error Handling

Change 1: the return type Result<(), Box<dyn Error>>

Listing 12.12 makes three significant changes. First, we changed the return type of run to Result<(), Box<dyn Error>>. The function previously returned the unit type, (), and we keep that as the value returned in the Ok case.

For the error type we used the trait object Box<dyn Error>, and brought std::error::Error into scope with a use statement at the top.

Definition 12.5 (Trait object Box<dyn Error>). A return type meaning that the function returns some type that implements the Error trait, without our having to specify which particular type the return value will be. The dyn keyword is short for dynamic. Trait objects are covered in Chapter 18.

This gives us flexibility to return error values that may be of different types in different error cases.
