A mini version of a classic tool

Excellent! We’ve built our own mini version of a classic tool and learned a lot about how to structure applications. We’ve also learned a bit about file input and output, lifetimes, testing, and command line parsing.

Table 12.1: How the minigrep code is organized at this point

FileHolds
src/main.rsmain: collect args, Config::build (exit 1 on error), call run, print “Application error” and exit 1
src/main.rsConfig { query, file_path } and run: read the file with ?, print each line search returns
src/lib.rspub fn search, plus the tests module with the one_result test

To round out this project, we briefly demonstrate how to work with environment variables and how to print to standard error, both of which are useful when you’re writing command line programs.
