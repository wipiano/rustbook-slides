Iterating through lines with the lines method

Rust has a helpful method to handle line-by-line iteration of strings, conveniently named lines. Note that this won’t compile yet.

Listing 12.17: Iterating through each line in contents — src/lib.rs

pub fn search<'a>(query: &str, contents: &'a str) -> Vec<&'a str> {

    for line in contents.lines() {

        // do something with line

    }

}

The lines method returns an iterator. Iterators are covered in depth in Chapter 13, but recall that you saw this way of using an iterator in Listing 3.5, where a for loop with an iterator ran some code on each item in a collection.
