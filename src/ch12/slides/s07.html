Chapter 12 · 12.1 Accepting Command Line Arguments

Running with arguments: the program name comes first

Now with two arguments:

$ cargo run -- needle haystack

   Compiling minigrep v0.1.0 (file:///projects/minigrep)

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 1.57s

     Running `target/debug/minigrep needle haystack`

[src/main.rs:5:5] args = [

    "target/debug/minigrep",

    "needle",

    "haystack",

]

The first value in the vector is "target/debug/minigrep", the name of our binary. This matches the behavior of the arguments list in C, letting programs use the name by which they were invoked in their execution. Having the program name is often convenient — to print it in messages, or to change the program’s behavior based on what command line alias was used to invoke it. For this chapter we ignore it and save only the two arguments we need.
