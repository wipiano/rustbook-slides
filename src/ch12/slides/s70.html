Chapter 12 · 12.5 Working with Environment Variables

Checking the environment variable with env::var

Finally, we need to check for the environment variable. The functions for working with environment variables are in the env module of the standard library, which is already in scope at the top of src/main.rs. We use the var function from env to check whether any value has been set for an environment variable named IGNORE_CASE (Listing 12.23, next slide).

let ignore_case = env::var("IGNORE_CASE").is_ok();

Here, we create a new variable, ignore_case. To set its value, we call env::var and pass it the name of the IGNORE_CASE environment variable. env::var returns a Result:

  • the successful Ok variant, containing the value of the environment variable, if the variable is set to any value;
  • the Err variant if the environment variable is not set.
