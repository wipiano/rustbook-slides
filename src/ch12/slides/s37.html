Returning errors from run

With the remaining logic separated into run, we can improve its error handling as we did with Config::build in Listing 12.9. Instead of letting the program panic by calling expect, run will return a Result<T, E> when something goes wrong. This lets us further consolidate the error-handling logic into main in a user-friendly way.

Listing 12.12: Changing the run function to return Result — src/main.rs

use std::error::Error;

 

// --snip--

 

fn run(config: Config) -> Result<(), Box<dyn Error>> {

    let contents = fs::read_to_string(config.file_path)?;

 

    println!("With text:\n{contents}");

 

    Ok(())

}
