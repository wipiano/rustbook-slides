Fixing the error handling: index out of bounds

Now we work on fixing our error handling. Recall that accessing the values in the args vector at index 1 or index 2 will cause the program to panic if the vector contains fewer than three items. Running the program without any arguments looks like this:

$ cargo run

   Compiling minigrep v0.1.0 (file:///projects/minigrep)

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.0s

     Running `target/debug/minigrep`

 

thread 'main' (6023615) panicked at src/main.rs:27:21:

index out of bounds: the len is 1 but the index is 1

note: run with `RUST_BACKTRACE=1` environment variable to display a backtrace

The line index out of bounds: the len is 1 but the index is 1 is an error message intended for programmers. It won’t help our end users understand what they should do instead. Let’s fix that now.
