Chapter 12 · 12.5 Working with Environment Variables

Running without and with IGNORE_CASE

First, without the environment variable set and with the query to, which should match any line containing the word to in all lowercase:

$ cargo run -- to poem.txt

   Compiling minigrep v0.1.0 (file:///projects/minigrep)

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.0s

     Running `target/debug/minigrep to poem.txt`

Are you nobody, too?

How dreary to be somebody!

Looks like that still works! Now run the program with IGNORE_CASE set to 1 but with the same query to:

$ IGNORE_CASE=1 cargo run -- to poem.txt
