Storing matching lines

To finish, we store the matching lines: make a mutable vector before the for loop, call push to store each matching line in it, and return the vector after the loop.

Listing 12.19: Storing the lines that match so that we can return them — src/lib.rs

pub fn search<'a>(query: &str, contents: &'a str) -> Vec<&'a str> {

    let mut results = Vec::new();

 

    for line in contents.lines() {

        if line.contains(query) {

            results.push(line);

        }

    }

 

    results

}

Now search should return only the lines that contain query, and our test should pass.
