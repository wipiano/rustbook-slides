Chapter 12 · 12.5 Working with Environment Variables

Why is_ok, and where the flag goes

We use the is_ok method on the Result to check whether the environment variable is set, which means the program should do a case-insensitive search. If IGNORE_CASE isn’t set to anything, is_ok returns false and the program performs a case-sensitive search.

Remark. We don’t care about the value of the environment variable, just whether it’s set or unset — so we check is_ok rather than using unwrap, expect, or any of the other methods we’ve seen on Result.

We pass the value in the ignore_case variable to the Config instance, so that the run function can read that value and decide whether to call search_case_insensitive or search, as implemented in Listing 12.22.
