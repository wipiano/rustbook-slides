What the test checks, and just enough code

  • The test searches for the string "duct". The text searched is three lines, only one of which contains "duct"; we assert that search returns only the line we expect.
  • The backslash after the opening double quote tells Rust not to put a newline character at the beginning of the contents of this string literal.

Run now, the test fails because unimplemented! panics with the message “not implemented”. Following TDD, we take a small step: just enough code that calling the function won’t panic, by always returning an empty vector. The test should then compile and fail, because an empty vector doesn’t match a vector containing the line "safe, fast, productive.".
