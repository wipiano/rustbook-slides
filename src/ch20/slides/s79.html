Chapter 20 · 20.4 Advanced Functions and Closures

Returning closures

Closures are represented by traits, so you can’t return closures directly. Where you might want to return a trait, you can usually return the concrete type that implements it — but closures don’t have a concrete type that is returnable. For example, you’re not allowed to use the function pointer fn as a return type if the closure captures any values from its scope.

Instead, you will normally use the impl Trait syntax from Chapter 10. You can return any function type, using Fn, FnOnce, and FnMut. Listing 20.32 compiles just fine.

Listing 20.32: Returning a closure from a function using the impl Trait syntax

fn returns_closure() -> impl Fn(i32) -> i32 {

    |x| x + 1

}
