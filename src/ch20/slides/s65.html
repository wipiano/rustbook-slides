The never type that never returns

Definition 20.19 (Never type). The special type !, known in type theory lingo as the empty type because it has no values. Rust prefers the name never type because it stands in the place of the return type when a function will never return.

fn bar() -> ! {

    // --snip--

    panic!();

}

This is read as “the function bar returns never.” We can’t create values of the type !, so bar can never possibly return.

Definition 20.20 (Diverging function). A function that returns never.
