Chapter 20 · 20.5 Macros

Why a manual implementation isn’t enough

Listing 20.39: How it would look if users wrote a manual implementation of the HelloMacro trait — src/main.rs

use hello_macro::HelloMacro;

 

struct Pancakes;

 

impl HelloMacro for Pancakes {

    fn hello_macro() {

        println!("Hello, Macro! My name is Pancakes!");

    }

}

 

fn main() {

    Pancakes::hello_macro();

}

  • Users would need this implementation block for every type used with hello_macro; we want to spare them.
  • No default implementation can print the type’s name: Rust has no reflection, so it can’t look up the name at runtime. We need a macro to generate code at compile time.
