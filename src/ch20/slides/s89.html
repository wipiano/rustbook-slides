Chapter 20 · 20.5 Macros

Reading the macro pattern

Macro pattern syntax differs from the pattern syntax of Chapter 19, because macro patterns are matched against Rust code structure rather than values. The pieces of the pattern ( $( $x:expr ),* ) in Listing 20.35 (full syntax: the Rust Reference):

  • A set of parentheses encompasses the whole pattern.
  • A dollar sign ($) declares a variable in the macro system that will contain the Rust code matching the pattern; it makes clear this is a macro variable, not a regular Rust variable.
  • Next, a set of parentheses captures values that match the pattern within them, for use in the replacement code. Within $() is $x:expr, which matches any Rust expression and gives it the name $x.
  • The comma following $() means a literal comma separator must appear between each instance of the code matching $(). The * means the pattern matches zero or more of whatever precedes it.

Calling vec![1, 2, 3];, the $x pattern matches three times with the three expressions 1, 2, and 3.
