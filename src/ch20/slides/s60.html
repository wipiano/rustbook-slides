Chapter 20 · 20.3 Advanced Types

Type synonyms and type aliases

Definition 20.18 (Type alias). Another name for an existing type, declared with the type keyword. The alias is a synonym, not a separate, new type.

The alias Kilometers to i32:

type Kilometers = i32;

 

let x: i32 = 5;

let y: Kilometers = 5;

 

println!("x + y = {}", x + y);

Unlike the Millimeters and Meters types of Listing 20.16, Kilometers is not a separate, new type: values of type Kilometers are treated the same as values of type i32.

Because Kilometers and i32 are the same type, we can add values of both types and pass Kilometers values to functions that take i32 parameters. But we don’t get the type-checking benefits of the newtype pattern: if we mix up Kilometers and i32 values somewhere, the compiler will not give us an error.
