Chapter 20 · 20.2 Advanced Traits

Using fully qualified syntax

To pick Animal for Dog over Animal for other types, use fully qualified syntax:

Listing 20.22: Using fully qualified syntax to specify that we want to call the baby_name function from the Animal trait as implemented on Dog — src/main.rs

fn main() {

    println!("A baby dog is called a {}", <Dog as Animal>::baby_name());

}

The type annotation in angle brackets treats the Dog type as an Animal for this call, so Animal’s baby_name as implemented on Dog runs. It now prints what we want:
