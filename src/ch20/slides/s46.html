Chapter 20 · 20.2 Advanced Traits

The trait name alone isn’t enough

With Animal, Dog and both impls as in Listing 20.20, main becomes:

Listing 20.21: Attempting to call the baby_name function from the Animal trait, but Rust doesn’t know which implementation to use — src/main.rs

fn main() {

    println!("A baby dog is called a {}", Animal::baby_name());

}

Because Animal::baby_name doesn’t have a self parameter, and there could be other types that implement the Animal trait, Rust can’t figure out which implementation of Animal::baby_name we want. We get compiler error E0790 (next slide): “cannot call associated function on trait without specifying the corresponding impl type.”

Remark. The compiler’s help already points at the fix: use the fully qualified path to the only available implementation, <Dog as Animal>::baby_name().
