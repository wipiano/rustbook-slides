Because fly takes a self parameter, if we had two types that both implement one trait, Rust could figure out which implementation to use based on the type of self.

But associated functions that are not methods have no self. When several types or traits define non-method functions with the same name, Rust doesn’t always know which type you mean unless you use fully qualified syntax. In Listing 20.20, an animal shelter names all baby dogs Spot: trait Animal has an associated non-method function baby_name, implemented for struct Dog, which also has its own baby_name.
