Recall from Chapter 4 (“The Slice Type”) that a slice is a pointer to some data and the length of the slice.

len gets the length of a slice; as_mut_ptr accesses its raw pointer. For a mutable slice of i32 values, as_mut_ptr returns a *mut i32, stored in ptr.

We keep the assertion that mid is within the slice. Then the unsafe code: slice::from_raw_parts_mut takes a raw pointer and a length and creates a slice. We use it to create a slice that starts from ptr and is mid items long. Then we call add on ptr with mid as an argument to get a raw pointer that starts at mid, and create a slice from that pointer with the remaining number of items after mid as the length.
