Chapter 20 · 20.2 Advanced Traits

Implementing external traits with the newtype pattern

Chapter 10 (“Implementing a Trait on a Type”) introduced the orphan rule: we may implement a trait on a type only if the trait or the type, or both, are local to our crate. The newtype pattern gets around this restriction.

Definition 20.17 (Newtype pattern). Creating a new type in a tuple struct (Chapter 5) with one field: a thin wrapper around the type for which we want to implement a trait. The wrapper type is local to our crate, so we can implement the trait on it. Newtype is a term that originates from the Haskell programming language.

  • There is no runtime performance penalty for using this pattern: the wrapper type is elided at compile time.
  • Example: we want to implement Display on Vec<T>, which the orphan rule prevents directly because Display and Vec<T> are both defined outside our crate.
  • Instead we make a Wrapper struct that holds an instance of Vec<T>, then implement Display on Wrapper and use the Vec<T> value (Listing 20.24, next slide).
