Default generic parameters and operator overloading

When we use generic type parameters, we can specify a default concrete type for the generic type. This eliminates the need for implementors of the trait to specify a concrete type if the default type works. You specify a default type when declaring a generic type with the <PlaceholderType=ConcreteType> syntax.

A great example of where this technique is useful is operator overloading.

Definition 20.13 (Operator overloading). Customizing the behavior of an operator (such as +) in particular situations.

Rust doesn’t allow you to create your own operators or overload arbitrary operators. But you can overload the operations and corresponding traits listed in std::ops by implementing the traits associated with the operator. Listing 20.15 (next slide) overloads the + operator to add two Point instances together, by implementing the Add trait on a Point struct.
