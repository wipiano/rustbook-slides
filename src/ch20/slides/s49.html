Chapter 20 · 20.2 Advanced Traits

Fully qualified syntax in general

Definition 20.15 (Fully qualified syntax). A call that names both the type and the trait whose implementation is meant, in the form below.

<Type as Trait>::function(receiver_if_method, next_arg, ...);

  • For associated functions that aren’t methods, there is no receiver: only the list of other arguments.
  • You could use fully qualified syntax everywhere you call functions or methods. However, you may omit any part of it that Rust can figure out from other information in the program.
  • You only need this more verbose syntax where there are multiple implementations that use the same name and Rust needs help to identify which implementation you want to call.
