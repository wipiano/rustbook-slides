Chapter 20 · 20.5 Macros

Macros: a family of features

We’ve used macros like println! throughout this book, but haven’t fully explored what a macro is and how it works. The term macro refers to a family of features in Rust: declarative macros with macro_rules! and three kinds of procedural macros.

Table 20.2: The kinds of macros in Rust

KindWhat it does
Declarative (macro_rules!)Matches the code passed in against patterns and replaces it with code
Custom #[derive] (procedural)Specifies code added with the derive attribute used on structs and enums
Attribute-like (procedural)Defines custom attributes usable on any item
Function-like (procedural)Looks like a function call but operates on the tokens specified as its argument

We’ll talk about each of these in turn, but first: why do we even need macros when we already have functions?
