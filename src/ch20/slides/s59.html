Chapter 20 · 20.3 Advanced Types

Type safety and abstraction with newtypes

The Rust type system has some features mentioned but not yet discussed. This section starts with newtypes in general, as types; then type aliases, a feature similar to newtypes but with slightly different semantics; then the ! type and dynamically sized types.

Building on “Implementing External Traits with the Newtype Pattern”, newtypes are useful for more tasks:

  • Statically enforcing that values are never confused, and indicating units. In Listing 20.16, Millimeters and Meters wrapped u32 values. A function with a Millimeters parameter won’t compile if called by accident with a Meters or a plain u32.
  • Abstracting away implementation details. The new type can expose a public API that is different from the API of the private inner type.
  • Hiding internal implementation. A People type could wrap a HashMap<i32, String> storing a person’s ID with their name. Code using People only uses our public API, such as a method to add a name string; it needn’t know we assign an i32 ID to names internally. A lightweight way to achieve encapsulation (Chapter 18).
