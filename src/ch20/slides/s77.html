Named functions and enum initializers in place of closures

Or we could name a function as the argument to map instead of the closure:

Listing 20.30: Using the String::to_string function with the map method to convert numbers to strings

let list_of_numbers = vec![1, 2, 3];

let list_of_strings: Vec<String> =

    list_of_numbers.iter().map(ToString::to_string).collect();

We must use the fully qualified syntax from “Advanced Traits”, because there are multiple functions available named to_string. Here we use the to_string defined in the ToString trait, which the standard library implements for any type that implements Display.

Recall from Chapter 6 (“Enum Values”) that the name of each enum variant also becomes an initializer function. These initializer functions are function pointers that implement the closure traits, so we can pass them to methods that take closures (Listing 20.31, next slide).
