Chapter 20 · 20.3 Advanced Types

Traits as DSTs, and the Sized trait

We can combine str with all kinds of pointers: for example, Box<str> or Rc<str>. You’ve seen this before with a different DST: traits. Every trait is a DST we can refer to by using the name of the trait. Chapter 18 (“Using Trait Objects to Abstract over Shared Behavior”) put trait objects behind a pointer, such as &dyn Trait or Box<dyn Trait> (Rc<dyn Trait> would work too).

Definition 20.23 (Sized trait). The trait Rust provides to determine whether or not a type’s size is known at compile time. It is automatically implemented for everything whose size is known at compile time.

In addition, Rust implicitly adds a bound on Sized to every generic function. A generic function definition like the one on the left is actually treated as though we had written the one on the right:

fn generic<T>(t: T) {

    // --snip--

}

fn generic<T: Sized>(t: T) {

    // --snip--

}
