Chapter 20 · 20.5 Macros

quote! and stringify!

  • The quote! macro lets us define the Rust code that we want to return. The compiler expects something different from the direct result of quote!, so we convert it to a TokenStream by calling into, which consumes this intermediate representation and returns a value of the required TokenStream type.
  • quote! also provides templating: we can enter #name, and quote! replaces it with the value in the variable name. It can even do repetition similar to regular macros (see the quote crate’s docs).
  • The macro generates an implementation of HelloMacro for the annotated type, #name. Its one function, hello_macro, prints Hello, Macro! My name is and then the name of the annotated type.
  • stringify! is built into Rust: it takes a Rust expression, such as 1 + 2, and at compile time turns it into a string literal, such as "1 + 2". Unlike format! or println!, it doesn’t evaluate the expression first. The #name input might be an expression to print literally, so we use stringify!; it also saves an allocation by converting #name to a string literal at compile time.
