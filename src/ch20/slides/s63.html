Aliases for Result<T, E>: the problem

Type aliases are also common with Result<T, E>. In std::io, I/O operations often return a Result<T, E> to handle failures; the std::io::Error struct represents all possible I/O errors, and many std::io functions return Result<T, E> with E = std::io::Error, such as these in the Write trait:

use std::fmt;

use std::io::Error;

 

pub trait Write {

    fn write(&mut self, buf: &[u8]) -> Result<usize, Error>;

    fn flush(&mut self) -> Result<(), Error>;

 

    fn write_all(&mut self, buf: &[u8]) -> Result<(), Error>;

    fn write_fmt(&mut self, fmt: fmt::Arguments) -> Result<(), Error>;

}

The Result<..., Error> is repeated a lot.
