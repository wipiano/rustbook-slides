Chapter 20 · 20.5 Macros

Procedural macros for generating code from attributes

Definition 20.28 (Procedural macro). The second form of macros, which acts more like a function (and is a type of procedure): it accepts some code as an input, operates on that code, and produces some code as an output — rather than matching against patterns and replacing the code with other code as declarative macros do. Its three kinds — custom derive, attribute-like, and function-like — all work in a similar fashion.

When creating procedural macros, the definitions must reside in their own crate with a special crate type. This is for complex technical reasons that the Rust team hopes to eliminate in the future. Listing 20.36 shows how to define a procedural macro, where some_attribute is a placeholder for using a specific macro variety.

Listing 20.36: An example of defining a procedural macro — src/lib.rs

use proc_macro::TokenStream;

 

#[some_attribute]

pub fn some_name(input: TokenStream) -> TokenStream {

}
