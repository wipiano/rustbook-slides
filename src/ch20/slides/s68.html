Chapter 20 · 20.3 Advanced Types

panic! has the type !

The definition of unwrap on Option<T>:

impl<T> Option<T> {

    pub fn unwrap(self) -> T {

        match self {

            Some(val) => val,

            None => panic!("called `Option::unwrap()` on a `None` value"),

        }

    }

}

The same thing happens as in the match in Listing 20.27: Rust sees that val has the type T and panic! has the type !, so the result of the overall match expression is T.

This code works because panic! doesn’t produce a value; it ends the program. In the None case, we won’t be returning a value from unwrap, so this code is valid.
