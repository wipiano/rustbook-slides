Chapter 20 · 20.5 Macros

Defining a macro with macro_rules!: vec!

To define a macro, you use the macro_rules! construct. Let’s look at how vec! is defined. Chapter 8 used it to create a new vector with particular values, for example three integers:

let v: Vec<u32> = vec![1, 2, 3];

We could also use vec! to make a vector of two integers or a vector of five string slices. A function couldn’t do the same, because we wouldn’t know the number or type of values up front. Listing 20.35 is a slightly simplified definition of vec!.

Listing 20.35: A simplified version of the vec! macro definition — src/lib.rs

#[macro_export]

macro_rules! vec {

    ( $( $x:expr ),* ) => {

        {

            let mut temp_vec = Vec::new();

            $(

                temp_vec.push($x);

            )*

            temp_vec

        }

    };

}
