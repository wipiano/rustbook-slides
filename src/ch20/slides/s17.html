Chapter 20 · 20.1 Unsafe Rust

Using extern functions to call external code

Sometimes Rust code needs to interact with code written in another language. For this, Rust has the keyword extern.

Definition 20.5 (Foreign Function Interface, FFI). A way for a programming language to define functions and enable a different (foreign) programming language to call those functions.

Listing 20.8 sets up an integration with the abs function from the C standard library.

Listing 20.8: Declaring and calling an extern function defined in another language — src/main.rs

unsafe extern "C" {

    fn abs(input: i32) -> i32;

}

 

fn main() {

    unsafe {

        println!("Absolute value of -3 according to C: {}", abs(-3));

    }

}
