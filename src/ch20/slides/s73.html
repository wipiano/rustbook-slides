Chapter 20 · 20.3 Advanced Types

Relaxing the bound with ?Sized

By default, generic functions work only on types that have a known size at compile time. This special syntax relaxes the restriction:

fn generic<T: ?Sized>(t: &T) {

    // --snip--

}

  • A trait bound on ?Sized means “T may or may not be Sized,” and this notation overrides the default that generic types must have a known size at compile time.
  • The ?Trait syntax with this meaning is only available for Sized, not any other traits.
  • The type of the t parameter switched from T to &T: because the type might not be Sized, we need to use it behind some kind of pointer. Here we’ve chosen a reference.
