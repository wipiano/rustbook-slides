Chapter 20 · 20.4 Advanced Functions and Closures

Function pointers

This section explores some advanced features related to functions and closures: function pointers and returning closures.

We’ve passed closures to functions; you can also pass regular functions to functions! This is useful when you want to pass a function you’ve already defined rather than defining a new closure.

Definition 20.24 (Function pointer). The type fn (with a lowercase f) that functions coerce to — not to be confused with the Fn closure trait. Passing functions with function pointers lets you use functions as arguments to other functions.

The syntax for a parameter that is a function pointer is similar to that of closures. In Listing 20.28, add_one adds 1 to its parameter. do_twice takes two parameters: a function pointer to any function that takes an i32 parameter and returns an i32, and one i32 value. It calls f twice, passing it arg, then adds the two results together. main calls do_twice with the arguments add_one and 5.
