Putting DSTs behind a pointer

So what do we do? You already know the answer: make the type of s1 and s2 a string slice (&str) rather than str.

  • Recall from Chapter 4 (“String Slices”) that the slice data structure only stores the starting position and the length of the slice.
  • Although &T is a single value that stores the memory address of where the T is located, a string slice is two values: the address of the str and its length.
  • So we can know the size of a string slice value at compile time: it’s twice the length of a usize. We always know the size of a string slice, no matter how long the string it refers to is.
  • In general, this is how dynamically sized types are used in Rust: they have an extra bit of metadata that stores the size of the dynamic information.

Remark. The golden rule of dynamically sized types: we must always put values of dynamically sized types behind a pointer of some kind.
