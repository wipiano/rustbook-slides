Chapter 20 · 20.5 Macros

Function-like macros

Function-like macros define macros that look like function calls. Like macro_rules! macros, they’re more flexible than functions; for example, they can take an unknown number of arguments. But macro_rules! macros can only be defined using the match-like syntax of “Declarative Macros for General Metaprogramming”. Function-like macros take a TokenStream parameter, and their definition manipulates that TokenStream using Rust code, as the other two types of procedural macros do. Example: an sql! macro that might be called like so:

let sql = sql!(SELECT * FROM posts WHERE id=1);

This macro would parse the SQL statement inside it and check that it’s syntactically correct — much more complex processing than a macro_rules! macro can do. It would be defined like this:

#[proc_macro]

pub fn sql(input: TokenStream) -> TokenStream {

This is similar to the custom derive macro’s signature: we receive the tokens inside the parentheses and return the code we wanted to generate.
