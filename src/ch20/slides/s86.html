Chapter 20 · 20.5 Macros

Downsides of macros; declarative macros

  • Macro definitions are more complex than function definitions, because you’re writing Rust code that writes Rust code. Due to this indirection, they are generally more difficult to read, understand, and maintain.
  • You must define macros or bring them into scope before you call them in a file, as opposed to functions, which you can define anywhere and call anywhere.

Declarative macros for general metaprogramming

Definition 20.27 (Declarative macro). The most widely used form of macros in Rust, also called “macros by example,” “macro_rules! macros,” or just plain “macros.” At its core, it lets you write something similar to a Rust match expression.

A match expression (Chapter 6) takes an expression, compares the resultant value to patterns, and runs the code associated with the matching pattern. Macros also compare a value to patterns associated with code: here the value is the literal Rust source code passed to the macro; the patterns are compared with the structure of that source code; and the code associated with each pattern, when matched, replaces the code passed to the macro. This all happens during compilation.
