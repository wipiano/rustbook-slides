Chapter 20 · 20.3 Advanced Types

str is a dynamically sized type

Consider str, used throughout the book. That’s right: not &str, but str on its own, is a DST. In many cases, such as when storing text entered by a user, we can’t know how long the string is until runtime. So we can’t create a variable of type str, nor take an argument of type str. This code does not work:

fn main() {

    let s1: str = "Hello there!";

    let s2: str = "How's it going?";

}

Rust needs to know how much memory to allocate for any value of a particular type, and all values of a type must use the same amount of memory. If Rust allowed this code, these two str values would need to take up the same amount of space. But they have different lengths: s1 needs 12 bytes of storage and s2 needs 15. This is why it’s not possible to create a variable holding a dynamically sized type.
