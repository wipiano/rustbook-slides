Chapter summary

Whew! Now you have some Rust features in your toolbox that you likely won’t use often, but you’ll know they’re available in very particular circumstances. These complex topics were introduced so that when you encounter them in error message suggestions or in other people’s code, you’ll recognize the concepts and syntax. Use this chapter as a reference to guide you to solutions:

  • unsafe unlocks five superpowers (raw pointers, unsafe functions, mutable statics, unsafe traits, union fields); keep it small, wrap it in safe abstractions, and check it with Miri.
  • Advanced traits: associated types, default type parameters, fully qualified syntax, supertraits, and newtypes for external traits.
  • Advanced types: newtypes, type aliases, the never type !, and dynamically sized types with Sized/?Sized.
  • Function pointers (fn) and returning closures with impl Trait or Box<dyn Fn>.
  • Macros: declarative macro_rules! and procedural custom derive, attribute-like and function-like macros.

Remark. Next, Chapter 21 puts everything discussed throughout the book into practice with one more project.
