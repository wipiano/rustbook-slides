Chapter 20 · 20.1 Unsafe Rust

Creating raw pointers in safe code

Listing 20.1 creates an immutable and a mutable raw pointer.

Listing 20.1: Creating raw pointers with the raw borrow operators

fn main() {

    let mut num = 5;

 

    let r1 = &raw const num;

    let r2 = &raw mut num;

}

  • There is no unsafe keyword here. We can create raw pointers in safe code; we just can’t dereference raw pointers outside an unsafe block, as you’ll see in a bit.
  • The raw borrow operators: &raw const num creates a *const i32 immutable raw pointer, and &raw mut num creates a *mut i32 mutable raw pointer.
  • Because we created them directly from a local variable, we know these particular raw pointers are valid — but we can’t make that assumption about just any raw pointer.
