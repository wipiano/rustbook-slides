Implementing OutlinePrint on a type without Display

What happens when we implement OutlinePrint on a type that doesn’t implement Display, such as the Point struct? Keeping use std::fmt; and the OutlinePrint trait of Listing 20.23, we add:

src/main.rs

struct Point {

    x: i32,

    y: i32,

}

 

impl OutlinePrint for Point {}

 

fn main() {

    let p = Point { x: 1, y: 3 };

    p.outline_print();

}

We get an error saying that Display is required but not implemented (next two slides).
