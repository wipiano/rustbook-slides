The Thunk alias

A type alias makes this code more manageable by reducing the repetition. Listing 20.26 introduces an alias named Thunk for the verbose type and replaces all uses of the type with it.

Listing 20.26: Introducing a type alias, Thunk, to reduce repetition

type Thunk = Box<dyn Fn() + Send + 'static>;

 

let f: Thunk = Box::new(|| println!("hi"));

 

fn takes_long_type(f: Thunk) {

    // --snip--

}

 

fn returns_long_type() -> Thunk {

    // --snip--

}

This code is much easier to read and write! A meaningful alias name also communicates intent: thunk is a word for code to be evaluated at a later time, so it’s an appropriate name for a closure that gets stored.
