Chapter 20 · 20.1 Unsafe Rust

Calling Rust functions from other languages

extern can also create an interface that lets other languages call Rust functions. Instead of a whole extern block, add the extern keyword and the ABI just before the fn keyword of the function, plus an #[unsafe(no_mangle)] annotation telling the compiler not to mangle its name.

Definition 20.7 (Mangling). A compiler changing the name we’ve given a function to a different name that contains more information for other parts of the compilation process to consume but is less human readable.

Every compiler mangles names slightly differently, so for a Rust function to be nameable by other languages, we must disable Rust’s name mangling. This is unsafe because there might be name collisions across libraries without the built-in mangling: it is our responsibility to make sure the name we choose is safe to export without mangling.

Here call_from_c becomes accessible from C code, after it’s compiled to a shared library and linked from C. This usage of extern requires unsafe only in the attribute, not on the extern block.

#[unsafe(no_mangle)]

pub extern "C" fn call_from_c() {

    println!("Just called a Rust function from C!");

}
