Chapter 20 · 20.4 Advanced Functions and Closures

Function pointers and the closure traits

Function pointers implement all three of the closure traits (Fn, FnMut, and FnOnce), so you can always pass a function pointer as an argument for a function that expects a closure. It’s best to write functions using a generic type and one of the closure traits, so your functions can accept either functions or closures.

That said, one case where you’d want to accept only fn and not closures is interfacing with external code that doesn’t have closures: C functions can accept functions as arguments, but C doesn’t have closures.

Where you could use either a closure defined inline or a named function: the map method of the Iterator trait. To turn a vector of numbers into a vector of strings, we could use a closure, as in Listing 20.29.

Listing 20.29: Using a closure with the map method to convert numbers to strings

let list_of_numbers = vec![1, 2, 3];

let list_of_strings: Vec<String> =

    list_of_numbers.iter().map(|i| i.to_string()).collect();
