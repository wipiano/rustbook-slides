Example: Iterator and its associated type Item

The standard library’s Iterator trait has an associated type named Item, which stands in for the type of the values the implementing type is iterating over.

Listing 20.13: The definition of the Iterator trait that has an associated type Item

pub trait Iterator {

    type Item;

 

    fn next(&mut self) -> Option<Self::Item>;

}

The type Item is a placeholder, and next returns values of type Option<Self::Item>. Implementors of Iterator specify the concrete type for Item, and next returns an Option containing a value of that concrete type.

Associated types might seem similar to generics, which also let us define a function without specifying what types it can handle. To examine the difference, the next slide implements Iterator on a type named Counter that specifies the Item type is u32.
