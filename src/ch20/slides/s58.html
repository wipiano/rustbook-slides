The downside of a newtype

Wrapper is a new type, so it doesn’t have the methods of the value it’s holding. Three options:

  • Implement all the methods of Vec<T> directly on Wrapper, delegating to self.0 — then we can treat Wrapper exactly like a Vec<T>.
  • If the new type should have every method the inner type has, implement the Deref trait on Wrapper to return the inner type (Chapter 15, “Treating Smart Pointers Like Regular References”).
  • If Wrapper should not have all the inner type’s methods — for example, to restrict its behavior — implement manually just the methods we do want.

The newtype pattern is also useful even when traits are not involved. Next, the focus switches to some advanced ways to interact with Rust’s type system.
