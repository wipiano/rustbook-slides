Listing 20.5: An attempted implementation of split_at_mut using only safe Rust

fn split_at_mut(values: &mut [i32], mid: usize) -> (&mut [i32], &mut [i32]) {

    let len = values.len();

 

    assert!(mid <= len);

 

    (&mut values[..mid], &mut values[mid..])

}

 

fn main() {

    let mut vector = vec![1, 2, 3, 4, 5, 6];

    let (left, right) = split_at_mut(&mut vector, 3);

}

  • First get the slice’s total length, then assert that the index is ≤ the length: given a larger index, the function panics before it attempts to use it.
  • Then return two mutable slices in a tuple: one from the start of the original slice to mid, another from mid to the end.
