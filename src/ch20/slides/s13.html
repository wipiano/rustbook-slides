Reaching for unsafe: split_at_mut

The borrow checker can’t understand that we’re borrowing different parts of the slice; it only knows we’re borrowing from the same slice twice. Borrowing non-overlapping parts is fundamentally okay, but Rust isn’t smart enough to know this. When we know code is okay but Rust doesn’t, it’s time to reach for unsafe code: Listing 20.6 uses an unsafe block, a raw pointer, and some calls to unsafe functions.
