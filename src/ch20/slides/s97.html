Declaring a proc-macro crate

We need to declare the hello_macro_derive crate as a procedural macro crate. We’ll also need functionality from the syn and quote crates, so we add them as dependencies. Add the following to the Cargo.toml file for hello_macro_derive:

hello_macro_derive/Cargo.toml

[lib]

proc-macro = true

 

[dependencies]

syn = "2.0"

quote = "1.0"

To start defining the procedural macro, place the code of Listing 20.40 (next slide) into the src/lib.rs file of the hello_macro_derive crate. This code won’t compile until we add a definition for the impl_hello_macro function.
