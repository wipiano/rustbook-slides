What does continue return?

Listing 20.27: A match with an arm that ends in continue

let guess: u32 = match guess.trim().parse() {

    Ok(num) => num,

    Err(_) => continue,

};

Code that doesn’t work: arms of different types

fn main() {

    let guess = "3";

    let guess = match guess.trim().parse() {

        Ok(_) => 5,

        Err(_) => "hello",

    };

}

Listing 20.27 is a bit of the guessing game; at the time, some details were skipped. Chapter 6 (“The match Control Flow Construct”) said that match arms must all return the same type, so the code on the right doesn’t work: the type of guess would have to be an integer and a string, and Rust requires that guess have only one type.

So what does continue return? How were we allowed to return a u32 from one arm and have another arm that ends with continue in Listing 20.27?
