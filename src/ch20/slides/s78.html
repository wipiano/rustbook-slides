An enum initializer as the argument to map

Listing 20.31: Using an enum initializer with the map method to create a Status instance from numbers

enum Status {

    Value(u32),

    Stop,

}

 

let list_of_statuses: Vec<Status> = (0u32..20).map(Status::Value).collect();

Here we create Status::Value instances using each u32 value in the range that map is called on, by using the initializer function of Status::Value.

Remark. Some people prefer this style and some people prefer to use closures. They compile to the same code, so use whichever style is clearer to you.
