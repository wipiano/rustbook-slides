Chapter 20 · 20.4 Advanced Functions and Closures

Passing add_one to do_twice

Listing 20.28: Using the fn type to accept a function pointer as an argument — src/main.rs

fn add_one(x: i32) -> i32 {

    x + 1

}

 

fn do_twice(f: fn(i32) -> i32, arg: i32) -> i32 {

    f(arg) + f(arg)

}

 

fn main() {

    let answer = do_twice(add_one, 5);

 

    println!("The answer is: {answer}");

}

This code prints The answer is: 12.

The parameter f in do_twice is an fn that takes one parameter of type i32 and returns an i32. We can then call f in the body of do_twice. In main, we pass the function name add_one as the first argument.

Unlike closures, fn is a type rather than a trait, so we specify fn as the parameter type directly rather than declaring a generic type parameter with one of the Fn traits as a trait bound.
