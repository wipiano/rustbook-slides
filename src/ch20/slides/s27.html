Running Miri on Listing 20.7

Miri requires a nightly build of Rust (Appendix G). rustup +nightly component add miri installs both a nightly Rust and Miri; this doesn’t change the Rust version your project uses, it only adds the tool to your system. Run it with cargo +nightly miri run or cargo +nightly miri test. For an example of how helpful this can be, run it against Listing 20.7:

$ cargo +nightly miri run
