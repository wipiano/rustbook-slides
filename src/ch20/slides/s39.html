Customizing Rhs: adding Millimeters and Meters

Listing 20.16: Implementing the Add trait on Millimeters to add Millimeters and Meters — src/lib.rs

use std::ops::Add;

 

struct Millimeters(u32);

struct Meters(u32);

 

impl Add<Meters> for Millimeters {

    type Output = Millimeters;

 

    fn add(self, other: Meters) -> Millimeters {

        Millimeters(self.0 + (other.0 * 1000))

    }

}

Now an example where we customize the Rhs type rather than using the default. Two structs, Millimeters and Meters, hold values in different units.

This thin wrapping of an existing type in another struct is the newtype pattern, described in more detail later in this section.

We want to add millimeters to meters and have Add do the conversion correctly. So we specify impl Add<Meters>, setting the Rhs type parameter instead of using the default of Self.
