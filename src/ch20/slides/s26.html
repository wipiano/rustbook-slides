Superpower 5: union fields — and checking with Miri

Accessing fields of a union

Definition 20.10 (Union). A type similar to a struct, but only one declared field is used in a particular instance at one time.

Unions are primarily used to interface with unions in C code. Accessing union fields is unsafe because Rust can’t guarantee the type of the data currently stored in the union instance (more: the Rust Reference).

Using Miri to check unsafe code

Definition 20.11 (Miri). An official Rust tool for detecting undefined behavior. Whereas the borrow checker is a static tool that works at compile time, Miri is a dynamic tool that works at runtime: it runs your program, or its test suite, and detects when you violate the rules it understands about how Rust should work.

Miri is one of the best ways to check that unsafe code you’ve written actually is safe and correct.
