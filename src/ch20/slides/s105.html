Using the derive macro in a binary crate

At this point, cargo build should complete successfully in both hello_macro and hello_macro_derive. To see the procedural macro in action, create a new binary project in your projects directory with cargo new pancakes, and add hello_macro and hello_macro_derive as dependencies in the pancakes crate’s Cargo.toml.

If you publish your versions of hello_macro and hello_macro_derive to crates.io, they would be regular dependencies; if not, specify them as path dependencies:

[dependencies]

hello_macro = { path = "../hello_macro" }

hello_macro_derive = { path = "../hello_macro/hello_macro_derive" }

Put the code of Listing 20.37 into src/main.rs and run cargo run: it should print Hello, Macro! My name is Pancakes! The implementation of HelloMacro from the procedural macro was included without the pancakes crate needing to implement it; #[derive(HelloMacro)] added the trait implementation.
