Chapter 20

Advanced Features

By now you’ve learned the most commonly used parts of Rust. Before one more project in Chapter 21, this chapter looks at aspects of the language you might run into every once in a while but may not use every day. Use it as a reference when you encounter any unknowns: these features are useful in very specific situations, and you should have a grasp of all the features Rust has to offer. It’s a panoply of Rust features with something for everyone!

  • 20.1 Unsafe Rust — opting out of some of Rust’s guarantees and taking responsibility for manually upholding them
  • 20.2 Advanced Traits — associated types, default type parameters, fully qualified syntax, supertraits, and the newtype pattern in relation to traits
  • 20.3 Advanced Types — more about the newtype pattern, type aliases, the never type, and dynamically sized types
  • 20.4 Advanced Functions and Closures — function pointers and returning closures
  • 20.5 Macros — ways to define code that defines more code at compile time
