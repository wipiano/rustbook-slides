Chapter 20 · 20.5 Macros

Custom derive macros: the goal

We’ll create a crate named hello_macro that defines a trait HelloMacro with one associated function hello_macro.

Rather than making users implement HelloMacro for each of their types, we provide a procedural macro so they can annotate their type with #[derive(HelloMacro)] to get a default implementation of hello_macro. It prints Hello, Macro! My name is TypeName!, where TypeName is the name of the type on which the trait has been defined.

Listing 20.37: The code a user of our crate will be able to write when using our procedural macro — src/main.rs

use hello_macro::HelloMacro;

use hello_macro_derive::HelloMacro;

 

#[derive(HelloMacro)]

struct Pancakes;

 

fn main() {

    Pancakes::hello_macro();

}

When we’re done, this code will print Hello, Macro! My name is Pancakes!
