Chapter 20 · 20.2 Advanced Traits

OutlinePrint requires Display

Listing 20.23: Implementing the OutlinePrint trait that requires the functionality from Display — src/main.rs

use std::fmt;

 

trait OutlinePrint: fmt::Display {

    fn outline_print(&self) {

        let output = self.to_string();

        let len = output.len();

        println!("{}", "*".repeat(len + 4));

        println!("*{}*", " ".repeat(len + 2));

        println!("* {output} *");

        println!("*{}*", " ".repeat(len + 2));

        println!("{}", "*".repeat(len + 4));

    }

}

 

fn main() {}

Because OutlinePrint requires the Display trait, we can use the to_string function that is automatically implemented for any type that implements Display.

Without the colon and Display after the trait name, using to_string would give an error saying that no method named to_string was found for the type &Self in the current scope.
