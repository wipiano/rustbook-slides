Chapter 20 · 20.2 Advanced Traits

Using supertraits

Sometimes a trait definition depends on another trait: for a type to implement the first trait, you want to require that it also implements the second, so that your trait definition can use the second trait’s associated items.

Definition 20.16 (Supertrait). The trait your trait definition is relying on.

Example: an OutlinePrint trait with an outline_print method that prints a value framed in asterisks. Given a Point that implements the standard library trait Display to result in (x, y), calling outline_print on a Point with 1 for x and 3 for y should print the output on the right.

**********

*        *

* (1, 3) *

*        *

**********

The implementation of outline_print needs Display’s functionality, so OutlinePrint must work only for types that also implement Display. We specify that in the trait definition as OutlinePrint: Display — similar to adding a trait bound to the trait.
