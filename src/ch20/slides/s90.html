Chapter 20 · 20.5 Macros

What vec![1, 2, 3] expands to

In the arm’s body, temp_vec.push() within $()* is generated for each part matching $() — zero or more times — with $x replaced by each expression matched. vec![1, 2, 3]; is replaced by:

{

    let mut temp_vec = Vec::new();

    temp_vec.push(1);

    temp_vec.push(2);

    temp_vec.push(3);

    temp_vec

}

We’ve defined a macro that can take any number of arguments of any type and can generate code to create a vector containing the specified elements.

Remark. To learn more about writing macros, consult the online documentation or other resources, such as “The Little Book of Rust Macros” (veykril.github.io/tlborm), started by Daniel Keep and continued by Lukas Wirth.
