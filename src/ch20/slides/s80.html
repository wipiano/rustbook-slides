A Vec of closures returned as impl Fn

Listing 20.33: Creating a Vec<T> of closures defined by functions that return impl Fn types — src/main.rs

fn main() {

    let handlers = vec![returns_closure(), returns_initialized_closure(123)];

    for handler in handlers {

        let output = handler(5);

        println!("{output}");

    }

}

 

fn returns_closure() -> impl Fn(i32) -> i32 {

    |x| x + 1

}

 

fn returns_initialized_closure(init: i32) -> impl Fn(i32) -> i32 {

    move |x| x + init

}

Both return impl Fn(i32) -> i32, but the closures they return differ. Compiling fails (next slide).
