Chapter 20 · 20.1 Unsafe Rust

Superpower 2: calling an unsafe function or method

Definition 20.4 (Unsafe function). A function or method that looks exactly like a regular one but has an extra unsafe before the rest of the definition. The keyword indicates the function has requirements we need to uphold when we call it, because Rust can’t guarantee we’ve met them.

By calling an unsafe function within an unsafe block, we’re saying that we’ve read this function’s documentation and we take responsibility for upholding the function’s contracts. Here is an unsafe function named dangerous that doesn’t do anything in its body:

unsafe fn dangerous() {}

 

unsafe {

    dangerous();

}

We must call dangerous within a separate unsafe block. Calling it without the unsafe block is an error (next slide).
