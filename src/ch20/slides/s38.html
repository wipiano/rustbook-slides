Chapter 20 · 20.2 Advanced Traits

The Add trait and Rhs=Self

The default generic type in Listing 20.15 is within the Add trait. Here is its definition:

trait Add<Rhs=Self> {

    type Output;

 

    fn add(self, rhs: Rhs) -> Self::Output;

}

This should look generally familiar: a trait with one method and an associated type. The new part is Rhs=Self.

Definition 20.14 (Default type parameters). The syntax Rhs=Self, which gives a generic type parameter a default concrete type.

The Rhs generic type parameter (short for “right-hand side”) defines the type of the rhs parameter in add. If we don’t specify a concrete type for Rhs when implementing Add, it defaults to Self, the type we’re implementing Add on. For Point we used the default, because we wanted to add two Point instances.
