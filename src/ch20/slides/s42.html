Chapter 20 · 20.2 Advanced Traits

Calling each fly

With the traits, struct and impls of Listing 20.17 unchanged, only main differs below.

Listing 20.18: Calling fly on an instance of Human — src/main.rs

fn main() {

    let person = Human;

    person.fly();

}

The compiler defaults to calling the method implemented directly on the type: this prints *waving arms furiously*.

Listing 20.19: Specifying which trait’s fly method we want to call — src/main.rs

fn main() {

    let person = Human;

    Pilot::fly(&person);

    Wizard::fly(&person);

    person.fly();

}

Specifying the trait name before the method name clarifies to Rust which implementation of fly we want. Human::fly(&person) is equivalent to person.fly(), but a bit longer to write if we don’t need to disambiguate.
