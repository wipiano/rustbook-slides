Chapter 20 · 20.2 Advanced Traits

Dog::baby_name calls the type’s own function

Naming all puppies Spot is done by Dog’s own baby_name. Dog also implements Animal, which describes characteristics all animals have; baby dogs are called puppies, expressed in Animal’s baby_name on Dog.

In main, we call Dog::baby_name, which calls the associated function defined on Dog directly. This prints:

$ cargo run

   Compiling traits-example v0.1.0 (file:///projects/traits-example)

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.54s

     Running `target/debug/traits-example`

A baby dog is called a Spot

This output isn’t what we wanted: we want the baby_name function that is part of the Animal trait implemented on Dog, so that the code prints A baby dog is called a puppy. Specifying the trait name, as in Listing 20.19, doesn’t help here: changing main to Listing 20.21 gives a compilation error.
