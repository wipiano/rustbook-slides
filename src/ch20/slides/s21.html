Chapter 20 · 20.1 Unsafe Rust

Superpower 3: static variables

Definition 20.8 (Static variable). Rust’s name for a global variable. Rust supports them, but they can be problematic with Rust’s ownership rules: if two threads are accessing the same mutable global variable, it can cause a data race.

Listing 20.10: Defining and using an immutable static variable — src/main.rs

static HELLO_WORLD: &str = "Hello, world!";

 

fn main() {

    println!("value is: {HELLO_WORLD}");

}

  • Static variables are similar to constants (Chapter 3, “Declaring Constants”). Their names are in SCREAMING_SNAKE_CASE by convention.
  • They can only store references with the 'static lifetime, so the compiler can figure out the lifetime and we needn’t annotate it.
  • Accessing an immutable static variable is safe.
