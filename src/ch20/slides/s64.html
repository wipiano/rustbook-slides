Chapter 20 · 20.3 Advanced Types

std::io::Result<T>

So std::io has this type alias declaration, and the Write trait’s signatures end up looking like this:

use std::fmt;

 

type Result<T> = std::result::Result<T, std::io::Error>;

 

pub trait Write {

    fn write(&mut self, buf: &[u8]) -> Result<usize>;

    fn flush(&mut self) -> Result<()>;

 

    fn write_all(&mut self, buf: &[u8]) -> Result<()>;

    fn write_fmt(&mut self, fmt: fmt::Arguments) -> Result<()>;

}

Because this declaration is in the std::io module, we can use the fully qualified alias std::io::Result<T>: a Result<T, E> with the E filled in as std::io::Error.

It makes code easier to write and gives a consistent interface across std::io. As an alias it’s just another Result<T, E>: its methods and special syntax like the ? operator work.
