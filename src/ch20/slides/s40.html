Chapter 20 · 20.2 Advanced Traits

Why default type parameters; same-named methods

You’ll use default type parameters in two main ways:

  1. To extend a type without breaking existing code: if you add a type parameter to an existing trait, a default allows extending the trait’s functionality without breaking the existing implementation code.
  2. To allow customization in specific cases most users won’t need. The standard library’s Add is an example: usually you add two like types, but Add lets you customize beyond that. With the default, you don’t have to specify the extra parameter most of the time — a bit of implementation boilerplate isn’t needed, making the trait easier to use.

Disambiguating between identically named methods

Nothing in Rust prevents a trait from having a method with the same name as another trait’s method, nor implementing both traits on one type. A type can also have a method of its own with the same name. When calling methods with the same name, you need to tell Rust which one you want.
