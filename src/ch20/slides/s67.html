Chapter 20 · 20.3 Advanced Types

continue has the type !

As you might have guessed, continue has a ! value. When Rust computes the type of guess, it looks at both match arms: the former with a value of u32, the latter with a ! value. Because ! can never have a value, Rust decides that the type of guess is u32.

Definition 20.21 (Coercion of !). The formal description of this behavior: expressions of type ! can be coerced into any other type.

We’re allowed to end this match arm with continue because continue doesn’t return a value; instead, it moves control back to the top of the loop. So in the Err case, we never assign a value to guess.

The never type is useful with the panic! macro as well. Recall the unwrap function that we call on Option<T> values to produce a value or panic (next slide).
