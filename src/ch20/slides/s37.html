Overloading + for Point

Listing 20.15: Implementing the Add trait to overload the + operator for Point instances — src/main.rs

use std::ops::Add;

 

#[derive(Debug, Copy, Clone, PartialEq)]

struct Point {

    x: i32,

    y: i32,

}

 

impl Add for Point {

    type Output = Point;

 

    fn add(self, other: Point) -> Point {

        Point {

            x: self.x + other.x,

            y: self.y + other.y,

        }

    }

}

 

fn main() {

    assert_eq!(

        Point { x: 1, y: 0 } + Point { x: 2, y: 3 },

        Point { x: 3, y: 3 }

    );

}

add sums the x values and the y values of two Point instances into a new Point. The Add trait’s associated type Output determines the type returned from add.
