Keywords currently in use (4 of 4): super – while

Table A.1 (continued): Keywords currently in use, with their functionality

KeywordFunctionality
superParent module of the current module
traitDefine a trait
trueBoolean true literal
typeDefine a type alias or associated type
unionDefine a union; is a keyword only when used in a union declaration
unsafeDenote unsafe code, functions, traits, or implementations
useBring symbols into scope
whereDenote clauses that constrain a type
whileLoop conditionally based on the result of an expression

Remark. union is a contextual keyword: outside a union declaration it can still be used as an ordinary identifier. See the Rust Reference, “Unions”.
