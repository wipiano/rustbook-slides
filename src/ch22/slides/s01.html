Appendix · A Keywords

Keywords are reserved words

The following lists contain keywords that are reserved for current or future use by the Rust language. As such, they cannot be used as identifiers — except as raw identifiers, discussed in “Raw Identifiers” at the end of this appendix.

Definition A.1 (Identifier). A name of a function, variable, parameter, struct field, module, crate, constant, macro, static value, attribute, type, trait, or lifetime.

Appendix A has three parts:

  • Keywords currently in use — each listed with its functionality (Table A.1, four slides).
  • Keywords reserved for future use — no functionality yet (Table A.2).
  • Raw identifiers — the r# syntax that lets you use a keyword as an identifier.
