PartialOrd for ordering comparisons

The PartialOrd trait lets you compare instances of a type for sorting purposes. A type that implements PartialOrd can be used with the <, >, <=, and >= operators. You can only apply PartialOrd to types that also implement PartialEq.

Deriving PartialOrd implements the partial_cmp method, which returns an Option<Ordering> that is None when the values given don’t produce an ordering. An example of a value that doesn’t produce an ordering, even though most values of its type can be compared, is the NaN floating-point value: calling partial_cmp with any floating-point number and NaN returns None.

  • On structs: compares two instances by comparing the value in each field, in the order the fields appear in the struct definition.
  • On enums: variants declared earlier in the enum definition are considered less than the variants listed later.

Required by: for example, the gen_range method from the rand crate, which generates a random value in the range specified by a range expression.
