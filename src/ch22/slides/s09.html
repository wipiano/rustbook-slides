Appendix · B Operators and Symbols

A glossary of Rust’s syntax

This appendix contains a glossary of Rust’s syntax, including operators and other symbols that appear by themselves or in the context of paths, generics, trait bounds, macros, attributes, comments, tuples, and brackets.

Operators

Table A.3 (the book’s Table B-1, next six slides) lists the operators in Rust, an example of how each operator would appear in context, a short explanation, and whether that operator is overloadable. If an operator is overloadable, the relevant trait to use to overload that operator is listed.

Example A.4. The row for + in expr + expr names the trait Add: implement std::ops::Add for your type and a + b works on it. Rows with an empty last cell (such as &&) cannot be overloaded.

The non-operator symbols follow in Tables A.4–A.12 (the book’s Tables B-2 to B-10).
