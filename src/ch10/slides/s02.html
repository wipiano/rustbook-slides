Chapter 10 · Removing Duplication by Extracting a Function

From duplicated values to a placeholder

Generics allow us to replace specific types with a placeholder that represents multiple types, to remove code duplication.

Before diving into generics syntax, first look at removing duplication in a way that doesn’t involve generic types: extracting a function that replaces specific values with a placeholder that represents multiple values. Then apply the same technique to extract a generic function!

By learning to recognize duplicated code you can extract into a function, you’ll start to recognize duplicated code that can use generics.
