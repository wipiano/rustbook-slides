Chapter 10 · Removing Duplication by Extracting a Function

Extracting a largest function

To eliminate this duplication, we create an abstraction: a function that operates on any list of integers passed in as a parameter. This makes the code clearer and expresses the concept of finding the largest number in a list abstractly.

Listing 10.3 extracts the code into a function named largest and calls it for the two lists from Listing 10.2. We could also use it on any other list of i32 values in the future.

Listing 10.3: Abstracted code to find the largest number in two lists — src/main.rs

fn largest(list: &[i32]) -> &i32 {

    let mut largest = &list[0];

 

    for item in list {

        if item > largest {

            largest = item;

        }

    }

 

    largest

}
