Chapter 10 · 10.3 Validating References with Lifetimes

Generic lifetimes in functions

We’ll write a function that returns the longer of two string slices: it takes two string slices and returns a single string slice. After we’ve implemented longest, the code in Listing 10.19 should print The longest string is abcd.

Listing 10.19: A main function that calls the longest function to find the longer of two string slices — src/main.rs

fn main() {

    let string1 = String::from("abcd");

    let string2 = "xyz";

 

    let result = longest(string1.as_str(), string2);

    println!("The longest string is {result}");

}

We want the function to take string slices, which are references, rather than strings, because we don’t want longest to take ownership of its parameters. See “String Slices as Parameters” in Chapter 4 for why these are the parameters we want.
