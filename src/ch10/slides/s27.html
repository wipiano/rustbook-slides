Chapter 10 · 10.1 Generic Data Types

Calling mixup

mixup creates a new Point with the x value from the self Point (of type X1) and the y value from the passed-in Point (of type Y2).

Listing 10.11 (continued)

fn main() {

    let p1 = Point { x: 5, y: 10.4 };

    let p2 = Point { x: "Hello", y: 'c' };

 

    let p3 = p1.mixup(p2);

 

    println!("p3.x = {}, p3.y = {}", p3.x, p3.y);

}

p1 has an i32 for x (value 5) and an f64 for y (value 10.4). p2 has a string slice for x (value "Hello") and a char for y (value c).

Calling mixup on p1 with argument p2 gives p3: an i32 for x (from p1) and a char for y (from p2). It prints p3.x = 5, p3.y = c.

The point: some generic parameters are declared with impl and some with the method definition. X1 and Y1 are declared after impl because they go with the struct definition. X2 and Y2 are declared after fn mixup because they’re only relevant to the method.
