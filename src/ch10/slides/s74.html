Chapter 10 · 10.3 Validating References with Lifetimes

Different concrete lifetimes: accepted

Let’s see how the annotations restrict longest by passing in references that have different concrete lifetimes. Listing 10.22 is a straightforward example.

Listing 10.22: Using the longest function with references to String values that have different concrete lifetimes — src/main.rs

fn main() {

    let string1 = String::from("long string is long");

 

    {

        let string2 = String::from("xyz");

        let result = longest(string1.as_str(), string2.as_str());

        println!("The longest string is {result}");

    }

}

 

fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {

    if x.len() > y.len() { x } else { y }

}
