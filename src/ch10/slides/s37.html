Chapter 10 · 10.2 Defining Shared Behavior with Traits

Using the trait from a binary crate

A binary crate using our aggregator library brings Summary into scope along with SocialPost:

use aggregator::{SocialPost, Summary};

 

fn main() {

    let post = SocialPost {

        username: String::from("horse_ebooks"),

        content: String::from(

            "of course, as you probably already know, people",

        ),

        reply: false,

        repost: false,

    };

 

    println!("1 new post: {}", post.summarize());

}

This code prints 1 new post: horse_ebooks: of course, as you probably already know, people.
