Chapter 10 · 10.3 Validating References with Lifetimes

The static lifetime

One special lifetime is 'static, which denotes that the affected reference can live for the entire duration of the program. All string literals have the 'static lifetime, which we can annotate as follows:

let s: &'static str = "I have a static lifetime.";

The text of this string is stored directly in the program’s binary, which is always available. Therefore, the lifetime of all string literals is 'static.

Remark. You might see suggestions in error messages to use the 'static lifetime. Before specifying 'static for a reference, think about whether the reference actually lives the entire lifetime of your program, and whether you want it to. Most of the time, an error message suggesting 'static results from attempting to create a dangling reference or a mismatch of the available lifetimes. In such cases, the solution is to fix those problems, not to specify the 'static lifetime.
