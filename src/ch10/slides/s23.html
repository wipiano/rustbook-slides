Chapter 10 · 10.1 Generic Data Types

Generics in method definitions

We can implement methods on structs and enums (Chapter 5) and use generic types in their definitions too. Listing 10.9 shows the Point<T> struct of Listing 10.6 with a method named x implemented on it.

Listing 10.9: Implementing a method named x on the Point<T> struct that will return a reference to the x field of type T — src/main.rs

struct Point<T> {

    x: T,

    y: T,

}

 

impl<T> Point<T> {

    fn x(&self) -> &T {

        &self.x

    }

}

fn main() {

    let p = Point { x: 5, y: 10 };

 

    println!("p.x = {}", p.x());

}

Here, we’ve defined a method named x on Point<T> that returns a reference to the data in the field x.
