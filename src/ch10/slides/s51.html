Chapter 10 · 10.2 Defining Shared Behavior with Traits

Where returning impl Trait shines — and its limit

Specifying a return type only by the trait it implements is especially useful with closures and iterators (Chapter 13). Closures and iterators create types that only the compiler knows, or types that are very long to specify. The impl Trait syntax lets you concisely say that a function returns some type that implements the Iterator trait without writing out a very long type.

Remark. You can only use impl Trait if you’re returning a single type.
