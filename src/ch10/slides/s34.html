Implementing a trait on a type

Listing 10.13 implements Summary on NewsArticle, using the headline, the author and the location to build the return value of summarize. For SocialPost, summarize is the username followed by the entire text of the post, assuming the content is already limited to 280 characters.

Listing 10.13: Implementing the Summary trait on the NewsArticle and SocialPost types — src/lib.rs

pub trait Summary {

    fn summarize(&self) -> String;

}

 

pub struct NewsArticle {

    pub headline: String,

    pub location: String,

    pub author: String,

    pub content: String,

}
