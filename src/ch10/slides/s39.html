Chapter 10 · 10.2 Defining Shared Behavior with Traits

Using default implementations

Sometimes it’s useful to have default behavior for some or all of the methods in a trait instead of requiring implementations for all methods on every type. Then, as we implement the trait on a particular type, we can keep or override each method’s default behavior.

Definition 10.8 (Default implementation). A method body written in the trait definition itself, used by every implementing type that does not override it.

In Listing 10.14, we specify a default string for the summarize method of the Summary trait instead of only defining the method signature, as we did in Listing 10.12.

To use a default implementation to summarize instances of NewsArticle, we specify an empty impl block: impl Summary for NewsArticle {}.
