A first longest that doesn’t compile

If we try to implement the longest function as shown in Listing 10.20, it won’t compile.

Listing 10.20: An implementation of the longest function that returns the longer of two string slices but does not yet compile — src/main.rs

fn main() {

    let string1 = String::from("abcd");

    let string2 = "xyz";

 

    let result = longest(string1.as_str(), string2);

    println!("The longest string is {result}");

}

 

fn longest(x: &str, y: &str) -> &str {

    if x.len() > y.len() { x } else { y }

}

Instead, we get an error that talks about lifetimes (next slide).
