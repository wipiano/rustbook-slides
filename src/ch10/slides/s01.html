The road through this chapter

Definition 10.1 (Generics). Abstract stand-ins for concrete types or other properties. Their behavior, and how they relate to other generics, can be expressed without knowing what will be in their place when the code is compiled and run.

  1. First, review how to extract a function to reduce code duplication. Then use the same technique to make a generic function from two functions that differ only in the types of their parameters, and use generic types in struct and enum definitions.
  2. Then, learn how to use traits to define behavior in a generic way. Combining traits with generic types constrains a generic type to accept only those types that have a particular behavior, as opposed to just any type.
  3. Finally, lifetimes: a variety of generics that give the compiler information about how references relate to each other. They let us give the compiler enough information about borrowed values so it can ensure references will be valid in more situations than it could without our help.
