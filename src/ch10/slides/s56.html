Chapter 10 · 10.2 Defining Shared Behavior with Traits

Blanket implementations

We can also conditionally implement a trait for any type that implements another trait. Implementations of a trait on any type that satisfies the trait bounds are called blanket implementations, and they are used extensively in the Rust standard library. For example, the standard library implements ToString on any type that implements Display; its impl block looks similar to this:

impl<T: Display> ToString for T {

    // --snip--

}

Because of this blanket implementation, we can call the to_string method defined by ToString on any type that implements Display. For example, we can turn integers into their corresponding String values because integers implement Display:

let s = 3.to_string();
