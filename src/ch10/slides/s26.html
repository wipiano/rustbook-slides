Chapter 10 · 10.1 Generic Data Types

Method generics that differ from the struct’s

Generic type parameters in a struct definition aren’t always the same as those in that struct’s method signatures. Listing 10.11 uses X1 and Y1 for the Point struct and X2 and Y2 for the mixup method.

Listing 10.11: A method that uses generic types that are different from its struct’s definition — src/main.rs

struct Point<X1, Y1> {

    x: X1,

    y: Y1,

}

 

impl<X1, Y1> Point<X1, Y1> {

    fn mixup<X2, Y2>(self, other: Point<X2, Y2>) -> Point<X1, Y2> {

        Point {

            x: self.x,

            y: other.y,

        }

    }

}
