Chapter 10 · 10.3 Validating References with Lifetimes

Lifetimes in struct definitions

So far, the structs we’ve defined all hold owned types. Structs can hold references, but then we need a lifetime annotation on every reference in the struct’s definition. Listing 10.24 has a struct named ImportantExcerpt that holds a string slice.

Listing 10.24: A struct that holds a reference, requiring a lifetime annotation — src/main.rs

struct ImportantExcerpt<'a> {

    part: &'a str,

}

 

fn main() {

    let novel = String::from("Call me Ishmael. Some years ago...");

    let first_sentence = novel.split('.').next().unwrap();

    let i = ImportantExcerpt {

        part: first_sentence,

    };

}
