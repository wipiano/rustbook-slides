Chapter 10 · 10.1 Generic Data Types

Methods only for Point<f32>

Listing 10.10: An impl block that only applies to a struct with a particular concrete type for the generic type parameter T — src/main.rs

struct Point<T> {

    x: T,

    y: T,

}

 

impl<T> Point<T> {

    fn x(&self) -> &T {

        &self.x

    }

}

impl Point<f32> {

    fn distance_from_origin(&self) -> f32 {

        (self.x.powi(2) + self.y.powi(2)).sqrt()

    }

}

 

fn main() {

    let p = Point { x: 5, y: 10 };

 

    println!("p.x = {}", p.x());

}

Point<f32> will have a distance_from_origin method; instances of Point<T> where T is not f32 will not. The method measures how far our point is from (0.0, 0.0) using mathematical operations available only for floating-point types.
