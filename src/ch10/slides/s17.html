Chapter 10 · 10.1 Generic Data Types

Generics in struct definitions

Structs can also use a generic type parameter in one or more fields using the <> syntax. Listing 10.6 defines a Point<T> struct to hold x and y coordinate values of any type.

Listing 10.6: A Point<T> struct that holds x and y values of type T — src/main.rs

struct Point<T> {

    x: T,

    y: T,

}

 

fn main() {

    let integer = Point { x: 5, y: 10 };

    let float = Point { x: 1.0, y: 4.0 };

}

The syntax is similar to that used in function definitions:

  1. Declare the name of the type parameter inside angle brackets just after the name of the struct.
  2. Use the generic type in the struct definition where we would otherwise specify concrete data types.
