Chapter 10 · 10.2 Defining Shared Behavior with Traits

Using traits as parameters: impl Trait

Now we can use traits to define functions that accept many different types. Using the Summary trait implemented on NewsArticle and SocialPost in Listing 10.13, we define a notify function that calls summarize on its item parameter, which is of some type that implements Summary. We use the impl Trait syntax:

pub fn notify(item: &impl Summary) {

    println!("Breaking news! {}", item.summarize());

}

  • Instead of a concrete type for item, we specify the impl keyword and the trait name. The parameter accepts any type that implements the specified trait.
  • In the body of notify, we can call any methods on item that come from Summary, such as summarize.
  • We can pass in any instance of NewsArticle or SocialPost. Calling it with any other type, such as a String or an i32, won’t compile, because those types don’t implement Summary.
