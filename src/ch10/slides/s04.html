Two lists: duplicating the logic

Now we must find the largest number in two different lists. We could duplicate the code of Listing 10.1 and use the same logic at two different places in the program, as in Listing 10.2.

Listing 10.2: Code to find the largest number in two lists of numbers — src/main.rs

fn main() {

    let number_list = vec![34, 50, 25, 100, 65];

 

    let mut largest = &number_list[0];

 

    for number in &number_list {

        if number > largest {

            largest = number;

        }

    }

 

    println!("The largest number is {largest}");
