Chapter 10 · 10.2 Defining Shared Behavior with Traits

Traits and trait bounds

Definition 10.5 (Trait). Defines the functionality a particular type has and can share with other types. Traits define shared behavior in an abstract way.

Definition 10.6 (Trait bound). A constraint specifying that a generic type can be any type that has certain behavior.

Remark. Traits are similar to a feature often called interfaces in other languages, although with some differences.

Defining a trait

A type’s behavior consists of the methods we can call on that type. Different types share the same behavior if we can call the same methods on all of those types. Trait definitions are a way to group method signatures together to define a set of behaviors necessary to accomplish some purpose.
