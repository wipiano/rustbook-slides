Chapter 10 · 10.1 Generic Data Types

What monomorphized code looks like

When Rust compiles this code, it reads the values used in Option<T> instances and identifies two kinds of Option<T>: one is i32 and the other is f64. It expands the generic definition into two definitions specialized to i32 and f64, replacing the generic definition with the specific ones.

The monomorphized version looks similar to this (the compiler uses different names than these illustrative ones):

src/main.rs

enum Option_i32 {

    Some(i32),

    None,

}

 

enum Option_f64 {

    Some(f64),

    None,

}

fn main() {

    let integer = Option_i32::Some(5);

    let float = Option_f64::Some(5.0);

}
