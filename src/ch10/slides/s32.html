Chapter 10 · 10.2 Defining Shared Behavior with Traits

A media aggregator and its Summary trait

Say we have multiple structs that hold various kinds and amounts of text: a NewsArticle struct that holds a news story filed in a particular location, and a SocialPost that can have at most 280 characters, along with metadata indicating whether it was a new post, a repost, or a reply to another post.

We want a media aggregator library crate named aggregator that can display summaries of data that might be stored in a NewsArticle or SocialPost instance. We need a summary from each type, requested by calling a summarize method on an instance. Listing 10.12 defines a public Summary trait that expresses this behavior.

Listing 10.12: A Summary trait that consists of the behavior provided by a summarize method — src/lib.rs

pub trait Summary {

    fn summarize(&self) -> String;

}
