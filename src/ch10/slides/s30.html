Chapter 10 · 10.1 Generic Data Types

No runtime cost — and where generics are declared

The generic Option<T> is replaced with the specific definitions created by the compiler. Because Rust compiles generic code into code that specifies the type in each instance, we pay no runtime cost for using generics: the code performs just as it would if we had duplicated each definition by hand. Monomorphization makes Rust’s generics extremely efficient at runtime.

Table 10.1: Where generic type parameters are declared (Section 10.1 recap)

DeclarationWhere the parameter goes
fn largest<T>(list: &[T]) -> &TAfter the function name, before the parameter list
struct Point<T, U> { x: T, y: U }After the struct name
enum Result<T, E> { Ok(T), Err(E) }After the enum name
impl<T> Point<T> { … }After impl, then used after the type name
impl Point<f32> { … }None: methods only for one concrete type
fn mixup<X2, Y2>(self, …)After the method name, for method-only types
