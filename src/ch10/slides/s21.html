Chapter 10 · 10.1 Generic Data Types

Generics in enum definitions: Option<T>

As with structs, enums can hold generic data types in their variants. Take another look at the Option<T> enum that the standard library provides, which we used in Chapter 6:

enum Option<T> {

    Some(T),

    None,

}

This definition should now make more sense. Option<T> is generic over type T and has two variants: Some, which holds one value of type T, and None, which doesn’t hold any value.

By using Option<T> we can express the abstract concept of an optional value, and because Option<T> is generic, we can use this abstraction no matter what the type of the optional value is.
