Chapter 10 · 10.2 Defining Shared Behavior with Traits

Who may implement what: the orphan rule

Other crates that depend on aggregator can also bring Summary into scope to implement it on their own types. One restriction: we can implement a trait on a type only if either the trait or the type, or both, are local to our crate.

Allowed

  • Standard library trait Display on our type SocialPost: the type is local to aggregator.
  • Our trait Summary on Vec<T>: the trait is local to aggregator.

Not allowed

  • External traits on external types: Display on Vec<T> within aggregator, because both are defined in the standard library.

Definition 10.7 (Orphan rule). Part of a property called coherence: external traits can’t be implemented on external types — so named because the parent type is not present. It ensures other people’s code can’t break your code and vice versa. Without it, two crates could implement the same trait for the same type, and Rust wouldn’t know which implementation to use.
