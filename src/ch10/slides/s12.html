Chapter 10 · 10.1 Generic Data Types

Naming and declaring a type parameter

To parameterize the types in a new single function, we name the type parameter, just as we do for the value parameters to a function. Any identifier works, but we use T: by convention, type parameter names in Rust are short, often just one letter, and Rust’s type-naming convention is UpperCamelCase. Short for type, T is the default choice of most Rust programmers.

Definition 10.3 (Generic type parameter). A name, declared in angle brackets <>, that stands for a type in a definition, just as a value parameter stands for a value.

When we use a parameter in a function body, we must declare its name in the signature so the compiler knows what it means. Similarly, a type parameter name used in a function signature must be declared before use: we place type name declarations inside angle brackets, <>, between the function name and the parameter list:
