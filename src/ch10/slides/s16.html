Why it fails: not every T can be compared

The help text mentions std::cmp::PartialOrd, which is a trait — the topic of the next section. For now, know that the error states that the body of largest won’t work for all possible types that T could be.

  • Because we want to compare values of type T in the body, we can only use types whose values can be ordered.
  • To enable comparisons, the standard library has the std::cmp::PartialOrd trait that you can implement on types (more in Appendix C).
  • To fix Listing 10.5, follow the help text’s suggestion: restrict the types valid for T to only those that implement PartialOrd.
  • The listing will then compile, because the standard library implements PartialOrd on both i32 and char.
