Chapter 10 · Removing Duplication by Extracting a Function

Three steps to remove duplication

In summary, the steps we took to change the code from Listing 10.2 to Listing 10.3:

  1. Identify duplicate code.
  2. Extract the duplicate code into the body of the function, and specify the inputs and return values of that code in the function signature.
  3. Update the two instances of duplicated code to call the function instead.

Next, we use these same steps with generics to reduce code duplication. In the same way that the function body can operate on an abstract list instead of specific values, generics allow code to operate on abstract types.
