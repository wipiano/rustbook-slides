What goes wrong in Listing 10.16

Definition 10.11 (Dangling reference). A reference that would point to data other than the data it’s intended to reference, because the referenced value has gone out of scope.

  • The outer scope declares a variable named r with no initial value.
  • The inner scope declares a variable named x with the initial value 5, and sets the value of r as a reference to x.
  • Then the inner scope ends, and we attempt to print the value in r.

This code won’t compile, because the value that r is referring to has gone out of scope before we try to use it. The error message is on the next slide.
