Chapter 10 · 10.3 Validating References with Lifetimes

Methods on ImportantExcerpt

Some examples use the struct ImportantExcerpt from Listing 10.24. First, a method named level whose only parameter is a reference to self and whose return value is an i32, which is not a reference to anything:

impl<'a> ImportantExcerpt<'a> {

    fn level(&self) -> i32 {

        3

    }

}

The lifetime parameter declaration after impl and its use after the type name are required, but because of the first elision rule, we’re not required to annotate the lifetime of the reference to self.
