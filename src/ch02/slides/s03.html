Chapter 2 · 2.2 Processing a Guess

Getting a guess from the user

The first part of the program asks for user input, processes that input, and checks that it is in the expected form. To start, we allow the player to input a guess: enter Listing 2.1 into src/main.rs.

Listing 2.1: Code that gets a guess from the user and prints it — src/main.rs

use std::io;

 

fn main() {

    println!("Guess the number!");

 

    println!("Please input your guess.");

 

    let mut guess = String::new();

 

    io::stdin()

        .read_line(&mut guess)

        .expect("Failed to read line");

 

    println!("You guessed: {guess}");

}
