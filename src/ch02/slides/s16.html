Declaring the dependency with a SemVer version

Cargo.toml

[dependencies]

rand = "0.10.1"

In Cargo.toml, everything after a header is part of that section until another section starts. [dependencies] tells Cargo which external crates your project depends on and which versions you require — here rand, with the semantic version specifier 0.10.1.

Definition 2.9 (Semantic Versioning). A standard for writing version numbers (semver.org), sometimes called SemVer, which Cargo understands.

  • The specifier 0.10.1 is shorthand for ^0.10.1: any version that is at least 0.10.1 but below 0.11.0.
  • Cargo considers these versions to have public APIs compatible with 0.10.1, so you get the latest patch release that will still compile with the code in this chapter.
  • Any version 0.11.0 or greater is not guaranteed to have the same API as the following examples use.
