Storing values with variables

Next, create a variable to store the user input. There’s a lot going on in this little line:

let mut guess = String::new();

Definition 2.2 (Variable). A name created with the let statement and bound to a value. In Rust, variables are immutable by default: once the variable is given a value, the value won’t change (Chapter 3, “Variables and Mutability”).

Another example: this line creates a new variable named apples and binds it to the value 5.

let apples = 5;

To make a variable mutable, add mut before the variable name:

let apples = 5; // immutable

let mut bananas = 5; // mutable

Remark. The // syntax starts a comment that continues until the end of the line. Rust ignores everything in comments. Chapter 3 discusses comments in more detail.
