Chapter 2 · 2.5 Allowing Multiple Guesses with Looping

A loop with no way out

  • We’ve moved everything from the guess input prompt onward into the loop. Be sure to indent the lines inside the loop another four spaces each, and run the program again.
  • The program now asks for another guess forever, which introduces a new problem: it doesn’t seem like the user can quit!
  • The user could always interrupt the program with the keyboard shortcut ctrl-C.
  • But there’s another way to escape this insatiable monster, as mentioned in the parse discussion in “Comparing the Guess to the Secret Number”: if the user enters a non-number answer, the program crashes. We can take advantage of that to allow the user to quit, as the session on the next two slides shows.
