Line by line: io, the prelude, main and println!

To get input and print output, bring the io library from the standard library, std, into scope:

use std::io;

Definition 2.1 (Prelude). The set of items defined in the standard library that Rust brings into the scope of every program by default. Everything in it is listed in the standard library documentation.

If a type you want to use isn’t in the prelude, bring it into scope explicitly with a use statement. Using the std::io library provides a number of useful features, including the ability to accept user input.

fn main() {

As in Chapter 1, main is the entry point. fn declares a new function; () indicates there are no parameters; { starts the body.
