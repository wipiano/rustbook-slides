The Result enum and its expect method

read_line puts whatever the user enters into the string we pass to it, but it also returns a Result value.

Definition 2.5 (Enumeration). A type that can be in one of multiple possible states, often called an enum; each possible state is a variant. Result is an enum (enums are covered in Chapter 6).

The purpose of Result types is to encode error-handling information. Result’s variants are:

  • Ok — the operation was successful; it contains the successfully generated value.
  • Err — the operation failed; it contains information about how or why it failed.

Like values of any type, a Result has methods, such as expect. If the Result is an Err value, expect causes the program to crash and displays the message passed to it; an Err from read_line would likely come from the underlying operating system. If it is an Ok value, expect takes the value Ok is holding and returns just that value for you to use — here, the number of bytes in the user’s input.
