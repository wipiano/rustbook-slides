References: why &mut guess

.read_line(&mut guess)

Definition 2.4 (Reference). An argument marked with &. A reference gives you a way to let multiple parts of your code access one piece of data without needing to copy that data into memory multiple times.

  • References are a complex feature, and one of Rust’s major advantages is how safe and easy it is to use them.
  • You don’t need to know a lot of those details to finish this program; Chapter 4 explains references more thoroughly.
  • For now, all you need to know is that, like variables, references are immutable by default.
  • Hence you need to write &mut guess rather than &guess to make it mutable.
