Now that we have user input and a random number, we can compare them, as in Listing 2.4. Note that this code won’t compile just yet, as explained shortly.

First, another use statement brings a type called std::cmp::Ordering into scope from the standard library.

The Ordering type is another enum and has the variants Less, Greater, and Equal. These are the three outcomes that are possible when you compare two values.
