Running cargo update

$ cargo update

    Updating crates.io index

     Locking 1 package to latest Rust 1.96.0 compatible version

    Updating rand v0.10.1 -> v0.10.2 (available: v0.999.0)

Cargo ignores the 0.999.0 release. Your Cargo.lock file now notes that the version of rand you are using is 0.10.2. To use rand version 0.999.0 or any version in the 0.999.x series, you’d have to update Cargo.toml to look like this instead (don’t actually make this change: the following examples assume rand 0.10):

[dependencies]

rand = "0.999.0"

The next time you run cargo build, Cargo will update the registry of crates available and reevaluate your rand requirements according to the new version you have specified.
