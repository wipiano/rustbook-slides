Chapter 2 · 2.1 Setting Up a New Project

Creating the guessing_game project

Go to the projects directory you created in Chapter 1 and make a new project using Cargo:

$ cargo new guessing_game

$ cd guessing_game

The first command, cargo new, takes the name of the project (guessing_game) as its first argument. The second command changes to the new project’s directory.

Look at the generated Cargo.toml file:

Cargo.toml

[package]

name = "guessing_game"

version = "0.1.0"

edition = "2024"

 

[dependencies]

As in Chapter 1, cargo new generates a “Hello, world!” program:

src/main.rs

fn main() {

    println!("Hello, world!");

}
