Chapter 2 · 2.3 Generating a Secret Number

A secret number from the rand crate

Next we generate a secret number for the user to guess. It should be different every time, so that the game is fun to play more than once, and between 1 and 100, so that the game isn’t too difficult. Rust doesn’t yet include random number functionality in its standard library, but the Rust team provides a rand crate (crates.io/crates/rand) with that functionality.

Increasing functionality with a crate

Remember that a crate is a collection of Rust source code files.

Definition 2.7 (Binary crate). A crate that is an executable, like the project we’ve been building.

Definition 2.8 (Library crate). A crate, like rand, containing code intended to be used in other programs; it can’t be executed on its own.

Coordinating external crates is where Cargo really shines. To use rand, first add it as a dependency: put the line shown next beneath the [dependencies] header in Cargo.toml. Specify rand exactly so, with this version number, or the code examples may not work.
