Chapter 2 · 2.4 Comparing the Guess to the Secret Number

parse, the u32 annotation, and failure

The parse method on strings converts a string to another type — here, from a string to a number. We tell Rust the exact number type we want with let guess: u32: the colon (:) after guess tells Rust we’ll annotate the variable’s type.

Rust has a few built-in number types; u32 is an unsigned, 32-bit integer, a good default choice for a small positive number (other number types: Chapter 3).

The u32 annotation and the comparison with secret_number mean Rust infers that secret_number should be a u32 as well. So now the comparison is between two values of the same type!

parse only works on characters that can logically be converted into numbers, so it can easily cause errors: a string such as A👍% cannot be converted to a number. Because it might fail, parse returns a Result, much as read_line does, and we treat it the same way, with expect:

  • Err (no number could be created from the string): expect crashes the game and prints the message we give it.
  • Ok (the conversion succeeded): expect returns the number that we want from the Ok value.
