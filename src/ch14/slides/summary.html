Chapter 14 · Summary

Chapter summary

Sharing code with Cargo and crates.io is part of what makes the Rust ecosystem useful for many different tasks. Rust’s standard library is small and stable, but crates are easy to share, use, and improve on a timeline different from that of the language. Don’t be shy about sharing code that’s useful to you on crates.io; it’s likely to be useful to someone else as well! In this chapter:

  • release profiles (dev, release) and [profile.*] overrides such as opt-level;
  • /// and //! doc comments, cargo doc, doc tests, and pub use re-exports for a convenient public API;
  • cargo login, required metadata, cargo publish (permanent) and cargo yank;
  • workspaces: one Cargo.lock and target, path dependencies, -p to run, test or publish one crate;
  • cargo install for binary crates, and cargo-something binaries as custom commands.

Remark. Next, Chapter 15 turns to smart pointers, such as Box<T>, Rc<T> and RefCell<T>.
