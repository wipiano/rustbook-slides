Chapter 14 · 14.4 Installing Binaries with cargo install

Example: installing ripgrep

Chapter 12 mentioned ripgrep, a Rust implementation of the grep tool for searching files. To install it, run:

$ cargo install ripgrep

    Updating crates.io index

  Downloaded ripgrep v14.1.1

  Downloaded 1 crate (213.6 KB) in 0.40s

  Installing ripgrep v14.1.1

--snip--

   Compiling grep v0.3.2

    Finished `release` profile [optimized + debuginfo] target(s) in 6.73s

  Installing ~/.cargo/bin/rg

   Installed package `ripgrep v14.1.1` (executable `rg`)

The second-to-last line of the output shows the location and the name of the installed binary, which for ripgrep is rg. As long as the installation directory is in your $PATH, you can then run rg --help and start using a faster, Rustier tool for searching files!
