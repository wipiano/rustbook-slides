Chapter 14 · 14.3 Cargo Workspaces

A path dependency between members

To have the adder package (our binary) depend on the add_one package (our library), first add a path dependency on add_one to adder/Cargo.toml:

adder/Cargo.toml

[dependencies]

add_one = { path = "../add_one" }

Cargo doesn’t assume that crates in a workspace will depend on each other, so we need to be explicit about the dependency relationships.

Next, use the add_one function (from the add_one crate) in the adder crate: change main in adder/src/main.rs to call it, as in Listing 14.7.

Listing 14.7: Using the add_one library crate from the adder crate — adder/src/main.rs

fn main() {

    let num = 10;

    println!("Hello, world! {num} plus one is {}!", add_one::add_one(num));

}
