Chapter 14 · 14.2 Publishing a Crate to Crates.io

Adding metadata: a unique crate name

Say you have a crate you want to publish. Before publishing, you need to add some metadata in the [package] section of the crate’s Cargo.toml file. First, your crate needs a unique name:

  • While working on a crate locally, you can name it whatever you like.
  • Crate names on crates.io, however, are allocated on a first-come, first-served basis: once a name is taken, no one else can publish a crate with that name.
  • Before attempting to publish, search for the name you want to use. If it has been used, find another name and edit the name field under [package] to use the new name for publishing:

Cargo.toml

[package]

name = "guessing_game"

Even with a unique name, running cargo publish at this point gives you a warning and then an error (next slide).
