Chapter 14 · 14.3 Cargo Workspaces

The workspace manifest, and the first member

In the add directory, create the Cargo.toml file that configures the entire workspace. It has no [package] section; instead it starts with a [workspace] section that lets us add members to the workspace. We also use the latest and greatest version of Cargo’s resolver algorithm by setting resolver to "3":

Cargo.toml

[workspace]

resolver = "3"

Next, create the adder binary crate by running cargo new within the add directory:

$ cargo new adder

     Created binary (application) `adder` package

      Adding `adder` as member of workspace at `file:///projects/add`
