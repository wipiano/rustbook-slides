Chapter 14 · 14.2 Publishing a Crate to Crates.io

Sharing code, and documentation comments

We’ve used packages from crates.io as dependencies of our projects, but you can also share your code with other people by publishing your own packages. The crate registry at crates.io distributes the source code of your packages, so it primarily hosts code that is open source.

Rust and Cargo have features that make your published package easier for people to find and use. We look at some of them first, and then at how to publish a package.

Making useful documentation comments

Accurately documenting your packages helps other users know how and when to use them, so it’s worth investing the time to write documentation. Chapter 3 showed ordinary comments with two slashes, //. Rust also has a particular kind of comment for documentation:

Definition 14.3 (Documentation comment). A comment written with three slashes, ///, instead of two, that supports Markdown notation for formatting the text and is placed just before the item it documents. It generates HTML documentation, which displays the documentation comments of public API items for programmers interested in knowing how to use your crate as opposed to how your crate is implemented.
