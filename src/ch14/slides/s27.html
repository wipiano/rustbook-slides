Chapter 14 · 14.3 Cargo Workspaces

Workspaces: several packages developed together

In Chapter 12 we built a package that included a binary crate and a library crate. As your project develops, the library crate might keep getting bigger, and you may want to split your package further into multiple library crates. Cargo’s workspaces help manage multiple related packages that are developed in tandem.

Definition 14.8 (Workspace). A set of packages that share the same Cargo.lock and output directory.

Creating a workspace

The example uses trivial code, to concentrate on the structure. There are multiple ways to structure a workspace; this is one common way: a workspace containing a binary and two libraries. The binary provides the main functionality and depends on the two libraries; one library provides an add_one function, the other an add_two function. Start with a new directory for the workspace:

$ mkdir add

$ cd add
