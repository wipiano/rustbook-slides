Using the re-exported items

The API documentation that cargo doc generates for this crate now lists and links the re-exports on the front page (the book’s Figure 14-4), making the PrimaryColor and SecondaryColor types and the mix function easier to find.

Users of the art crate can still see and use the internal structure from Listing 14.3, as demonstrated in Listing 14.4, or they can use the more convenient structure of Listing 14.5, as in Listing 14.6:

Listing 14.6: A program using the re-exported items from the art crate — src/main.rs

use art::PrimaryColor;

use art::mix;

 

fn main() {

    // --snip--

    let red = PrimaryColor::Red;

    let yellow = PrimaryColor::Yellow;

    mix(red, yellow);

}
