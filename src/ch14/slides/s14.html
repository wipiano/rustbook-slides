Why the internal structure hurts users

The author of the code in Listing 14.4 had to figure out that PrimaryColor is in the kinds module and mix is in the utils module.

  • The module structure of the art crate is more relevant to developers working on the crate than to those using it.
  • The internal structure contains no useful information for someone trying to understand how to use art; rather, it causes confusion.
  • Developers who use the crate have to figure out where to look, and must specify the module names in their use statements.

To remove the internal organization from the public API, we can modify the art crate code of Listing 14.3 to add pub use statements that re-export the items at the top level, as shown in Listing 14.5 on the next slide.
