Chapter 14 · 14.1 Customizing Builds with Release Profiles

Overriding a default setting

You override a default by adding a different value for it in Cargo.toml. For example, to use optimization level 1 in the development profile, add these two lines to the project’s Cargo.toml:

Cargo.toml

[profile.dev]

opt-level = 1

  • This overrides the default setting of 0.
  • Now cargo build uses the defaults for the dev profile plus our customization to opt-level.
  • Because opt-level is 1, Cargo applies more optimizations than the default, but not as many as in a release build.

Remark. For the full list of configuration options and defaults for each profile, see Cargo’s documentation (doc.rust-lang.org/cargo/reference/profiles.html).
