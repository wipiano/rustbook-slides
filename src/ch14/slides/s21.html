Chapter 14 · 14.2 Publishing a Crate to Crates.io

Adding a description and a license

  • description: just a sentence or two, because it appears with your crate in search results.
  • license: you need to give a license identifier value.

Definition 14.6 (License identifier value). A standard identifier naming a license; the Linux Foundation’s Software Package Data Exchange (SPDX, spdx.org/licenses) lists the identifiers you can use.

For example, to specify that you’ve licensed your crate using the MIT License, add the MIT identifier:

Cargo.toml

[package]

name = "guessing_game"

license = "MIT"

To use a license that doesn’t appear in the SPDX, place the text of that license in a file, include the file in your project, and then use license-file to specify the name of that file instead of using the license key.
