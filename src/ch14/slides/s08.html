Chapter 14 · 14.2 Publishing a Crate to Crates.io

Contained item comments: //!

Definition 14.4 (Contained item comment). A doc comment written //!. It adds documentation to the item that contains the comments rather than to the items following the comments. It is typically used inside the crate root file (src/lib.rs by convention) or inside a module, to document the crate or the module as a whole.

For example, to describe the purpose of the my_crate crate that contains the add_one function, we add documentation comments that start with //! to the beginning of the src/lib.rs file, as in Listing 14.2.

Listing 14.2: The documentation for the my_crate crate as a whole — src/lib.rs

//! # My Crate

//!

//! `my_crate` is a collection of utilities to make performing certain

//! calculations more convenient.

 

/// Adds one to the number given.

// --snip--
