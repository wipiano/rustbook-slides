Chapter 14 · 14.1 Customizing Builds with Release Profiles

Default settings and the opt-level setting

Cargo has default settings for each profile that apply when you haven’t explicitly added any [profile.*] sections to the project’s Cargo.toml. By adding [profile.*] sections for any profile you want to customize, you override any subset of the default settings. For example, these are the defaults for opt-level:

Cargo.toml

[profile.dev]

opt-level = 0

 

[profile.release]

opt-level = 3

Definition 14.2 (opt-level). The profile setting that controls the number of optimizations Rust will apply to your code, in a range of 0 to 3.

  • Applying more optimizations extends compiling time.
  • In development you compile often, so you want fewer optimizations to compile faster, even if the resulting code runs slower: the default opt-level for dev is 0.
  • For release it’s best to spend more time compiling: you compile in release mode once but run the program many times, so release mode trades longer compile time for faster code — the default for release is 3.
