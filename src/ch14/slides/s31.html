Chapter 14 · 14.3 Cargo Workspaces

Creating the second package in the workspace

Next, create another member package in the workspace, called add_one. Generate a new library crate named add_one:

$ cargo new add_one --lib

     Created library `add_one` package

      Adding `add_one` as member of workspace at `file:///projects/add`

The top-level Cargo.toml now includes the add_one path in the members list:

Cargo.toml

[workspace]

resolver = "3"

members = ["adder", "add_one"]
