Chapter 14 · 14.3 Cargo Workspaces

The members key, and the workspace layout

Running cargo new inside a workspace also automatically adds the newly created package to the members key in the [workspace] definition of the workspace Cargo.toml:

Cargo.toml

[workspace]

resolver = "3"

members = ["adder"]

At this point we can build the workspace by running cargo build. The files in the add directory should look like this:

├── Cargo.lock

├── Cargo.toml

├── adder

│   ├── Cargo.toml

│   └── src

│       └── main.rs

└── target
