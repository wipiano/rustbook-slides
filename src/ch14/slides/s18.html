Chapter 14 · 14.2 Publishing a Crate to Crates.io

Setting up a crates.io account

Before you can publish any crates, you need an account on crates.io and an API token:

  1. Visit the home page at crates.io and log in via a GitHub account. (A GitHub account is currently a requirement, but the site might support other ways of creating an account in the future.)
  2. Once logged in, visit your account settings at crates.io/me/ and retrieve your API key.
  3. Run the cargo login command and paste your API key when prompted:

$ cargo login

abcdefghijklmnopqrstuvwxyz012345

This informs Cargo of your API token and stores it locally in ~/.cargo/credentials.toml.

Remark. This token is a secret: do not share it with anyone else. If you do share it with anyone for any reason, revoke it and generate a new token on crates.io.
