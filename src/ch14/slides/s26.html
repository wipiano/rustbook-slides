Chapter 14 · 14.2 Publishing a Crate to Crates.io

Yanking and unyanking with cargo yank

To yank a version, run cargo yank in the directory of the crate you previously published, and specify which version to yank. For example, having published guessing_game version 1.0.1, we’d run this in the project directory for guessing_game:

$ cargo yank --vers 1.0.1

    Updating crates.io index

        Yank guessing_game@1.0.1

Adding --undo to the command undoes a yank and allows projects to start depending on that version again:

$ cargo yank --vers 1.0.1 --undo

    Updating crates.io index

      Unyank guessing_game@1.0.1

Remark. A yank does not delete any code. It cannot, for example, delete accidentally uploaded secrets. If that happens, you must reset those secrets immediately.
