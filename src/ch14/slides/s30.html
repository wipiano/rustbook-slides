Chapter 14 · 14.3 Cargo Workspaces

One shared target directory

  • The workspace has one target directory at the top level, into which the compiled artifacts are placed; the adder package doesn’t have its own target directory.
  • Even if we run cargo build from inside the adder directory, the compiled artifacts still end up in add/target rather than add/adder/target.

Why Cargo structures it this way

The crates in a workspace are meant to depend on each other. If each crate had its own target directory, each crate would have to recompile each of the other crates in the workspace to place the artifacts in its own target directory. By sharing one target directory, the crates avoid unnecessary rebuilding.
