Chapter 14

More About Cargo and Crates.io

So far we’ve used only the most basic features of Cargo to build, run, and test our code, but it can do a lot more. This chapter discusses some of its other, more advanced features, to show you how to:

  • customize your build through release profiles (14.1);
  • publish libraries on crates.io (14.2);
  • organize large projects with workspaces (14.3);
  • install binaries from crates.io (14.4);
  • extend Cargo using custom commands (14.5).

Cargo can do even more than this chapter covers; for a full explanation of all its features, see its documentation (doc.rust-lang.org/cargo).
