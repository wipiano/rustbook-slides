Chapter 11 · 11.2 Controlling How Tests Are Run

Keeping test runs fast, and a recap of the options

By controlling which tests run, you can make sure your cargo test results are returned quickly. When it makes sense to check the results of the ignored tests and you have time to wait, run cargo test -- --ignored instead. To run all tests whether they’re ignored or not, run cargo test -- --include-ignored.

Table 11.2: Ways to control a test run covered in this section

CommandEffect
cargo test -- --test-threads=1Run tests one at a time instead of in parallel
cargo test -- --show-outputAlso show what passing tests printed
cargo test one_hundredRun only tests whose name matches the string
cargo test addFilter: run every test whose name contains add
cargo test -- --ignoredRun only tests marked #[ignore]
cargo test -- --include-ignoredRun all tests, ignored or not
