Chapter 11 · 11.1 How to Write Tests

Placing #[should_panic]

Listing 11.8 (continued)

 

#[cfg(test)]

mod tests {

    use super::*;

 

    #[test]

    #[should_panic]

    fn greater_than_100() {

        Guess::new(200);

    }

}

We place the #[should_panic] attribute after the #[test] attribute and before the test function it applies to.

The test calls Guess::new(200): 200 is outside the range 1 to 100, so the code should panic — and the test should therefore pass.
