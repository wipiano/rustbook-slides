Calling common::setup from an integration test

tests/integration_test.rs

use adder::add_two;

 

mod common;

 

#[test]

fn it_adds_two() {

    common::setup();

 

    let result = add_two(2);

    assert_eq!(result, 4);

}

After we’ve created tests/common/mod.rs, we can use it from any of the integration test files as a module. Here the it_adds_two test calls the setup function.

The mod common; declaration is the same as the module declaration demonstrated in Listing 7-21. Then, in the test function, we can call the common::setup() function.
