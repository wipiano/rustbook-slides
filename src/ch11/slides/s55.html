Chapter 11 · 11.2 Controlling How Tests Are Run

Showing function output: captured by default

By default, if a test passes, Rust’s test library captures anything printed to standard output. If we call println! in a test and the test passes, we won’t see the println! output in the terminal; we’ll see only the line that indicates the test passed. If a test fails, we’ll see whatever was printed to standard output with the rest of the failure message.
