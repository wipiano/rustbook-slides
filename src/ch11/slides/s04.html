Chapter 11 · 11.1 How to Write Tests

The generated test module

Listing 11.1: The code generated automatically by cargo new — src/lib.rs

pub fn add(left: u64, right: u64) -> u64 {

    left + right

}

 

#[cfg(test)]

mod tests {

    use super::*;

 

    #[test]

    fn it_works() {

        let result = add(2, 2);

        assert_eq!(result, 4);

    }

}

The file starts with an example add function so that we have something to test.

Focus on it_works. The #[test] annotation tells the test runner to treat this function as a test. The tests module might also hold non-test functions that set up common scenarios or perform common operations, so we always need to indicate which functions are tests.

The body uses the assert_eq! macro to assert that result — the result of calling add with 2 and 2 — equals 4. This assertion is an example of the format of a typical test.
