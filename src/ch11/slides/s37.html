Checking for panics with should_panic

In addition to checking return values, it’s important to check that our code handles error conditions as we expect.

Example 11.6. The Guess type from Chapter 9, Listing 9-13: other code that uses Guess depends on the guarantee that Guess instances contain only values between 1 and 100. We can write a test that ensures that attempting to create a Guess instance with a value outside that range panics.

Definition 11.7 (should_panic). An attribute added to a test function: the test passes if the code inside the function panics, and fails if the code inside the function doesn’t panic.

Listing 11.8 (next two slides) shows a test that checks that the error conditions of Guess::new happen when we expect them to.
