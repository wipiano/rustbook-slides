Chapter 11 · 11.3 Test Organization

What cfg(test) means

Generated by Cargo for adder — src/lib.rs

pub fn add(left: u64, right: u64) -> u64 {

    left + right

}

 

#[cfg(test)]

mod tests {

    use super::*;

 

    #[test]

    fn it_works() {

        let result = add(2, 2);

        assert_eq!(result, 4);

    }

}

Recall the code Cargo generated for the new adder project in the first section of this chapter (left).

On the generated tests module, the attribute cfg stands for configuration: it tells Rust that the following item should only be included given a certain configuration option. Here the option is test, which Rust provides for compiling and running tests.

So Cargo compiles our test code only if we actively run the tests with cargo test — including any helper functions within this module, in addition to the functions annotated with #[test].
