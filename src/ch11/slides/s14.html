Testing can_hold with assert!

This is Listing 5-15 from Chapter 5, now in src/lib.rs. can_hold returns a Boolean, a perfect use case for assert!. The test creates a Rectangle of width 8 and height 7 and asserts that it can hold one of width 5 and height 1.

Listing 11.6: A test for can_hold that checks whether a larger rectangle can indeed hold a smaller rectangle — src/lib.rs

#[derive(Debug)]

struct Rectangle {

    width: u32,

    height: u32,

}

 

impl Rectangle {

    fn can_hold(&self, other: &Rectangle) -> bool {

        self.width > other.width && self.height > other.height

    }

}
