The Guess type under test

Listing 11.8: Testing that a condition will cause a panic! — src/lib.rs

pub struct Guess {

    value: i32,

}

 

impl Guess {

    pub fn new(value: i32) -> Guess {

        if value < 1 || value > 100 {

            panic!("Guess value must be between 1 and 100, got {value}.");

        }

 

        Guess { value }

    }

}

Guess::new panics whenever the value is below 1 or above 100. The test module follows on the next slide.
