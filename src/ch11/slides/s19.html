Introducing a bug into can_hold

Now let’s see what happens to our test results when we introduce a bug. Change the implementation of can_hold by replacing the greater-than sign (>) with a less-than sign (<) when it compares the widths:

src/lib.rs

// --snip--

impl Rectangle {

    fn can_hold(&self, other: &Rectangle) -> bool {

        self.width < other.width && self.height > other.height

    }

}

The Rectangle struct and both tests stay exactly as before. Running the tests now produces the output on the next two slides.
