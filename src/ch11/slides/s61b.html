Chapter 11 · 11.2 Controlling How Tests Are Run

Three tests with three different names

Listing 11.11 (continued)

    #[test]

    fn add_two_and_two() {

        let result = add_two(2);

        assert_eq!(result, 4);

    }

 

    #[test]

    fn add_three_and_two() {

        let result = add_two(3);

        assert_eq!(result, 5);

    }

 

    #[test]

    fn one_hundred() {

        let result = add_two(100);

        assert_eq!(result, 102);

    }

}

The three tests are named add_two_and_two, add_three_and_two and one_hundred. If we run the tests without passing any arguments, as we saw earlier, all the tests run in parallel (next slide).
