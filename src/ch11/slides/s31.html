Chapter 11 · 11.1 How to Write Tests

Why check contains, and a bug in greeting

src/lib.rs

pub fn greeting(name: &str) -> String {

    String::from("Hello!")

}

 

#[cfg(test)]

mod tests {

    use super::*;

 

    #[test]

    fn greeting_contains_name() {

        let result = greeting("Carol");

        assert!(result.contains("Carol"));

    }

}

The requirements for this program haven’t been agreed upon yet, and we’re pretty sure the Hello text at the beginning of the greeting will change. We don’t want to update the test when the requirements change, so instead of checking for exact equality with the value returned from greeting, we just assert that the output contains the text of the input parameter.

Now introduce a bug by changing greeting to exclude name (left), to see what the default test failure looks like.
