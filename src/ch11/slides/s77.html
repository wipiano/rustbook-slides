Chapter 11 · 11.3 Test Organization

Reading the integration test output

  • The first section, for the unit tests, is the same as we’ve been seeing: one line for each unit test (one named internal, added in Listing 11.12) and then a summary line for the unit tests.
  • The integration tests section starts with the line Running tests/integration_test.rs. Next comes a line for each test function in that integration test, and a summary line for its results just before the Doc-tests adder section starts.
  • Each integration test file has its own section, so if we add more files in the tests directory, there will be more integration test sections.

Running one integration test file

We can still run a particular integration test function by giving its name as an argument to cargo test. To run all the tests in a particular integration test file, use the --test argument of cargo test followed by the name of the file (next slide).
