A passing and a failing test that both print

Listing 11.10 (continued)

 

    #[test]

    fn this_test_will_pass() {

        let value = prints_and_returns_10(4);

        assert_eq!(value, 10);

    }

 

    #[test]

    fn this_test_will_fail() {

        let value = prints_and_returns_10(8);

        assert_eq!(value, 5);

    }

}

The first test prints I got the value 4 and passes; the second prints I got the value 8 and fails, because 10 is not 5.
