Making assert_eq! fail

src/lib.rs

pub fn add_two(a: u64) -> u64 {

    a + 3

}

 

#[cfg(test)]

mod tests {

    use super::*;

 

    #[test]

    fn it_adds_two() {

        let result = add_two(2);

        assert_eq!(result, 4);

    }

}

Let’s introduce a bug into our code to see what assert_eq! looks like when it fails.

Change the implementation of the add_two function to instead add 3, leaving the test unchanged.
