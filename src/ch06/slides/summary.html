Chapter 6 · Summary

Chapter summary

In this chapter we covered:

  • how to use enums to create custom types that can be one of a set of enumerated values;
  • how the standard library’s Option<T> type helps you use the type system to prevent errors;
  • when enum values have data inside them, how to use match or if let to extract and use those values, depending on how many cases you need to handle.

Your Rust programs can now express concepts in your domain using structs and enums. Creating custom types to use in your API ensures type safety: the compiler will make certain your functions only get values of the type each function expects.

Remark. Next, Chapter 7 turns to Rust’s modules, in order to provide a well-organized API to your users that is straightforward to use and only exposes exactly what your users will need.
