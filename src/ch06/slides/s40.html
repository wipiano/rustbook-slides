Staying on the “happy path”: a UsState helper

A common pattern is to perform some computation when a value is present and return a default value otherwise. Continuing with coins that hold a UsState value: if we wanted to say something funny depending on how old the state on the quarter was, we might introduce a method on UsState to check the age of a state, like so:

impl UsState {

    fn existed_in(&self, year: u16) -> bool {

        match self {

            UsState::Alabama => year >= 1819,

            UsState::Alaska => year >= 1959,

            // -- snip --

        }

    }

}
