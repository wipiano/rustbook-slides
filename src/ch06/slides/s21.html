Chapter 6 · 6.2 The match Control Flow Construct

Match arms and how a match executes

Definition 6.7 (Match arm). One branch of a match, with two parts: a pattern and some code, separated by the => operator. Each arm is separated from the next with a comma.

In Listing 6.3 the first arm has a pattern that is the value Coin::Penny, then the => operator that separates the pattern and the code to run. The code in this case is just the value 1.

When the match expression executes, it compares the resultant value against the pattern of each arm, in order. If a pattern matches the value, the code associated with that pattern is executed. If that pattern doesn’t match the value, execution continues to the next arm, much as in a coin-sorting machine. We can have as many arms as we need: in Listing 6.3, our match has four arms.

The code associated with each arm is an expression, and the resultant value of the expression in the matching arm is the value that gets returned for the entire match expression.
