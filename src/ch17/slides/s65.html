Handing back control without sleeping: yield_now

We don’t really want to sleep here, though: we want to make progress as fast as we can. We just need to hand back control to the runtime. We can do that directly, using the trpl::yield_now function. In Listing 17.17, we replace all those trpl::sleep calls with trpl::yield_now.

Table 17.3: Two ways to create an await point between slow calls

CallWhat it does
trpl::sleep(one_ms).awaitWaits on a timer before resuming; this sleep always waits at least a millisecond.
trpl::yield_now().awaitSimply hands control back to the runtime, with no timer involved.
