Chapter 17 · 17.2 Applying Concurrency with Async

Awaiting the task’s join handle

Listing 17.6 stops as soon as the for loop in the main async block finishes, because the task spawned by spawn_task is shut down when main ends. To run it all the way to completion, use a join handle to wait for the first task. With threads we used join to “block” until the thread was done; here we use await, because the task handle itself is a future. Its Output type is a Result, so we also unwrap it after awaiting it.
