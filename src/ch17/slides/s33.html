How Listing 17.6 runs

We set up main with trpl::block_on so that our top-level function can be async.

Remark. From here on, every example includes this exact same wrapping code with trpl::block_on in main, so the book often skips it, just as it does with main. Remember to include it in your code!

Then we write two loops within that block, each containing a trpl::sleep call that waits for half a second (500 milliseconds) before sending the next message. One loop is in the body of a trpl::spawn_task, the other in a top-level for loop. We add an await after the sleep calls.

This behaves similarly to the thread-based version — including that the messages may appear in a different order in your terminal:
