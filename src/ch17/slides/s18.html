Chapter 17 · 17.1 Futures and the Async Syntax

Walking through the transformed version

  • It uses the impl Trait syntax from Chapter 10’s “Traits as Parameters” section.
  • The returned value implements the Future trait with an associated type of Output. The Output type is Option<String>, the same as the original return type of the async fn version of page_title.
  • All of the code called in the body of the original function is wrapped in an async move block. Remember that blocks are expressions: this whole block is the expression returned from the function.
  • This async block produces a value with the type Option<String>, which matches the Output type in the return type — just like other blocks you have seen.
  • The new function body is an async move block because of how it uses the url parameter. (async versus async move is discussed much more later in the chapter.)

Now we can call page_title in main.
