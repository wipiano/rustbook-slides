Chapter 17 · Summary

Chapter summary

This isn’t the last of concurrency in this book: the Chapter 21 project applies these concepts more realistically and compares threading with tasks and futures more directly.

Whichever approach you choose, Rust gives you the tools to write safe, fast, concurrent code — for a high-throughput web server or an embedded OS. You learned:

  • futures, async and await, and running them with a runtime (trpl::block_on);
  • concurrency with tasks, join/join!, select, async channels and async move;
  • yielding control with await points, and composing futures into new abstractions such as timeout;
  • streams, and the Future, Stream, StreamExt, Pin and Unpin machinery underneath;
  • how futures, tasks and threads fit together, and when to use which.

Remark. Next, Chapter 18 talks about idiomatic ways to model problems and structure solutions as your Rust programs get bigger, and how Rust’s idioms relate to those you might know from object-oriented programming.
