Moving a self-referential value is unsafe

By default, any object that has a reference to itself is unsafe to move, because references always point to the actual memory address of whatever they refer to. If you move the data structure itself, those internal references are left pointing to the old location — which is now invalid. For one thing, its value will not be updated when you change the data structure. For another, more important, thing, the computer is now free to reuse that memory for other purposes! You could end up reading completely unrelated data later.
