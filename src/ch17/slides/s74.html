Chapter 17 · 17.3 Working with Any Number of Futures

Futures compose

Because futures compose with other futures, you can build really powerful tools using smaller async building blocks. For example, you can use this same approach to combine timeouts with retries, and in turn use those with operations such as network calls (like those in Listing 17.5).

In practice, you’ll usually work directly with async and await, and secondarily with functions such as select and macros such as join! to control how the outermost futures are executed.

Table 17.4: Building blocks for combining futures used so far

Building blockCompletes when
trpl::join(a, b)both futures are done; output is a tuple of both outputs
trpl::join!(a, b, c, …)all futures are done; their number is known at compile time
trpl::select(a, b)the first future finishes; output is Either::Left or Either::Right
