Chapter 17 · 17.1 Futures and the Async Syntax

From async and await to the Future trait

Some other languages, such as C# and JavaScript, also use async and await keywords for async programming. If you know them, you may notice significant differences in how Rust handles the syntax — for good reason, as we’ll see!

When writing async Rust, we use the async and await keywords most of the time. Rust compiles them into equivalent code using the Future trait, much as it compiles for loops into equivalent code using the Iterator trait:

Table 17.1: Syntax and the trait it compiles to

Syntax you writeCompiled into code using
for loopsthe Iterator trait
async and awaitthe Future trait

Because Rust provides the Future trait, you can also implement it for your own data types when you need to. Many functions in this chapter return types with their own implementations of Future. We return to the trait’s definition at the end of the chapter.
