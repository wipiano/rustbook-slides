Chapter 17 · 17.5 A Closer Look at the Traits for Async

StreamExt supplies next

Something very similar to Stream will likely end up in Rust’s standard library. Meanwhile, it’s part of the toolkit of most runtimes, so you can rely on it.

In Section 17.4 we didn’t use poll_next or Stream, but next and StreamExt.

We could work directly in terms of the poll_next API by hand-writing our own Stream state machines, just as we could work with futures directly via their poll method. Using await is much nicer, though, and the StreamExt trait supplies the next method so we can do just that.

use std::pin::Pin;

use std::task::{Context, Poll};

 

trait Stream {

    type Item;

    fn poll_next(

        self: Pin<&mut Self>,

        cx: &mut Context<'_>,

    ) -> Poll<Option<Self::Item>>;

}

 

trait StreamExt: Stream {

    async fn next(&mut self) -> Option<Self::Item>

    where

        Self: Unpin;

 

    // other methods...

}
