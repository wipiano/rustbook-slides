Chapter 17 · 17.5 A Closer Look at the Traits for Async

Futures can reference themselves

When we move a future — whether by pushing it into a data structure to use as an iterator with join_all or by returning it from a function — that actually means moving the state machine Rust creates for us.

And unlike most other types in Rust, the futures Rust creates for async blocks can end up with references to themselves in the fields of any given variant, as in the simplified illustration of Figure 17.4.

Definition 17.20 (Self-referential type). A data type that holds a reference to (part of) itself in one of its own fields.
