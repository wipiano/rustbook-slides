Chapter 17 · 17.2 Applying Concurrency with Async

Try it: variations on awaiting the futures

Starting from Listing 17.8, try some of these variations and see what they do:

  1. Remove the async block from around either or both of the loops.
  2. Await each async block immediately after defining it.
  3. Wrap only the first loop in an async block, and await the resulting future after the body of the second loop.

For an extra challenge, see if you can figure out what the output will be in each case before running the code!

Remark. Each variation changes where the await points are and which futures are polled together — the two things that decide whether work interleaves.
