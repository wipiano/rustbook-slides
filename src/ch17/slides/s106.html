Chapter 17 · 17.5 A Closer Look at the Traits for Async

Item and poll_next

The associated type Item is the type of the items produced: zero to many, as with Iterator, unlike Future’s always-single Output (even if it’s the unit type ()).

The method is called poll_next to make clear that it polls in the same way Future::poll does and produces a sequence of items in the same way Iterator::next does. Its return type combines Poll with Option: the outer type is Poll, because it has to be checked for readiness, just as a future does; the inner type is Option, because it needs to signal whether there are more messages, just as an iterator does.
