Chapter 17 · 17.2 Applying Concurrency with Async

async move: the program now shuts down

Listing 17.12: A revision of the code from Listing 17.11 that correctly shuts down when complete — src/main.rs

use std::time::Duration;

 

fn main() {

    trpl::block_on(async {

        let (tx, mut rx) = trpl::channel();

 

        let tx_fut = async move {

            // --snip--

        };

        let rx_fut = async {

            while let Some(value) = rx.recv().await {

                println!("received '{value}'");

            }

        };

 

        trpl::join(tx_fut, rx_fut).await;

    });

}

The only change from Listing 17.11 is async move on tx_fut (its body, elided here, is unchanged). tx is now owned by that block, so it is dropped when the block finishes; the channel closes, rx.recv yields None, and the loop ends.

When we run this version, it shuts down gracefully after the last message is sent and received. Next: sending data from more than one future.
