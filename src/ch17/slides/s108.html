Chapter 17 · 17.5 A Closer Look at the Traits for Async

The real next, and why the traits are separate

Remark. The actual definition we used earlier in the chapter looks slightly different, because it supports versions of Rust that did not yet support async functions in traits:

fn next(&mut self) -> Next<'_, Self> where Self: Unpin;

That Next type is a struct that implements Future and lets us name the lifetime of the reference to self with Next<'_, Self>, so that await can work with this method.

StreamExt is also the home of all the interesting methods available to use with streams. It is automatically implemented for every type that implements Stream, but the traits are defined separately so the community can iterate on convenience APIs without affecting the foundational trait.

In the trpl version of StreamExt, the trait not only defines next but also supplies a default implementation that correctly handles the details of calling Stream::poll_next. So even when you write your own streaming data type, you only have to implement Stream; anyone who uses your type can use StreamExt and its methods with it automatically.
