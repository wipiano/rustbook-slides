A slow, blocking operation

Listing 17.14: Using thread::sleep to simulate slow operations — src/main.rs

use std::{thread, time::Duration};

 

fn main() {

    trpl::block_on(async {

        // We will call `slow` here later

    });

}

 

fn slow(name: &str, ms: u64) {

    thread::sleep(Duration::from_millis(ms));

    println!("'{name}' ran for {ms}ms");

}

This code uses std::thread::sleep instead of trpl::sleep, so calling slow blocks the current thread for some number of milliseconds. We can use slow to stand in for real-world operations that are both long-running and blocking.
