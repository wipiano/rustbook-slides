Chapter 17 · 17.2 Applying Concurrency with Async

The second future, and joining them

Listing 17.8 (continued) — src/main.rs

 

        let fut2 = async {

            for i in 1..5 {

                println!("hi number {i} from the second task!");

                trpl::sleep(Duration::from_millis(500)).await;

            }

        };

 

        trpl::join(fut1, fut2).await;

    });

}

Neither loop is spawned as a task: each is just an async block, and the one future we await is the one trpl::join returns. When we run this, both futures run to completion.
