Chapter 17 · 17.6 Putting It All Together: Futures, Tasks, and Threads

Combining a thread with async

If you need both parallelism and concurrency, you don’t have to choose between threads and async: use them together freely, letting each play the part it’s best at. Listing 17.25 shows a fairly common example of this kind of mix in real-world Rust code.

Listing 17.25: Sending messages with blocking code in a thread and awaiting the messages in an async block — src/main.rs

use std::{thread, time::Duration};

 

fn main() {

    let (tx, mut rx) = trpl::channel();

 

    thread::spawn(move || {

        for i in 1..11 {

            tx.send(i).unwrap();

            thread::sleep(Duration::from_secs(1));

        }

    });

 

    trpl::block_on(async {

        while let Some(message) = rx.recv().await {

            println!("{message}");

        }

    });

}
