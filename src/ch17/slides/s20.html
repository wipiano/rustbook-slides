Chapter 17 · 17.1 Futures and the Async Syntax

main is not allowed to be async

Listing 17.3 tries to get the title for a single page. It follows the pattern for getting command line arguments from Chapter 12’s “Accepting Command Line Arguments” section, passes the URL argument to page_title, and awaits the result. Because the value produced by the future is an Option<String>, a match expression prints different messages depending on whether the page had a <title>.

Unfortunately, this code doesn’t compile. The only place we can use the await keyword is in async functions or blocks, and Rust won’t let us mark the special main function as async:
