Chapter 17 · 17.2 Applying Concurrency with Async

Who decides what runs next

Table 17.2: Scheduling with threads versus async Rust

ModelWho decides
ThreadsThe operating system decides which thread to check and how long to let it run.
Async RustThe runtime decides which task to check.

In practice, the details get complicated because an async runtime might use operating system threads under the hood as part of how it manages concurrency, so guaranteeing fairness can be more work for a runtime — but it’s still possible!

Runtimes don’t have to guarantee fairness for any given operation, and they often offer different APIs to let you choose whether or not you want fairness.
