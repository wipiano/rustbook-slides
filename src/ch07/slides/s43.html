Chapter 7 · 7.4 Bringing Paths into Scope with the use Keyword

The standard library is external too

The standard std library is also a crate that’s external to our package. Because the standard library is shipped with the Rust language, we don’t need to change Cargo.toml to include std. But we do need to refer to it with use to bring items from there into our package’s scope. For example, with HashMap:

use std::collections::HashMap;

This is an absolute path starting with std, the name of the standard library crate.
