Why enums and structs differ

Because we made the Appetizer enum public, we can use the Soup and Salad variants in eat_at_restaurant.

Table 7.2: What pub on a struct or an enum makes public

Itempub on the definitionWhy this default
structThe struct only; each field stays private unless marked pubStructs are often useful without their fields being public
enumThe enum and all of its variantsEnums aren’t very useful unless their variants are public

It would be annoying to annotate all enum variants with pub in every case, so the default for enum variants is to be public. Struct fields follow the general rule: everything is private by default unless annotated with pub.

Remark. One more pub situation involves the last feature, use: first use alone, then pub with use.
