Chapter 7 · 7.4 Bringing Paths into Scope with the use Keyword

Nesting at any level, with self

A nested path can be used at any level in a path, which is useful when combining two use statements that share a subpath.

Listing 7.19 has two use statements: one brings std::io into scope and one brings std::io::Write into scope.

Listing 7.19: Two use statements where one is a subpath of the other — src/lib.rs

use std::io;

use std::io::Write;

The common part of these two paths is std::io, and that’s the complete first path. To merge them into one use statement, use self in the nested path:

Listing 7.20: Combining the paths in Listing 7.19 into one use statement — src/lib.rs

use std::io::{self, Write};

This line brings std::io and std::io::Write into scope.
