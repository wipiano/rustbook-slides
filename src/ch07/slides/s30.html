Chapter 7 · 7.4 Bringing Paths into Scope with the use Keyword

Creating a shortcut with use

Writing out paths to call functions can feel inconvenient and repetitive: in Listing 7.7, every call to add_to_waitlist had to specify front_of_house and hosting too. Instead, we can create a shortcut to a path with the use keyword once and then use the shorter name everywhere else in the scope.

Example 7.14. use plus a path is like a symbolic link in the filesystem: after use crate::front_of_house::hosting in the crate root, hosting is a valid name there, as though the module had been defined in the crate root. Paths brought into scope with use also check privacy, like any other paths.

Listing 7.11: Bringing a module into scope with use — src/lib.rs

mod front_of_house {

    pub mod hosting {

        pub fn add_to_waitlist() {}

    }

}

 

use crate::front_of_house::hosting;

 

pub fn eat_at_restaurant() {

    hosting::add_to_waitlist();

}
