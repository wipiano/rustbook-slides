Chapter 7 · 7.4 Bringing Paths into Scope with the use Keyword

Re-exporting names with pub use

A name brought into scope with use is private to the scope into which we imported it. To let code outside that scope refer to the name as if it had been defined in that scope, combine pub and use.

Definition 7.16 (Re-exporting). Bringing an item into scope with pub use, which also makes that item available for others to bring into their scope.

Listing 7.17 is Listing 7.11 with use in the root module changed to pub use.

Listing 7.17: Making a name available for any code to use from a new scope with pub use — src/lib.rs

mod front_of_house {

    pub mod hosting {

        pub fn add_to_waitlist() {}

    }

}

 

pub use crate::front_of_house::hosting;

 

pub fn eat_at_restaurant() {

    hosting::add_to_waitlist();

}
