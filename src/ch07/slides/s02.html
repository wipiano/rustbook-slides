Chapter 7 · 7.1 Packages and Crates

Crate roots and packages

Definition 7.4 (Crate root). A source file that the Rust compiler starts from and that makes up the root module of your crate (modules are explained in 7.2).

Definition 7.5 (Package). A bundle of one or more crates that provides a set of functionality. A package contains a Cargo.toml file that describes how to build those crates.

Cargo itself is a package: it contains the binary crate for the command line tool you’ve been using to build your code, and also a library crate that the binary crate depends on. Other projects can depend on the Cargo library crate to use the same logic the Cargo command line tool uses.

Rules on what a package may contain:

  • as many binary crates as you like;
  • at most only one library crate;
  • at least one crate, whether that’s a library or binary crate.
