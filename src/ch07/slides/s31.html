Chapter 7 · 7.4 Bringing Paths into Scope with the use Keyword

A use shortcut applies only in its own scope

Listing 7.12: A use statement only applies in the scope it’s in. — src/lib.rs

mod front_of_house {

    pub mod hosting {

        pub fn add_to_waitlist() {}

    }

}

 

use crate::front_of_house::hosting;

 

mod customer {

    pub fn eat_at_restaurant() {

        hosting::add_to_waitlist();

    }

}

use only creates the shortcut for the particular scope in which the use occurs.

Listing 7.12 moves the eat_at_restaurant function into a new child module named customer. That is a different scope than the use statement, so the function body won’t compile.

The compiler error on the next slides shows that the shortcut no longer applies within the customer module.
