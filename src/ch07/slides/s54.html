Chapter 7 · 7.5 Separating Modules into Different Files

Same module tree, different files

We’ve moved each module’s code to a separate file, and the module tree remains the same. The function calls in eat_at_restaurant work without any modification, even though the definitions live in different files. This technique lets you move modules to new files as they grow in size.

The pub use crate::front_of_house::hosting statement in src/lib.rs hasn’t changed either, and use has no impact on what files are compiled as part of the crate. The mod keyword declares modules, and Rust looks in a file with the same name as the module for the code that goes into that module.
