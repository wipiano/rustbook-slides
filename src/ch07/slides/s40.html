Chapter 7 · 7.4 Bringing Paths into Scope with the use Keyword

Using external packages

The Chapter 2 guessing game used an external package called rand to get random numbers. To use rand in the project, we added this line to Cargo.toml:

Cargo.toml

rand = "0.10.1"

Adding rand as a dependency in Cargo.toml tells Cargo to download the rand package and any dependencies from crates.io and make rand available to our project.

Then, to bring rand definitions into the scope of our package, we added a use line starting with the name of the crate, rand, and listed the items we wanted to bring into scope. In “Generating a Random Number” (Chapter 2) we brought the items in the rand::prelude module into scope and called the rand::rng function — shown on the next two slides.
