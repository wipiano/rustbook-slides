Chapter 7 · 7.5 Separating Modules into Different Files

Extracting front_of_house into its own file

So far, every example defined multiple modules in one file. When modules get large, you might move their definitions to a separate file to make the code easier to navigate. Starting from Listing 7.17, we extract modules into files; here the crate root file is src/lib.rs, but the procedure also works with binary crates whose crate root file is src/main.rs.

First, extract front_of_house: remove the code inside its curly brackets, leaving only the mod front_of_house; declaration. This won’t compile until we create src/front_of_house.rs in Listing 7.22.

Listing 7.21: Declaring the front_of_house module whose body will be in src/front_of_house.rs — src/lib.rs

mod front_of_house;

 

pub use crate::front_of_house::hosting;

 

pub fn eat_at_restaurant() {

    hosting::add_to_waitlist();

}
