Chapter 7 · 7.3 Paths for Referring to an Item in the Module Tree

Starting relative paths with super

Definition 7.13 (super). A keyword at the start of a path that makes it a relative path beginning in the parent module, rather than the current module or the crate root — like starting a filesystem path with .. to go to the parent directory.

Listing 7.8: Calling a function using a relative path starting with super — src/lib.rs

fn deliver_order() {}

 

mod back_of_house {

    fn fix_incorrect_order() {

        cook_order();

        super::deliver_order();

    }

 

    fn cook_order() {}

}

Using super references an item we know is in the parent module, which makes rearranging the module tree easier when the module is closely related to the parent but the parent might be moved elsewhere someday.

A chef fixes an incorrect order and personally brings it out. From back_of_house, super goes to its parent — crate, the root — where deliver_order is found. Success!

back_of_house and deliver_order are likely to stay in the same relationship and get moved together, so super leaves fewer places to update if the code moves.
