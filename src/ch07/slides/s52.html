Chapter 7 · 7.5 Separating Modules into Different Files

Extracting a child module: hosting

Extracting hosting is a bit different, because hosting is a child module of front_of_house, not of the root module. Its file goes in a new directory named for its ancestors in the module tree, here src/front_of_house.

1. Change src/front_of_house.rs to contain only the declaration of the hosting module — src/front_of_house.rs

pub mod hosting;

2. Create a src/front_of_house directory and a hosting.rs file with the definitions made in the hosting module — src/front_of_house/hosting.rs

pub fn add_to_waitlist() {}

Remark. If we instead put hosting.rs in the src directory, the compiler would expect the hosting.rs code to be in a hosting module declared in the crate root, not declared as a child of the front_of_house module. The compiler’s rules for which files to check for which modules’ code mean the directories and files more closely match the module tree.
