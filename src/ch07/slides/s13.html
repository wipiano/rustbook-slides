Chapter 7 · 7.3 Paths for Referring to an Item in the Module Tree

Calling add_to_waitlist two ways

Listing 7.3: Calling the add_to_waitlist function using absolute and relative paths — src/lib.rs

mod front_of_house {

    mod hosting {

        fn add_to_waitlist() {}

    }

}

 

pub fn eat_at_restaurant() {

    // Absolute path

    crate::front_of_house::hosting::add_to_waitlist();

 

    // Relative path

    front_of_house::hosting::add_to_waitlist();

}

  • Listing 7.3 is Listing 7.1 with some of the modules and functions removed.
  • It shows two ways to call add_to_waitlist from a new function, eat_at_restaurant, defined in the crate root.
  • These paths are correct, but another problem remains that prevents this example from compiling as is — explained shortly.
  • eat_at_restaurant is part of our library crate’s public API, so we mark it with the pub keyword (more on pub later in this section).
