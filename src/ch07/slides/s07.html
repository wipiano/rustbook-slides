Chapter 7 · 7.2 Control Scope and Privacy with Modules

The rules in one crate: backyard

A binary crate named backyard illustrates these rules. The crate’s directory, also named backyard, contains these files and directories, and the crate root file is src/main.rs:

backyard

├── Cargo.lock

├── Cargo.toml

└── src

    ├── garden

    │   └── vegetables.rs

    ├── garden.rs

    └── main.rs

…so src/garden/vegetables.rs is included too:

#[derive(Debug)]

pub struct Asparagus {}

src/main.rs

use crate::garden::vegetables::Asparagus;

 

pub mod garden;

 

fn main() {

    let plant = Asparagus {};

    println!("I'm growing {plant:?}!");

}

pub mod garden; includes src/garden.rs, where pub mod vegetables;…

pub mod vegetables;
