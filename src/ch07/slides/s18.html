Exposing paths with pub: a public module

Listing 7.5: Declaring the hosting module as pub to use it from eat_at_restaurant — src/lib.rs

mod front_of_house {

    pub mod hosting {

        fn add_to_waitlist() {}

    }

}

 

// -- snip --

pub fn eat_at_restaurant() {

    // Absolute path

    crate::front_of_house::hosting::add_to_waitlist();

 

    // Relative path

    front_of_house::hosting::add_to_waitlist();

}

Back to the error in Listing 7.4 that told us the hosting module is private.

We want eat_at_restaurant in the parent module to have access to add_to_waitlist in the child module, so we mark the hosting module with the pub keyword.
