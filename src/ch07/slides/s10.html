Chapter 7 · 7.2 Control Scope and Privacy with Modules

The module tree

Earlier we said that src/main.rs and src/lib.rs are called crate roots. The reason for the name: the contents of either file form a module named crate at the root of the crate’s module structure.

Definition 7.7 (Module tree). The crate’s module structure: the modules and items nested inside one another, rooted under the implicit module named crate.

Listing 7.2 shows the module tree for the structure in Listing 7.1.
