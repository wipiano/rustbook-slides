Chapter 7 · 7.3 Paths for Referring to an Item in the Module Tree

Making structs public

Listing 7.9: A struct with some public fields and some private fields — src/lib.rs

mod back_of_house {

    pub struct Breakfast {

        pub toast: String,

        seasonal_fruit: String,

    }

 

    impl Breakfast {

        pub fn summer(toast: &str) -> Breakfast {

            Breakfast {

                toast: String::from(toast),

                seasonal_fruit: String::from("peaches"),

            }

        }

    }

}

pub before a struct definition makes the struct public, but its fields stay private. Each field can be made public or not on a case-by-case basis.

Here back_of_house::Breakfast is public, with a public toast field but a private seasonal_fruit field. In the restaurant, the customer picks the bread that comes with a meal, but the chef decides which fruit accompanies it based on what’s in season and in stock. The fruit changes quickly, so customers can’t choose it or even see which fruit they’ll get.
