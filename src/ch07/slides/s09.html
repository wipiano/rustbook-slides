Chapter 7 · 7.2 Control Scope and Privacy with Modules

Defining modules with mod

Listing 7.1: A front_of_house module containing other modules that then contain functions — src/lib.rs

mod front_of_house {

    mod hosting {

        fn add_to_waitlist() {}

 

        fn seat_at_table() {}

    }

 

    mod serving {

        fn take_order() {}

 

        fn serve_order() {}

 

        fn take_payment() {}

    }

}

This code, entered into src/lib.rs, is the front of house section.

  • A module is defined with the mod keyword followed by its name (here front_of_house); its body goes inside curly brackets.
  • Modules can hold other modules (here hosting and serving) and definitions of other items: structs, enums, constants, traits, and functions.
  • Grouping related definitions names why they’re related: readers navigate by group instead of reading every definition, and contributors know where to place new code to keep the program organized.
