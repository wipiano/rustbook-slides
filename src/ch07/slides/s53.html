Chapter 7 · 7.5 Separating Modules into Different Files

Alternate file paths

So far we’ve covered the most idiomatic file paths the Rust compiler uses, but Rust also supports an older style of file path.

Table 7.4: Where the compiler looks for a module’s code

ModuleIdiomatic (what we covered)Older style, still supported
front_of_house, declared in the crate rootsrc/front_of_house.rssrc/front_of_house/mod.rs
hosting, a submodule of front_of_housesrc/front_of_house/hosting.rssrc/front_of_house/hosting/mod.rs
  • Using both styles for the same module gives a compiler error.
  • Mixing both styles for different modules in the same project is allowed but might be confusing for people navigating your project.
  • The main downside of the mod.rs style: your project can end up with many files named mod.rs, which can get confusing when you have them open in your editor at the same time.
