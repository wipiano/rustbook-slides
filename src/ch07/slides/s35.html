Chapter 7 · 7.4 Bringing Paths into Scope with the use Keyword

Idiomatic use paths for structs and enums

On the other hand, when bringing in structs, enums, and other items with use, it’s idiomatic to specify the full path. Listing 7.14 shows the idiomatic way to bring the standard library’s HashMap struct into the scope of a binary crate.

Listing 7.14: Bringing HashMap into scope in an idiomatic way — src/main.rs

use std::collections::HashMap;

 

fn main() {

    let mut map = HashMap::new();

    map.insert(1, 2);

}

Remark. There’s no strong reason behind this idiom: it’s just the convention that has emerged, and folks have gotten used to reading and writing Rust code this way.
