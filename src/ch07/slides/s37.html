Chapter 7 · 7.4 Bringing Paths into Scope with the use Keyword

Providing new names with the as keyword

Listing 7.16: Renaming a type when it’s brought into scope with the as keyword — src/lib.rs

use std::fmt::Result;

use std::io::Result as IoResult;

 

fn function1() -> Result {

    // --snip--

    Ok(())

}

 

fn function2() -> IoResult<()> {

    // --snip--

    Ok(())

}

Another solution to bringing two types of the same name into the same scope with use: after the path, specify as and a new local name.

Definition 7.15 (Alias). A new local name for a type, given with as after the path in a use statement.

Listing 7.16 rewrites Listing 7.15: the second use chooses the new name IoResult for std::io::Result, which won’t conflict with the Result from std::fmt also in scope. Listings 7.15 and 7.16 are both considered idiomatic, so the choice is up to you!
