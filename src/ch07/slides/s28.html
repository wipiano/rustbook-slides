Chapter 7 · 7.3 Paths for Referring to an Item in the Module Tree

Constructors for private fields; public enums

Because back_of_house::Breakfast has a private field, the struct needs to provide a public associated function that constructs an instance of Breakfast (here named summer). Without such a function, we couldn’t create an instance of Breakfast in eat_at_restaurant, because we couldn’t set the value of the private seasonal_fruit field there.

In contrast, if we make an enum public, all of its variants are then public. We only need the pub before the enum keyword.

Listing 7.10: Designating an enum as public makes all its variants public. — src/lib.rs

mod back_of_house {

    pub enum Appetizer {

        Soup,

        Salad,

    }

}

 

pub fn eat_at_restaurant() {

    let order1 = back_of_house::Appetizer::Soup;

    let order2 = back_of_house::Appetizer::Salad;

}
