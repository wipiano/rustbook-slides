Chapter 21 · 21.1 Building a Single-Threaded Web Server

The 404 page

The response has a status line with status code 404 and the reason phrase NOT FOUND. Its body is the HTML in 404.html: create that file next to hello.html, with any HTML you want, or this example:

Listing 21.8: Sample content for the page to send back with any 404 response — 404.html

<!DOCTYPE html>

<html lang="en">

  <head>

    <meta charset="utf-8">

    <title>Hello!</title>

  </head>

  <body>

    <h1>Oops!</h1>

    <p>Sorry, I don't know what you're asking for.</p>

  </body>

</html>

Run again: 127.0.0.1:7878 returns hello.html; any other request, like 127.0.0.1:7878/foo, returns 404.html.
