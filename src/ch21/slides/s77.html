Chapter 21 · 21.3 Graceful Shutdown and Cleanup

A better alternative: Vec::drain

Vec::drain takes a range of items to remove and returns an iterator of them; the .. range removes every value. We update drop in src/lib.rs:

impl Drop for ThreadPool {

    fn drop(&mut self) {

        for worker in self.workers.drain(..) {

            println!("Shutting down worker {}", worker.id);

 

            worker.thread.join().unwrap();

        }

    }

}

This resolves the compiler error and requires no other changes to our code.

Remark. Because drop can be called when panicking, the unwrap could also panic and cause a double panic, which immediately crashes the program and ends any cleanup in progress. This is fine for an example program, but it isn’t recommended for production code.
