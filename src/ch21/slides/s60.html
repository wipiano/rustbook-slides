The code tries to pass receiver to multiple Worker instances. As in Chapter 16, Rust’s channel implementation is multiple producer, single consumer, so we can’t just clone the consuming end. Nor do we want to send a message multiple times to multiple consumers: we want one list of messages with multiple Worker instances, such that each message gets processed once.

Also, taking a job off the channel queue mutates the receiver, so the threads need a safe way to share and modify it; otherwise we might get race conditions (Chapter 16).
