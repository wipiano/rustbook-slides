Final Project: Building a Multithreaded Web Server

It’s been a long journey, but we’ve reached the end of the book. One last project, demonstrating concepts from the final chapters and recapping earlier lessons: a web server that says “Hello!” in a browser. The plan:

  1. Learn a bit about TCP and HTTP.
  2. Listen for TCP connections on a socket.
  3. Parse a small number of HTTP requests.
  4. Create a proper HTTP response.
  5. Improve the throughput of our server with a thread pool.
