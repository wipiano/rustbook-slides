Chapter 21 · 21.1 Building a Single-Threaded Web Server

A web server in about 40 lines

Awesome! We now have a simple web server in approximately 40 lines of Rust code. It:

  • listens for TCP connections on 127.0.0.1:7878;
  • reads the request line of each HTTP request;
  • responds to one request (GET / HTTP/1.1) with a page of content, hello.html, and status 200 OK;
  • responds to all other requests with a 404 response and 404.html.

Currently, our server runs in a single thread, meaning it can only serve one request at a time. Next we examine how that can be a problem by simulating some slow requests, and then fix it so that the server can handle multiple requests at once.
