Listing 21.2 (continued): Reading from the TcpStream and printing the data — src/main.rs

fn handle_connection(mut stream: TcpStream) {

    let buf_reader = BufReader::new(&stream);

    let http_request: Vec<_> = buf_reader

        .lines()

        .map(|result| result.unwrap())

        .take_while(|line| !line.is_empty())

        .collect();

 

    println!("Request: {http_request:#?}");

}

  • We bring std::io::BufReader and std::io::prelude into scope to get traits and types that let us read from and write to the stream; main’s loop now passes each stream to handle_connection.
  • handle_connection creates a new BufReader that wraps a reference to the stream. BufReader adds buffering by managing calls to the std::io::Read trait methods for us.
