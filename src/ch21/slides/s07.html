Chapter 21 · 21.1 Building a Single-Threaded Web Server

Pre-opened connections; then reading the request

Browsers also sometimes open multiple connections to the server without sending any requests, so that if they do later send requests, those happen more quickly. Our server sees each such connection, whether or not a request is sent over it. Many versions of Chrome-based browsers do this; you can disable that optimization with private browsing mode or by using a different browser.

The important factor is that we’ve successfully gotten a handle to a TCP connection!

Remark. Stop the program with ctrl-C when you’re done running a particular version of the code. Then restart it with cargo run after each set of code changes, to make sure you’re running the newest code.
