Writing the tiny response to the stream

In handle_connection, remove the println! that printed the request data and replace it:

Listing 21.3: Writing a tiny successful HTTP response to the stream — src/main.rs

fn handle_connection(mut stream: TcpStream) {

    let buf_reader = BufReader::new(&stream);

    let http_request: Vec<_> = buf_reader

        .lines()

        .map(|result| result.unwrap())

        .take_while(|line| !line.is_empty())

        .collect();

 

    let response = "HTTP/1.1 200 OK\r\n\r\n";

 

    stream.write_all(response.as_bytes()).unwrap();

}

The use lines and main are unchanged from Listing 21.2.
