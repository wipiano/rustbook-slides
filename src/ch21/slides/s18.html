Listing 21.4: A sample HTML file to return in a response — hello.html

<!DOCTYPE html>

<html lang="en">

  <head>

    <meta charset="utf-8">

    <title>Hello!</title>

  </head>

  <body>

    <h1>Hello!</h1>

    <p>Hi from Rust</p>

  </body>

</html>

This is a minimal HTML5 document with a heading and some text. To return it from the server when a request is received, we modify handle_connection as in Listing 21.5: read the HTML file, add it to the response as a body, and send it.
