Building the response with Content-Length

Listing 21.5 (continued): Sending the contents of hello.html as the body of the response — src/main.rs

    let status_line = "HTTP/1.1 200 OK";

    let contents = fs::read_to_string("hello.html").unwrap();

    let length = contents.len();

 

    let response =

        format!("{status_line}\r\nContent-Length: {length}\r\n\r\n{contents}");

 

    stream.write_all(response.as_bytes()).unwrap();

}

  • We added fs to the use statement to bring the standard library’s filesystem module into scope. Reading a file’s contents to a string should look familiar from the I/O project (Listing 12.4).
  • We use format! to add the file’s contents as the body of the success response. To ensure a valid HTTP response, we add the Content-Length header, set to the size of the response body — here, the size of hello.html.
