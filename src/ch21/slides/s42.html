Chapter 21 · 21.2 From a Single-Threaded to a Multithreaded Server

Learning from thread::spawn’s signature

The documentation shows:

pub fn spawn<F, T>(f: F) -> JoinHandle<T>

    where

        F: FnOnce() -> T,

        F: Send + 'static,

        T: Send + 'static,

  • We care about F; T relates to the return value, which doesn’t concern us.
  • spawn uses FnOnce as the trait bound on F. That’s probably what we want too, because we’ll eventually pass the argument we get in execute to spawn. And the thread running a request will execute that request’s closure only one time, which matches the Once in FnOnce.
  • F also has the trait bound Send and the lifetime bound 'static, both useful here: we need Send to transfer the closure from one thread to another, and 'static because we don’t know how long the thread will take to execute.
