On Ok(job) the Worker runs the job as before; on Err — the channel has been closed — it prints that it disconnected and breaks out of the loop, so its thread finishes.

To see this code in action, Listing 21.25 modifies main to accept only two requests before gracefully shutting down the server.

Remark. You wouldn’t want a real-world web server to shut down after serving only two requests. This code just demonstrates that the graceful shutdown and cleanup is in working order.
