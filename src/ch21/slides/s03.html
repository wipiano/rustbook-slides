Chapter 21 · 21.1 Building a Single-Threaded Web Server

Listening to the TCP connection

The server first needs to listen to a TCP connection; the standard library’s std::net module lets us do this. Make a new project in the usual fashion. Listing 21.1 listens at 127.0.0.1:7878 for incoming TCP streams and prints Connection established! for each.

$ cargo new hello

     Created binary (application) `hello` project

$ cd hello

Listing 21.1: Listening for incoming streams and printing a message when we receive a stream — src/main.rs

use std::net::TcpListener;

 

fn main() {

    let listener = TcpListener::bind("127.0.0.1:7878").unwrap();

 

    for stream in listener.incoming() {

        let stream = stream.unwrap();

 

        println!("Connection established!");

    }

}
