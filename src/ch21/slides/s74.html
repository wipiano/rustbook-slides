Implementing Drop on ThreadPool

When the pool is dropped, the threads should join to finish their work. First attempt (won’t quite work yet):

Listing 21.22: Joining each thread when the thread pool goes out of scope — src/lib.rs

impl Drop for ThreadPool {

    fn drop(&mut self) {

        for worker in &mut self.workers {

            println!("Shutting down worker {}", worker.id);

 

            worker.thread.join().unwrap();

        }

    }

}

We loop through each of the pool’s workers, using &mut because self is a mutable reference and we also need to be able to mutate worker. For each one, we print a message that this Worker is shutting down, then call join on its thread. If join fails, unwrap makes Rust panic and go into an ungraceful shutdown.
