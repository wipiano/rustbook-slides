Chapter 21 · 21.2 From a Single-Threaded to a Multithreaded Server

It compiles — but does nothing

$ cargo check

    Checking hello v0.1.0 (file:///projects/hello)

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.24s

It compiles! But if you try cargo run and make a request in the browser, you’ll see the errors in the browser that we saw at the beginning of the chapter. Our library isn’t actually calling the closure passed to execute yet!

Remark. A saying you might hear about languages with strict compilers, such as Haskell and Rust, is “If the code compiles, it works.” But this saying is not universally true. Our project compiles, but it does absolutely nothing! If we were building a real, complete project, this would be a good time to start writing unit tests to check that the code compiles and has the behavior we want.

Consider: what would be different here if we were going to execute a future instead of a closure?
