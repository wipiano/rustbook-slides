Validating the number of threads in new

We aren’t doing anything with the parameters to new and execute. Starting with new: we chose an unsigned type for size because a negative number of threads makes no sense. But a pool with zero threads also makes no sense, yet zero is a perfectly valid usize. So we check that size is greater than zero before returning a ThreadPool, making the program panic on zero with the assert! macro.
