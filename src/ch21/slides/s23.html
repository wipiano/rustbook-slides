  • We only look at the first line, so rather than reading the whole request into a vector, we call next to get the first item. The first unwrap handles the Option, stopping the program if the iterator has no items; the second handles the Result, like the unwrap in the map of Listing 21.2.
  • If request_line equals the request line of a GET request to /, the if block returns the contents of our HTML file.
  • Otherwise we’ve received some other request; the else block will respond to those in a moment.

Run it: 127.0.0.1:7878 gives the HTML in hello.html; any other request, such as 127.0.0.1:7878/something-else, gets a connection error like those from Listings 21.1 and 21.2.
