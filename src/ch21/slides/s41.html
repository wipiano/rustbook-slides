There’s no execute method yet. As decided, it should resemble thread::spawn: take the closure it’s given and give it to an idle thread in the pool to run.

So execute takes a closure as a parameter. Closures can be taken as parameters with three different traits — Fn, FnMut and FnOnce (Chapter 13) — so which one? We’ll end up doing something similar to the standard library’s thread::spawn, so we can look at the bounds its signature puts on its parameter.
