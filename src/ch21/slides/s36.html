Chapter 21 · 21.2 From a Single-Threaded to a Multithreaded Server

The ideal ThreadPool interface

Listing 21.12: Our ideal ThreadPool interface — src/main.rs

fn main() {

    let listener = TcpListener::bind("127.0.0.1:7878").unwrap();

    let pool = ThreadPool::new(4);

 

    for stream in listener.incoming() {

        let stream = stream.unwrap();

 

        pool.execute(|| {

            handle_connection(stream);

        });

    }

}

ThreadPool::new creates a pool with a configurable number of threads, here four. In the loop, pool.execute, like thread::spawn, takes a closure the pool should run for each stream, and must give it to a thread in the pool. This won’t compile yet, but we try so the compiler can guide us.
