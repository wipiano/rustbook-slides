Chapter 21 · 21.1 Building a Single-Threaded Web Server

HTML rendered — but for any request

Run this code with cargo run and load 127.0.0.1:7878 in your browser: you should see your HTML rendered!

Currently, we ignore the request data in http_request and send back the contents of the HTML file unconditionally. Requesting 127.0.0.1:7878/something-else still gets the same HTML response. Our server is very limited and does not do what most web servers do. We want to customize responses depending on the request, and only send back the HTML file for a well-formed request to /.

Validating the request and selectively responding

Let’s check that the browser is requesting / before returning the HTML file, and return an error if the browser requests anything else. Listing 21.6 modifies handle_connection: it checks the content of the request received against what we know a request for / looks like, and adds if and else blocks to treat requests differently.
