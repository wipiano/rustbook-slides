Chapter 21 · 21.1 Building a Single-Threaded Web Server

Writing a response: the format

To send data in response to a client request: responses have the following format.

HTTP-Version Status-Code Reason-Phrase CRLF

headers CRLF

message-body

Definition 21.9 (Status line). The first line of a response: the HTTP version used in the response, a numeric status code that summarizes the result of the request, and a reason phrase that gives a text description of the status code. After its CRLF come any headers, another CRLF sequence, and the body of the response.

Example 21.10. HTTP version 1.1, status code 200 (the standard success response), an OK reason phrase, no headers, and no body: a tiny successful HTTP response.

HTTP/1.1 200 OK\r\n\r\n
