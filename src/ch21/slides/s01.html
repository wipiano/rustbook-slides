Chapter 21 · Final Project

The goal, and two details before we start

Example 21.1. Figure 21-1, our final shared project: a web browser visiting 127.0.0.1:8080 shows a page with the heading “Hello!” and the text “Hi from Rust”.

  1. The method we’ll use won’t be the best way to build a web server with Rust. Community members have published production-ready crates on crates.io with more complete web server and thread pool implementations. Our intention is to help you learn, not to take the easy route. Because Rust is a systems programming language, we can choose the level of abstraction we work with, and go lower than is possible or practical in other languages.
  2. We will not use async and await. Building a thread pool is a big enough challenge on its own, without also building an async runtime! We will, however, note how async and await might apply to some of the same problems. As noted in Chapter 17, many async runtimes use thread pools for managing their work.

So we write the basic HTTP server and thread pool manually, to learn the general ideas and techniques behind the crates you might use in the future.
