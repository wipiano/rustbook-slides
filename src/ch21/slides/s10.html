Chapter 21 · 21.1 Building a Single-Threaded Web Server

Collecting the request lines

let http_request: Vec<_> = buf_reader

    .lines()

    .map(|result| result.unwrap())

    .take_while(|line| !line.is_empty())

    .collect();

  • The variable http_request collects the lines of the request the browser sends. The Vec<_> type annotation says we want to collect them in a vector.
  • BufReader implements the std::io::BufRead trait, whose lines method returns an iterator of Result<String, std::io::Error>, splitting the data at each newline byte.
  • To get each String, we map and unwrap each Result. It might be an error if the data isn’t valid UTF-8 or there was a problem reading from the stream. A production program should handle these errors more gracefully; we stop the program for simplicity.
  • The browser signals the end of an HTTP request by sending two newline characters in a row. So to get one request, we take lines until we get a line that is the empty string, then print the vector with pretty debug formatting to look at the instructions the browser sends.
