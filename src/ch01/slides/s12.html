Cargo: Rust’s build system and package manager

Definition 1.7 (Cargo). Rust’s build system and package manager. It builds your code, downloads the libraries your code depends on, and builds those libraries. The libraries your code needs are its dependencies.

  • Most Rustaceans use Cargo to manage their Rust projects, because it handles so many tasks for you.
  • The simplest programs, like “Hello, world!”, have no dependencies; built with Cargo, they would use only the part of Cargo that builds your code.
  • As programs grow more complex you add dependencies — and a project started with Cargo makes that much easier.
  • Because the vast majority of Rust projects use Cargo, the rest of the book assumes you do too. The official installers include it.

If you installed Rust some other way, check for Cargo. A version number means you have it; an error such as command not found means you should consult your installation method’s documentation to install Cargo separately.

$ cargo --version
