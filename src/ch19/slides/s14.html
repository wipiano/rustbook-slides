Chapter 19 · 19.2 Refutability: Whether a Pattern Might Fail to Match

Refutable and irrefutable patterns

You’ve now seen several ways to use patterns, but patterns don’t work the same in every place we can use them. In some places the patterns must be irrefutable; in others they can be refutable. Patterns come in these two forms:

Definition 19.4 (Irrefutable pattern). A pattern that will match for any possible value passed. Example: x in let x = 5; matches anything and therefore cannot fail to match.

Definition 19.5 (Refutable pattern). A pattern that can fail to match for some possible value. Example: Some(x) in if let Some(x) = a_value — if a_value is None rather than Some, the pattern will not match.

  • Function parameters, let statements, and for loops can only accept irrefutable patterns, because the program cannot do anything meaningful when values don’t match.
  • if let and while let expressions and the let...else statement accept refutable and irrefutable patterns, but the compiler warns against irrefutable ones: by definition they’re intended to handle possible failure — a conditional’s functionality is its ability to perform differently depending on success or failure.
