Listing 19.4: Using a while let loop to print values for as long as rx.recv() returns Ok

fn main() {

    let (tx, rx) = std::sync::mpsc::channel();

    std::thread::spawn(move || {

        for val in [1, 2, 3] {

            tx.send(val).unwrap();

        }

    });

 

    while let Ok(value) = rx.recv() {

        println!("{value}");

    }

}

Similar in construction to if let, the while let loop lets a while loop run for as long as a pattern continues to match. Listing 19.4 waits on messages sent between threads — checking a Result instead of an Option.

It prints 1, 2, and then 3. recv takes the first message out of the receiver side of the channel and returns Ok(value). In Chapter 16 we unwrapped the error directly, or used the receiver as an iterator in a for loop. We can also use while let: recv returns Ok each time a message arrives, as long as the sender exists, and then Err once the sender side disconnects.
