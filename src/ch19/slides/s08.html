If the user specifies a favorite color, that color is the background. If no favorite color is specified and today is Tuesday, the background is green. Otherwise, if the user specifies their age as a string and we can parse it as a number successfully, the color is purple or orange depending on the number. If none of these conditions apply, the background is blue.

This conditional structure lets us support complex requirements. With the hardcoded values here, the example prints Using purple as the background color.
