Matching two enums in one pattern

Listing 19.16 (continued)

 

    match msg {

        Message::ChangeColor(Color::Rgb(r, g, b)) => {

            println!("Change color to red {r}, green {g}, and blue {b}");

        }

        Message::ChangeColor(Color::Hsv(h, s, v)) => {

            println!("Change color to hue {h}, saturation {s}, value {v}");

        }

        _ => (),

    }

}

The first arm’s pattern matches a Message::ChangeColor variant that contains a Color::Rgb variant, then binds to the three inner i32 values. The second arm also matches Message::ChangeColor, but its inner enum matches Color::Hsv instead. We can specify these complex conditions in one match expression, even though two enums are involved.
