Chapter 19 · 19.2 Refutability: Whether a Pattern Might Fail to Match

Refutability in match arms

For this reason, match arms must use refutable patterns, except for the last arm, which should match any remaining values with an irrefutable pattern. Rust allows an irrefutable pattern in a match with only one arm, but this syntax isn’t particularly useful and could be replaced with a simpler let statement.

Example 19.6. Left: the first arm’s literal is refutable; the last arm’s _ is irrefutable and catches every remaining value. Right: a one-arm match with an irrefutable pattern does exactly what the let below it does.

match x {

    1 => println!("one"),

    _ => println!("anything"),

}

match (1, 2) {

    (a, b) => println!("{a} {b}"),

}

let (a, b) = (1, 2);
