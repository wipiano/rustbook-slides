Chapter 19 · 19.3 Pattern Syntax

_s binds and moves; _ never binds

Listing 19.21: An unused variable starting with an underscore still binds the value, which might take ownership of the value.

fn main() {

    let s = Some(String::from("Hello!"));

 

    if let Some(_s) = s {

        println!("found a string");

    }

 

    println!("{s:?}");

}

We get an error: the s value is still moved into _s, which prevents us from using s again.

Listing 19.22: Using an underscore does not bind the value.

fn main() {

    let s = Some(String::from("Hello!"));

 

    if let Some(_) = s {

        println!("found a string");

    }

 

    println!("{s:?}");

}

The underscore by itself never binds to the value, so this compiles without errors: we never bind s to anything, so it isn’t moved.
