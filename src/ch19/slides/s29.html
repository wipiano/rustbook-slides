Chapter 19 · 19.3 Pattern Syntax

Points on the x axis, the y axis, or neither

Listing 19.14 (continued) — src/main.rs

    match p {

        Point { x, y: 0 } => println!("On the x axis at {x}"),

        Point { x: 0, y } => println!("On the y axis at {y}"),

        Point { x, y } => {

            println!("On neither axis: ({x}, {y})");

        }

    }

}

  • The first arm matches any point on the x axis: its y field matches only if its value matches the literal 0. The pattern still creates an x variable that the arm’s code can use.
  • The second arm matches any point on the y axis — the x field must be 0 — and creates a variable y for the y field’s value.
  • The third arm specifies no literals, so it matches any other Point and creates variables for both the x and y fields.
