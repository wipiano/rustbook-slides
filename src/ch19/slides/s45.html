.. must be unambiguous

Using .. must be unambiguous. If it is unclear which values are intended for matching and which should be ignored, Rust gives us an error. Listing 19.25 uses .. ambiguously, so it will not compile.

Listing 19.25: An attempt to use .. in an ambiguous way — src/main.rs

fn main() {

    let numbers = (2, 4, 8, 16, 32);

 

    match numbers {

        (.., second, ..) => {

            println!("Some numbers: {second}")

        },

    }

}
