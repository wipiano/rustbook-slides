Chapter 19 · 19.1 All the Places Patterns Can Be Used

for loops

In a for loop, the value that directly follows the keyword for is a pattern: in for x in y, the x is the pattern. Listing 19.5 uses a pattern in a for loop to destructure, or break apart, a tuple as part of the loop.

Listing 19.5: Using a pattern in a for loop to destructure a tuple

fn main() {

    let v = vec!['a', 'b', 'c'];

 

    for (index, value) in v.iter().enumerate() {

        println!("{value} is at index {index}");

    }

}

We adapt the iterator with the enumerate method so that it produces a value and the index for that value, placed into a tuple. The output follows on the next slide.
