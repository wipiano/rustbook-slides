Chapter 19 · 19.3 Pattern Syntax

Matching named variables

Listing 19.11: A match expression with an arm that introduces a new variable which shadows an existing variable y — src/main.rs

fn main() {

    let x = Some(5);

    let y = 10;

 

    match x {

        Some(50) => println!("Got 50"),

        Some(y) => println!("Matched, y = {y}"),

        _ => println!("Default case, x = {x:?}"),

    }

 

    println!("at the end: x = {x:?}, y = {y}");

}

Named variables are irrefutable patterns that match any value, and we’ve used them many times. But there is a complication in match, if let, or while let expressions: each starts a new scope, so variables declared as part of a pattern inside them shadow those with the same name outside, as is the case with all variables.

In Listing 19.11, x has the value Some(5) and y the value 10; then we match on x. Look at the patterns in the arms and the println! at the end, and try to figure out what the code will print before reading further.
