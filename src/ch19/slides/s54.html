Chapter 19 · 19.3 Pattern Syntax

What each arm of Listing 19.29 can see

  • The second arm has only a range in its pattern, so its code has no variable containing the actual value of the id field. The value could have been 10, 11, or 12, but the code that goes with that pattern doesn’t know which: we haven’t saved the id value in a variable.
  • The last arm specifies a variable without a range, so the value is available in the arm’s code in a variable named id, thanks to the struct field shorthand syntax. But it applies no test to the value, as the first two arms did: any value would match this pattern.

Table 19.2: Testing versus binding in the three arms of Listing 19.29

Pattern for the id fieldTests the value?Value usable in the arm?
id: id @ 3..=7Yes, range 3..=7Yes, as id
id: 10..=12Yes, range 10..=12No
id (shorthand)No, any value matchesYes, as id

Using @ lets us test a value and save it in a variable within one pattern.
