Chapter 19 · 19.1 All the Places Patterns Can Be Used

Function parameters

Function parameters can also be patterns. Listing 19.6 declares a function foo taking one parameter x of type i32 — by now familiar.

Listing 19.6: A function signature using patterns in the parameters

fn foo(x: i32) {

    // code goes here

}

 

fn main() {}

The x part is a pattern! As with let, we could match a tuple in a function’s arguments to the pattern. Listing 19.7 splits the values in a tuple as we pass it to a function.

Listing 19.7: A function with parameters that destructure a tuple — src/main.rs

fn print_coordinates(&(x, y): &(i32, i32)) {

    println!("Current location: ({x}, {y})");

}

 

fn main() {

    let point = (3, 5);

    print_coordinates(&point);

}

This prints Current location: (3, 5). The values &(3, 5) match the pattern &(x, y), so x is 3 and y is 5.

Remark. Closures are similar to functions (Chapter 13), so closure parameter lists take patterns in the same way.
