Literal values inside struct patterns

We can also destructure with literal values as part of the struct pattern rather than creating variables for all the fields. This lets us test some of the fields for particular values while creating variables to destructure the other fields.

In Listing 19.14, a match separates Point values into three cases: points that lie directly on the x axis (true when y = 0), on the y axis (x = 0), or on neither axis.

Listing 19.14: Destructuring and matching literal values in one pattern — src/main.rs

    x: i32,

    y: i32,

}
