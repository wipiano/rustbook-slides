Chapter 19 · 19.2 Refutability: Whether a Pattern Might Fail to Match

The fix: let...else

If we have a refutable pattern where an irrefutable pattern is needed, we can fix it by changing the code that uses the pattern: instead of let, use let...else. Then, if the pattern doesn’t match, the code in the curly brackets handles the value. Listing 19.9 fixes Listing 19.8.

Listing 19.9: Using let...else and a block with refutable patterns instead of let

fn main() {

    let some_option_value: Option<i32> = None;

    let Some(x) = some_option_value else {

        return;

    };

}

Listing 19.10: Attempting to use an irrefutable pattern with let...else

fn main() {

    let x = 5 else {

        return;

    };

}

We’ve given the code an out! Listing 19.9 is perfectly valid, but it means we cannot use an irrefutable pattern without receiving a warning: if we give let...else a pattern that will always match, such as x in Listing 19.10, the compiler warns.
