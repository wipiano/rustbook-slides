Chapter 19 · 19.3 Pattern Syntax

Multiple patterns with | and ranges with ..=

Matching multiple patterns

In match expressions, | is the pattern or operator. Below, if x matches either value in the first arm, that arm’s code runs:

fn main() {

    let x = 1;

 

    match x {

        1 | 2 => println!("one or two"),

        3 => println!("three"),

        _ => println!("anything"),

    }

}

This code prints one or two.

Matching ranges of values

The ..= syntax matches an inclusive range of values. When a pattern matches any value within the range, that arm executes:

fn main() {

    let x = 5;

 

    match x {

        1..=5 => println!("one through five"),

        _ => println!("something else"),

    }

}
