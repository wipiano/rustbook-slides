Chapter 19 · 19.3 Pattern Syntax

Destructuring structs

Listing 19.12: Destructuring a struct’s fields into separate variables — src/main.rs

struct Point {

    x: i32,

    y: i32,

}

 

fn main() {

    let p = Point { x: 0, y: 7 };

 

    let Point { x: a, y: b } = p;

    assert_eq!(0, a);

    assert_eq!(7, b);

}

Patterns can also destructure structs, enums, and tuples, so that we can use different parts of these values. Let’s walk through each.

Listing 19.12 shows a Point struct with two fields, x and y, that we break apart using a pattern with a let statement.

The code creates variables a and b that match the values of the x and y fields of p. So the names of the variables in the pattern don’t have to match the struct’s field names.
