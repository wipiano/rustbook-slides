Using @ bindings

Definition 19.8 (@ binding). The at operator @ creates a variable that holds a value at the same time as we’re testing that value for a pattern match.

In Listing 19.29 we want to test that a Message::Hello id field is within the range 3..=7. We also want to bind the value to the variable id, so that we can use it in the code associated with the arm.
