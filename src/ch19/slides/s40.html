Chapter 19 · 19.3 Pattern Syntax

Underscores in one or several places

Listing 19.18 prints Can't overwrite an existing customized value and then setting is Some(5). The first arm doesn’t use the values inside either Some, but tests for both being Some; then it prints why setting_value isn’t changed. In all other cases (either is None), the second arm’s _ lets new_setting_value become setting_value.

Listing 19.19: Ignoring multiple parts of a tuple

fn main() {

    let numbers = (2, 4, 8, 16, 32);

 

    match numbers {

        (first, _, third, _, fifth) => {

            println!("Some numbers: {first}, {third}, {fifth}");

        }

    }

}

We can also use underscores in multiple places within one pattern to ignore particular values. Listing 19.19 ignores the second and fourth values in a tuple of five items.

It prints Some numbers: 2, 8, 32; the values 4 and 16 are ignored.
