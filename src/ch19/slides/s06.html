Fixing the mismatch; conditional if let expressions

To fix the error, we could ignore one or more of the tuple’s values using _ or .. (see “Ignoring Values in a Pattern”). If the problem is too many variables in the pattern, make the types match by removing variables so that the number of variables equals the number of elements in the tuple.

Conditional if let expressions

Chapter 6 used if let mainly as a shorter way to write the equivalent of a match that only matches one case. Optionally, if let can have a corresponding else containing code to run if the pattern doesn’t match.

You can also mix and match if let, else if, and else if let expressions. This gives more flexibility than a match, which can express only one value to compare with the patterns. And Rust doesn’t require the conditions in a series of if let, else if, and else if let arms to relate to each other.
