Chapter 19 · 19.3 Pattern Syntax

Adding conditionals with match guards

Definition 19.7 (Match guard). An additional if condition, specified after the pattern in a match arm, that must also match for that arm to be chosen. Match guards express more complex ideas than a pattern alone allows. They are only available in match expressions, not in if let or while let expressions.

The condition can use variables created in the pattern. In Listing 19.26 the first arm has the pattern Some(x) and the match guard if x % 2 == 0, which is true if the number is even.

Listing 19.26: Adding a match guard to a pattern

fn main() {

    let num = Some(4);

 

    match num {

        Some(x) if x % 2 == 0 => println!("The number {x} is even"),

        Some(x) => println!("The number {x} is odd"),

        None => (),

    }

}
