Chapter 19 · 19.3 Pattern Syntax

Matching literals

This section gathers all the syntax that is valid in patterns and discusses why and when you might want to use each one.

fn main() {

    let x = 1;

 

    match x {

        1 => println!("one"),

        2 => println!("two"),

        3 => println!("three"),

        _ => println!("anything"),

    }

}

As you saw in Chapter 6, you can match patterns against literals directly. The code on the left gives some examples.

It prints one, because the value in x is 1.

This syntax is useful when you want your code to take an action if it gets a particular concrete value.
