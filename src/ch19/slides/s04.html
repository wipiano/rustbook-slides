Chapter 19 · 19.1 All the Places Patterns Can Be Used

Destructuring a tuple with let

Listing 19.1: Using a pattern to destructure a tuple and create three variables at once

fn main() {

    let (x, y, z) = (1, 2, 3);

}

Rust compares the value (1, 2, 3) to the pattern (x, y, z) and sees that the value matches — the number of elements is the same in both — so it binds 1 to x, 2 to y, and 3 to z. Think of this tuple pattern as nesting three individual variable patterns inside it.

If the number of elements in the pattern doesn’t match the number in the tuple, the overall type won’t match and we get a compiler error. Listing 19.2 tries to destructure a three-element tuple into two variables:

Listing 19.2: Incorrectly constructing a pattern whose variables don’t match the number of elements in the tuple

fn main() {

    let (x, y) = (1, 2, 3);

}
