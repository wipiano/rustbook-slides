How the match guard decides

  • Listing 19.26 prints The number 4 is even. num matches the first arm’s pattern, because Some(4) matches Some(x). Then the match guard checks whether the remainder of dividing x by 2 equals 0; it does, so the first arm is selected.
  • Had num been Some(5), the first arm’s guard would be false (5 divided by 2 leaves 1, not 0). Rust would go to the second arm, which matches because it has no match guard and therefore matches any Some variant.

There is no way to express the if x % 2 == 0 condition within a pattern, so the match guard gives us that ability. The downside of this extra expressiveness: the compiler doesn’t try to check for exhaustiveness when match guard expressions are involved.
