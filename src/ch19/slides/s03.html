Chapter 19 · 19.1 All the Places Patterns Can Be Used

let statements

Before this chapter we had only explicitly discussed patterns with match and if let, but we’ve used patterns elsewhere too — including in let statements.

A straightforward variable assignment:

let x = 5;

More formally, a let statement looks like this:

let PATTERN = EXPRESSION;

Every time you’ve used a let statement like this, you’ve been using patterns, although you might not have realized it!

  • In let x = 5; the variable name in the PATTERN slot is just a particularly simple form of a pattern.
  • Rust compares the expression against the pattern and assigns any names it finds.
  • x is a pattern that means “bind what matches here to the variable x.” Because the name x is the whole pattern, it effectively means “bind everything to the variable x, whatever the value is.”
