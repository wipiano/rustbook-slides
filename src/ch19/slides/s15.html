Chapter 19 · 19.2 Refutability: Whether a Pattern Might Fail to Match

Which constructs accept which patterns

Table 19.1: Pattern refutability required by each construct

ConstructAccepts
Function parameters, let, forIrrefutable patterns only
if let, while let, let...elseRefutable and irrefutable (warning on irrefutable)
match armsRefutable arms; the last arm irrefutable

In general, you shouldn’t have to worry about the distinction. But you do need to be familiar with refutability so that you can respond when you see it in an error message: then you’ll need to change either the pattern or the construct you’re using the pattern with, depending on the intended behavior of the code.
