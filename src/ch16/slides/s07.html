Chapter 16 · 16.1 Using Threads to Run Code Simultaneously

Waiting for all threads to finish: JoinHandle<T>

Listing 16.1 has two problems:

  • most of the time, the spawned thread is stopped prematurely because the main thread ends;
  • because there is no guarantee on the order in which threads run, we can’t even guarantee that the spawned thread will get to run at all!

Both are fixed by saving the return value of thread::spawn in a variable. Its return type is JoinHandle<T>.

Definition 16.7 (JoinHandle<T>). The owned value returned by thread::spawn. Calling the join method on it waits for its thread to finish.

Listing 16.2 (next slides) uses the JoinHandle<T> of the thread created in Listing 16.1 and calls join to make sure the spawned thread finishes before main exits.
