Chapter 16 · 16.4 Extensible Concurrency with Send and Sync

Accessing from multiple threads: Sync

Definition 16.19 (Sync). The marker trait indicating that it is safe for the type implementing Sync to be referenced from multiple threads. In other words, any type T implements Sync if &T (an immutable reference to T) implements Send, meaning the reference can be sent safely to another thread.

Similar to Send, primitive types all implement Sync, and types composed entirely of types that implement Sync also implement Sync.
