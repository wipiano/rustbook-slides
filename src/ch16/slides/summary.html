Chapter 16 · Summary

Chapter summary

  • The Rust standard library provides channels for message passing and smart pointer types, such as Mutex<T> and Arc<T>, that are safe to use in concurrent contexts.
  • The type system and the borrow checker ensure that code using these solutions won’t end up with data races or invalid references. Once your code compiles, you can rest assured that it will happily run on multiple threads without the kinds of hard-to-track-down bugs common in other languages.
  • Because very little of how Rust handles concurrency is part of the language, many concurrency solutions are implemented as crates. These evolve more quickly than the standard library, so search online for the current, state-of-the-art crates to use in multithreaded situations.

Concurrent programming is no longer a concept to be afraid of: go forth and make your programs concurrent, fearlessly!

Remark. This isn’t the last you’ll see of concurrency: Chapter 17 focuses on async programming, and the project in Chapter 21 uses this chapter’s concepts in a more realistic situation than the smaller examples here.
