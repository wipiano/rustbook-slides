Chapter 16 · 16.2 Transfer Data Between Threads with Message Passing

Creating a channel

The goal is a program with one thread that generates values and sends them down a channel, and another thread that receives the values and prints them out. Simple values illustrate the feature; once you’re familiar with the technique, you could use channels for any threads that need to communicate with each other, such as a chat system or a system where many threads perform parts of a calculation and send the parts to one thread that aggregates the results.

Listing 16.6 creates a channel but does nothing with it. It won’t compile yet, because Rust can’t tell what type of values we want to send over the channel.

Listing 16.6: Creating a channel and assigning the two halves to tx and rx — src/main.rs

use std::sync::mpsc;

 

fn main() {

    let (tx, rx) = mpsc::channel();

}
