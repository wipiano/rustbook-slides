Chapter 16 · 16.4 Extensible Concurrency with Send and Sync

Concurrency in the language: the marker traits

Interestingly, almost every concurrency feature in this chapter so far has been part of the standard library, not the language. Your options for handling concurrency are not limited to the language or the standard library; you can write your own concurrency features or use those written by others.

However, among the key concurrency concepts embedded in the language rather than the standard library are the std::marker traits Send and Sync.

Transferring ownership between threads

Definition 16.18 (Send). The marker trait indicating that ownership of values of the type implementing Send can be transferred between threads.

Almost every Rust type implements Send, with some exceptions, including Rc<T>: if you cloned an Rc<T> value and tried to transfer ownership of the clone to another thread, both threads might update the reference count at the same time. So Rc<T> is implemented for single-threaded situations where you don’t want to pay the thread-safe performance penalty.
