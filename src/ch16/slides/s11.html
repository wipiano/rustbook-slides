Chapter 16 · 16.1 Using Threads to Run Code Simultaneously

What if join comes before the main loop?

Now see what happens when we instead move handle.join() before the for loop in main. The program starts as before:

src/main.rs

use std::thread;

use std::time::Duration;

 

fn main() {

    let handle = thread::spawn(|| {

        for i in 1..10 {

            println!("hi number {i} from the spawned thread!");

            thread::sleep(Duration::from_millis(1));

        }

    });
