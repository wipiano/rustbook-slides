Chapter 16 · 16.1 Using Threads to Run Code Simultaneously

join before the loop: the main thread waits first

src/main.rs (continued)

 

    handle.join().unwrap();

 

    for i in 1..5 {

        println!("hi number {i} from the main thread!");

        thread::sleep(Duration::from_millis(1));

    }

}

The main thread will wait for the spawned thread to finish and only then run its for loop, so the output won’t be interleaved anymore (next slide).
