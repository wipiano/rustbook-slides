Chapter 16 · 16.2 Transfer Data Between Threads with Message Passing

Two producers, one receiver

Before creating the first spawned thread, Listing 16.11 calls clone on the transmitter. This gives a new transmitter, passed to the first spawned thread; the original transmitter goes to a second spawned thread. That gives two threads, each sending different messages to the one receiver.

Output should look something like this:

Got: hi

Got: more

Got: from

Got: messages

Got: for

Got: the

Got: thread

Got: you

You might see the values in another order, depending on your system. This is what makes concurrency interesting as well as difficult.

Experiment with thread::sleep, giving it various values in the different threads: each run will be more nondeterministic and create different output each time.
