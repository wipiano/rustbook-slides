Chapter 16 · 16.1 Using Threads to Run Code Simultaneously

The 1:1 threading model, and thread::spawn

Rust attempts to mitigate the negative effects of threads, but multithreaded programming still takes careful thought and a code structure different from that of single-threaded programs.

Languages implement threads in a few different ways; many operating systems provide an API the language can call to create new threads.

Definition 16.6 (1:1 model). The model of thread implementation used by the Rust standard library, whereby a program uses one operating system thread per one language thread.

Crates implement other threading models with different trade-offs. (Rust’s async system, in the next chapter, is another approach to concurrency as well.)
