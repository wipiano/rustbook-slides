Chapter 16 · 16.3 Shared-State Concurrency

The API of Mutex<T>

To see how to use a mutex, start with a mutex in a single-threaded context:

Listing 16.12: Exploring the API of Mutex<T> in a single-threaded context for simplicity — src/main.rs

use std::sync::Mutex;

 

fn main() {

    let m = Mutex::new(5);

 

    {

        let mut num = m.lock().unwrap();

        *num = 6;

    }

 

    println!("m = {m:?}");

}
