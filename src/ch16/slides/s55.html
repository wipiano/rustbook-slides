Why not make everything atomic? Switching to Arc<T>

Why aren’t all primitive types atomic, and standard library types implemented with Arc<T> by default? Thread safety comes with a performance penalty that you only want to pay when you really need to. Operating on values within a single thread, code runs faster without the guarantees atomics provide.
