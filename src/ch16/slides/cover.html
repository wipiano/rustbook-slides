Chapter 16

Fearless Concurrency

Handling concurrent programming safely and efficiently is another of Rust’s major goals. Historically, programming with threads has been difficult and error-prone; Rust uses its ownership and type systems to turn many concurrency errors into compile-time errors. This chapter covers:

  • 16.1 Using Threads to Run Code Simultaneously — how to create threads to run multiple pieces of code at the same time
  • 16.2 Transfer Data Between Threads with Message Passing — message-passing concurrency, where channels send messages between threads
  • 16.3 Shared-State Concurrency — shared-state concurrency, where multiple threads have access to some piece of data
  • 16.4 Extensible Concurrency with Send and Sync — the traits that extend Rust’s concurrency guarantees to user-defined types as well as types provided by the standard library
