Comparing RefCell<T>/Rc<T> and Mutex<T>/Arc<T>

You might have noticed that counter is immutable, yet we could get a mutable reference to the value inside it: Mutex<T> provides interior mutability, as the Cell family does. In the same way RefCell<T> (Chapter 15) allowed mutating contents inside an Rc<T>, Mutex<T> is used to mutate contents inside an Arc<T>.
