Capturing a vector from the main thread

Listing 16.3: Attempting to use a vector created by the main thread in another thread — src/main.rs

use std::thread;

 

fn main() {

    let v = vec![1, 2, 3];

 

    let handle = thread::spawn(|| {

        println!("Here's a vector: {v:?}");

    });

 

    handle.join().unwrap();

}

The closure uses v, so it will capture v and make it part of the closure’s environment. Because thread::spawn runs this closure in a new thread, we should be able to access v inside that new thread. But when we compile this example, we get the error on the next two slides.
