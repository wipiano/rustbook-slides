Chapter 16 · 16.1 Using Threads to Run Code Simultaneously

Calling join blocks until the thread terminates

Listing 16.2 (continued) — src/main.rs

 

    for i in 1..5 {

        println!("hi number {i} from the main thread!");

        thread::sleep(Duration::from_millis(1));

    }

 

    handle.join().unwrap();

}

Calling join on the handle blocks the thread currently running until the thread represented by the handle terminates.

Definition 16.8 (Blocking). Blocking a thread means that thread is prevented from performing work or exiting.

Because the call to join comes after the main thread’s for loop, the main thread runs its loop first and only then waits for the spawned thread.
