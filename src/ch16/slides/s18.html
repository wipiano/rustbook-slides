Chapter 16 · 16.1 Using Threads to Run Code Simultaneously

Why borrowing v is rejected

Rust infers a borrow of v (println! only needs a reference), but it can’t tell how long the spawned thread will run, so it doesn’t know if the reference will always be valid. Listing 16.4 makes that more likely:

Listing 16.4: A thread with a closure that attempts to capture a reference to v from a main thread that drops v — src/main.rs

use std::thread;

 

fn main() {

    let v = vec![1, 2, 3];

 

    let handle = thread::spawn(|| {

        println!("Here's a vector: {v:?}");

    });

 

    drop(v); // oh no!

 

    handle.join().unwrap();

}
