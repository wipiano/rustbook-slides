Chapter 16 · 16.2 Transfer Data Between Threads with Message Passing

Sending a value from a spawned thread

Move the transmitter into a spawned thread and send one string to the main thread — like putting a rubber duck in the river upstream, or sending a chat message to another thread.

Listing 16.7: Moving tx to a spawned thread and sending "hi" — src/main.rs

use std::sync::mpsc;

use std::thread;

 

fn main() {

    let (tx, rx) = mpsc::channel();

 

    thread::spawn(move || {

        let val = String::from("hi");

        tx.send(val).unwrap();

    });

}

move moves tx into the closure: the spawned thread must own the transmitter to send through the channel.
