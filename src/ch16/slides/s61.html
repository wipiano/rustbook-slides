Chapter 16 · 16.4 Extensible Concurrency with Send and Sync

Send is checked by the type system

Rust’s type system and trait bounds ensure that you can never accidentally send an Rc<T> value across threads unsafely.

  • In Listing 16.14, trying to do so produced the error the trait `Send` is not implemented for `Rc<Mutex<i32>>`.
  • Switching to Arc<T>, which does implement Send, made the code compile (Listing 16.15).

Remark. Any type composed entirely of Send types is automatically marked as Send as well. Almost all primitive types are Send, aside from raw pointers, which Chapter 20 discusses.
