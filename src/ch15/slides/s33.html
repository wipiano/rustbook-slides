Chapter 15 · 15.3 Running Code on Cleanup with the Drop Trait

Implementing Drop on CustomSmartPointer

You specify the code to run when a value goes out of scope by implementing Drop, which requires one method named drop that takes a mutable reference to self. To see when Rust calls drop, we implement it with println! statements for now.

Listing 15.14’s CustomSmartPointer struct has only one custom functionality: it prints Dropping CustomSmartPointer! when the instance goes out of scope, showing when Rust runs drop.

Listing 15.14: A CustomSmartPointer struct that implements the Drop trait where we would put our cleanup code — src/main.rs

struct CustomSmartPointer {

    data: String,

}

 

impl Drop for CustomSmartPointer {

    fn drop(&mut self) {

        println!("Dropping CustomSmartPointer with data `{}`!", self.data);

    }

}
