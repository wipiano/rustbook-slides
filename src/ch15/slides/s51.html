Chapter 15 · 15.4 Rc<T>, the Reference-Counted Smart Pointer

Shared ownership, read-only

What we can’t see in this example: when b and then a go out of scope at the end of main, the count is 0, and the Rc<List> is cleaned up completely. Rc<T> allows a single value to have multiple owners, and the count ensures that the value remains valid as long as any of the owners still exist.

Via immutable references, Rc<T> lets you share data between multiple parts of your program for reading only. If it allowed multiple mutable references too, you might violate one of the borrowing rules of Chapter 4: multiple mutable borrows to the same place can cause data races and inconsistencies.

But being able to mutate data is very useful! The next section discusses the interior mutability pattern and the RefCell<T> type, which you can use together with an Rc<T> to work with this immutability restriction.
