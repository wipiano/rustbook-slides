Chapter 15 · 15.5 RefCell<T> and the Interior Mutability Pattern

What changed in Listing 15.22

  1. The sent_messages field is now of type RefCell<Vec<String>> instead of Vec<String>. The new function creates a new RefCell<Vec<String>> instance around the empty vector.
  2. In send, the first parameter is still an immutable borrow of self, which matches the trait definition. We call borrow_mut on the RefCell<Vec<String>> in self.sent_messages to get a mutable reference to the value inside it, the vector. Then we call push on that mutable reference to keep track of the messages sent during the test.
  3. In the assertion, to see how many items are in the inner vector, we call borrow on the RefCell<Vec<String>> to get an immutable reference to the vector.
