use crate::List::{Cons, Nil};

 

fn main() {

    let list = Cons(1, Cons(2, Cons(3, Nil)));

}

  • The first Cons value holds 1 and another List value.
  • That List value is another Cons value that holds 2 and another List value.
  • That one is one more Cons value that holds 3 and a List value, which is finally Nil, the non-recursive variant that signals the end of the list.
