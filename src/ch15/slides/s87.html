Chapter 15 · 15.6 Reference Cycles Can Leak Memory

Preventing reference cycles using Weak<T>

So far, calling Rc::clone increases the strong_count of an Rc<T> instance, and an Rc<T> instance is only cleaned up if its strong_count is 0. You can also create a weak reference to the value within an Rc<T> instance by calling Rc::downgrade and passing a reference to the Rc<T>.

Definition 15.18 (Strong reference). A reference through which you share ownership of an Rc<T> instance (counted in strong_count).

Definition 15.19 (Weak reference). A reference that doesn’t express an ownership relationship; its count doesn’t affect when an Rc<T> instance is cleaned up.

Weak references won’t cause a reference cycle, because any cycle involving some weak references will be broken once the strong reference count of the values involved is 0.
