Accessing the parent of leaf after the end of the scope gives None again. At the end of the program, the Rc<Node> in leaf has a strong count of 1 and a weak count of 0, because the variable leaf is again the only reference to the Rc<Node>.

All of the logic that manages the counts and value dropping is built into Rc<T> and Weak<T> and their implementations of the Drop trait. By specifying in the definition of Node that the relationship from a child to its parent should be a Weak<T> reference, parent nodes can point to child nodes and vice versa without creating a reference cycle and memory leaks.
