Chapter 15 · 15.2 Treating Smart Pointers Like Regular References

Defining our own smart pointer: MyBox<T>

We build a wrapper type similar to the standard library’s Box<T> to see how smart pointer types behave differently from references by default, then add the ability to use the dereference operator.

Remark. There’s one big difference between MyBox<T> and the real Box<T>: our version will not store its data on the heap. The example focuses on Deref, so where the data is actually stored is less important than the pointer-like behavior.

Box<T> is ultimately defined as a tuple struct with one element, so Listing 15.8 defines MyBox<T> the same way, with a new function to match Box::new.

Listing 15.8: Defining a MyBox<T> type — src/main.rs

struct MyBox<T>(T);

 

impl<T> MyBox<T> {

    fn new(x: T) -> MyBox<T> {

        MyBox(x)

    }

}

We define a struct named MyBox with a generic parameter T, because we want it to hold values of any type: a tuple struct with one element of type T. MyBox::new takes one parameter of type T and returns a MyBox instance that holds the value passed in.
