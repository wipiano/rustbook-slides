Chapter 15 · 15.5 RefCell<T> and the Interior Mutability Pattern

How Listing 15.24 works

  • We create a value that is an instance of Rc<RefCell<i32>> and store it in a variable named value, so we can access it directly later.
  • We create a List in a with a Cons variant that holds value. We clone value so that both a and value own the inner 5, rather than transferring ownership from value to a or having a borrow from value.
  • We wrap the list a in an Rc<T> so that lists b and c can both refer to a, as in Listing 15.18.
  • To add 10 to the value in value, we call borrow_mut on it. This uses automatic dereferencing (“Where’s the -> Operator?”, Chapter 5) to dereference the Rc<T> to the inner RefCell<T>. borrow_mut returns a RefMut<T> smart pointer; we use the dereference operator on it and change the inner value.
