Chapter 15 · 15.6 Reference Cycles Can Leak Memory

Building lists a and b

Listing 15.26 adds a main function that uses the definitions in Listing 15.25. It creates a list in a and a list in b that points to the list in a. Then it modifies the list in a to point to b, creating a reference cycle. println! statements along the way show the reference counts at various points.

Listing 15.26: Creating a reference cycle of two List values pointing to each other — src/main.rs

fn main() {

    let a = Rc::new(Cons(5, RefCell::new(Rc::new(Nil))));

 

    println!("a initial rc count = {}", Rc::strong_count(&a));

    println!("a next item = {:?}", a.tail());

 

    let b = Rc::new(Cons(10, RefCell::new(Rc::clone(&a))));

 

    println!("a rc count after b creation = {}", Rc::strong_count(&a));

    println!("b initial rc count = {}", Rc::strong_count(&b));

    println!("b next item = {:?}", b.tail());
