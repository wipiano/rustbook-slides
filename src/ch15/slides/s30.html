Chapter 15 · 15.2 Treating Smart Pointers Like Regular References

Deref coercion with mutable references

Just as the Deref trait overrides the * operator on immutable references, the DerefMut trait overrides the * operator on mutable references. Rust does deref coercion when it finds types and trait implementations in three cases:

Table 15.1: The three cases of deref coercion

CaseFrom → toWhen
1&T → &UT: Deref<Target=U>
2&mut T → &mut UT: DerefMut<Target=U>
3&mut T → &UT: Deref<Target=U>

The first two cases are the same except that the second implements mutability. The first says that if you have a &T, and T implements Deref to some type U, you can get a &U transparently. The second says the same deref coercion happens for mutable references.
