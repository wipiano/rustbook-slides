Chapter 15 · 15.1 Using Box<T> to Point to Data on the Heap

A List that uses Box<T> compiles

We change the definition of List from Listing 15.2 and its usage from Listing 15.3 to the code in Listing 15.5, which will compile.

Listing 15.5: The definition of List that uses Box<T> in order to have a known size — src/main.rs

enum List {

    Cons(i32, Box<List>),

    Nil,

}

 

use crate::List::{Cons, Nil};

 

fn main() {

    let list = Cons(1, Box::new(Cons(2, Box::new(Cons(3, Box::new(Nil))))));

}

The Cons variant needs the size of an i32 plus the space to store the box’s pointer data; Nil stores no values, so it needs less space on the stack. Any List value now takes up the size of an i32 plus the size of a box’s pointer data. The box breaks the infinite, recursive chain, so the compiler can figure out the size it needs to store a List value.
