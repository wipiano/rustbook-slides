Chapter 15 · 15.1 Using Box<T> to Point to Data on the Heap

Storing an i32 on the heap

Listing 15.1: Storing an i32 value on the heap using a box — src/main.rs

fn main() {

    let b = Box::new(5);

    println!("b = {b}");

}

The variable b has the value of a Box that points to the value 5, which is allocated on the heap. The program prints b = 5: we can access the data in the box similarly to how we would if it were on the stack. Just like any owned value, when a box goes out of scope, as b does at the end of main, it is deallocated — both the box (stored on the stack) and the data it points to (stored on the heap).

Putting a single value on the heap isn’t very useful, so you won’t use boxes by themselves this way very often; values like a single i32 are more appropriately stored on the stack, where they live by default.
