Chapter 15 · 15.6 Reference Cycles Can Leak Memory

A parent field of type RefCell<Weak<Node>>

Instead of Rc<T>, the type of parent uses Weak<T>, specifically a RefCell<Weak<Node>>. The Node struct definition now looks like this:

src/main.rs

use std::cell::RefCell;

use std::rc::{Rc, Weak};

 

#[derive(Debug)]

struct Node {

    value: i32,

    parent: RefCell<Weak<Node>>,

    children: RefCell<Vec<Rc<Node>>>,

}

A node can now refer to its parent node but doesn’t own its parent. Listing 15.28 updates main to use this new definition, so the leaf node has a way to refer to its parent, branch.
