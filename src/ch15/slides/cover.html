Chapter 15

Smart Pointers

Smart pointers are data structures that act like a pointer but carry extra metadata and capabilities. This chapter covers the most common ones in the standard library — Box<T>, Rc<T> and RefCell<T> — the Deref and Drop traits that make them work, the interior mutability pattern, and how reference cycles leak memory and how Weak<T> prevents them.
