Chapter 15 · 15.4 Rc<T>, the Reference-Counted Smart Pointer

When to use Rc<T>

We use Rc<T> when we want to allocate some data on the heap for multiple parts of our program to read, and we can’t determine at compile time which part will finish using the data last. If we knew which part would finish last, we could just make that part the data’s owner, and the normal ownership rules enforced at compile time would take effect.

Remark. Rc<T> is only for use in single-threaded scenarios. Chapter 16, on concurrency, covers how to do reference counting in multithreaded programs.
