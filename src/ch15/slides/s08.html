A first attempt at a cons list enum

Listing 15.2 contains an enum definition for a cons list. This code won’t compile yet, because the List type doesn’t have a known size, as we’ll demonstrate.

Listing 15.2: The first attempt at defining an enum to represent a cons list data structure of i32 values — src/main.rs

enum List {

    Cons(i32, List),

    Nil,

}

Remark. This cons list holds only i32 values, for the purposes of this example. It could have been implemented using generics (Chapter 10) to define a cons list type that could store values of any type.
