Chapter 15 · 15.6 Reference Cycles Can Leak Memory

After the link: leaf can reach its parent

The branch node also gets a new Weak<Node> reference in its parent field, because branch doesn’t have a parent node; leaf is still one of its children. With the Node instance in branch, we give leaf a Weak<Node> reference to its parent: borrow_mut on the RefCell<Weak<Node>> in leaf.parent, then Rc::downgrade to create a Weak<Node> reference to branch from the Rc<Node> in branch.

Printing the parent of leaf again now gives a Some variant holding branch: leaf can access its parent! Printing leaf also avoids the cycle that ended in a stack overflow in Listing 15.26; the Weak<Node> references are printed as (Weak):

leaf parent = Some(Node { value: 5, parent: RefCell { value: (Weak) },

children: RefCell { value: [Node { value: 3, parent: RefCell { value: (Weak) },

children: RefCell { value: [] } }] } })

The lack of infinite output indicates that this code didn’t create a reference cycle. We can also tell this from the values of Rc::strong_count and Rc::weak_count.
