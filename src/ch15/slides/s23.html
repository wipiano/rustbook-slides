Chapter 15 · 15.2 Treating Smart Pointers Like Regular References

Implementing the Deref trait

To implement a trait we provide implementations for its required methods (“Implementing a Trait on a Type,” Chapter 10). The standard library’s Deref trait requires one method named deref that borrows self and returns a reference to the inner data. Listing 15.10 adds an implementation of Deref to the definition of MyBox<T>.

Listing 15.10: Implementing Deref on MyBox<T> — src/main.rs

use std::ops::Deref;

 

impl<T> Deref for MyBox<T> {

    type Target = T;

 

    fn deref(&self) -> &Self::Target {

        &self.0

    }

}

The type Target = T; syntax defines an associated type for the Deref trait to use. Associated types are a slightly different way of declaring a generic parameter; you don’t need to worry about them for now — Chapter 20 covers them in more detail.
