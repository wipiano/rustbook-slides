Chapter 15 · 15.3 Running Code on Cleanup with the Drop Trait

Creating two CustomSmartPointers

Listing 15.14 (continued): main — src/main.rs

fn main() {

    let c = CustomSmartPointer {

        data: String::from("my stuff"),

    };

    let d = CustomSmartPointer {

        data: String::from("other stuff"),

    };

    println!("CustomSmartPointers created");

}

The Drop trait is included in the prelude, so we don’t need to bring it into scope. We implement Drop on CustomSmartPointer with a drop method that calls println!. The body of drop is where you would place any logic you want to run when an instance of your type goes out of scope; here we print text to demonstrate visually when Rust calls drop.
