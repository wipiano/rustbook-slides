Chapter 15 · 15.6 Reference Cycles Can Leak Memory

Visualizing strong_count and weak_count

To see how strong_count and weak_count of the Rc<Node> instances change, Listing 15.29 moves the creation of branch into a new inner scope, so we see what happens when branch is created and then dropped when it goes out of scope.

Listing 15.29: Creating branch in an inner scope and examining strong and weak reference counts — src/main.rs

fn main() {

    let leaf = Rc::new(Node {

        value: 3,

        parent: RefCell::new(Weak::new()),

        children: RefCell::new(vec![]),

    });

 

    println!(

        "leaf strong = {}, weak = {}",

        Rc::strong_count(&leaf),

        Rc::weak_count(&leaf),

    );
