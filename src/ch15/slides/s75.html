The code panicked with the message already borrowed: BorrowMutError: this is how RefCell<T> handles violations of the borrowing rules at runtime.

Catching borrowing errors at runtime means finding mistakes later — possibly not until production — plus a small runtime performance penalty for tracking borrows. But RefCell<T> let us write a mock that records the messages it sees while used where only immutable values are allowed: despite its trade-offs, more functionality than regular references provide.
