What we want to test, and the mock we need

The other important part: we want to test the behavior of set_value on LimitTracker. We can change what we pass in for the value parameter, but set_value doesn’t return anything for us to make assertions on. We want to be able to say: if we create a LimitTracker with something that implements Messenger and a particular value for max, the messenger is told to send the appropriate messages when we pass different numbers for value.

We need a mock object that, instead of sending an email or text message when we call send, only keeps track of the messages it’s told to send. Then we can create a new mock object, create a LimitTracker that uses it, call set_value on the LimitTracker, and check that the mock object has the messages we expect.
