Chapter 15 · 15.5 RefCell<T> and the Interior Mutability Pattern

Testing with mock objects

A practical example where RefCell<T> mutates an immutable value, and why that is useful. Sometimes during testing a programmer uses a type in place of another type, to observe particular behavior and assert that it’s implemented correctly.

Definition 15.13 (Test double). A placeholder type that stands in for another type when we’re running tests — in the sense of a stunt double in filmmaking, who steps in and substitutes for an actor to do a particularly tricky scene.

Definition 15.14 (Mock object). A specific type of test double that records what happens during a test, so that you can assert that the correct actions took place.

Rust doesn’t have objects in the same sense as other languages, and its standard library has no built-in mock object functionality as some other languages do. However, you can definitely create a struct that serves the same purposes as a mock object.
