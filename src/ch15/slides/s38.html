Chapter 15 · 15.3 Running Code on Cleanup with the Drop Trait

Destructors, double frees, and std::mem::drop

The error states that we’re not allowed to explicitly call drop. It uses the term destructor:

Definition 15.9 (Destructor). The general programming term for a function that cleans up an instance — analogous to a constructor, which creates an instance. The drop function in Rust is one particular destructor.

  • Rust doesn’t let us call drop explicitly because it would still automatically call drop on the value at the end of main. That would be a double free error: Rust trying to clean up the same value twice.
  • We can’t disable the automatic insertion of drop, and we can’t call the drop method explicitly. So, to force a value to be cleaned up early, we use the std::mem::drop function.
  • std::mem::drop is different from the drop method in the Drop trait: we call it passing as an argument the value we want to force-drop. It is in the prelude, so main can call it directly, as in Listing 15.16.
