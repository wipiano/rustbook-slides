Chapter 15 · 15.3 Running Code on Cleanup with the Drop Trait

The Drop trait

The second trait important to the smart pointer pattern is Drop, which lets you customize what happens when a value is about to go out of scope. You can implement Drop on any type, and that code can be used to release resources like files or network connections.

Drop is introduced with smart pointers because its functionality is almost always used when implementing one. For example, when a Box<T> is dropped, it deallocates the space on the heap that the box points to.

In some languages, for some types, the programmer must call code to free memory or resources every time they finish using an instance — for example file handles, sockets, and locks. If they forget, the system might become overloaded and crash. In Rust, you can specify that a particular bit of code be run whenever a value goes out of scope, and the compiler inserts this code automatically. So you don’t need to place cleanup code everywhere an instance of a particular type is finished with — and you still won’t leak resources!
