Chapter 15 · 15.2 Treating Smart Pointers Like Regular References

Deref coercion in action

We use MyBox<T> from Listing 15.8 and its Deref implementation from Listing 15.10. Listing 15.11 defines a function that has a string slice parameter.

Listing 15.11: A hello function that has the parameter name of type &str — src/main.rs

fn hello(name: &str) {

    println!("Hello, {name}!");

}

We can call hello with a string slice, such as hello("Rust");. Deref coercion makes it possible to call it with a reference to a value of type MyBox<String>, too:

Listing 15.12: Calling hello with a reference to a MyBox<String> value, which works because of deref coercion — src/main.rs

fn main() {

    let m = MyBox::new(String::from("Rust"));

    hello(&m);

}
