Boxes provide only the indirection and heap allocation; they have no other special capabilities, like those of the other smart pointer types — and none of the performance overhead those capabilities incur. So they are useful in cases like the cons list, where indirection is the only feature we need. Chapter 18 shows more use cases for boxes.

Box<T> is a smart pointer because it implements the Deref trait, which allows Box<T> values to be treated like references. When a Box<T> goes out of scope, the heap data it points to is cleaned up as well, because of its Drop implementation. These two traits matter even more for the other smart pointers in this chapter.
