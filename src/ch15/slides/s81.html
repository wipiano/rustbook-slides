Chapter 15 · 15.6 Reference Cycles Can Leak Memory

A List whose tail can be changed

Listing 15.25: A cons list definition that holds a RefCell<T> so that we can modify what a Cons variant is referring to — src/main.rs

use crate::List::{Cons, Nil};

use std::cell::RefCell;

use std::rc::Rc;

 

#[derive(Debug)]

enum List {

    Cons(i32, RefCell<Rc<List>>),

    Nil,

}

impl List {

    fn tail(&self) -> Option<&RefCell<Rc<List>>> {

        match self {

            Cons(_, item) => Some(item),

            Nil => None,

        }

    }

}

Another variation of the List definition from Listing 15.5: the second element in Cons is now RefCell<Rc<List>>. Instead of modifying the i32 value as in Listing 15.24, we want to modify the List value a Cons variant is pointing to. The tail method makes it convenient to access the second item if we have a Cons variant.
