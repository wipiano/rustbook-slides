Chapter 15 · 15.2 Treating Smart Pointers Like Regular References

Trying to dereference MyBox<T>

We add the main function of Listing 15.7 to Listing 15.8 and change it to use MyBox<T> instead of Box<T>. The code in Listing 15.9 won’t compile, because Rust doesn’t know how to dereference MyBox.

Listing 15.9: Attempting to use MyBox<T> in the same way we used references and Box<T> — src/main.rs

struct MyBox<T>(T);

 

impl<T> MyBox<T> {

    fn new(x: T) -> MyBox<T> {

        MyBox(x)

    }

}

 

fn main() {

    let x = 5;

    let y = MyBox::new(x);

 

    assert_eq!(5, x);

    assert_eq!(5, *y);

}

The two panels are one file: the definitions (left) followed by main (right).
