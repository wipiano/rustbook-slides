Why a recursive List has infinite size

Contrast the recursive List of Listing 15.2. The compiler looks at the Cons variant, which holds an i32 and a List, so Cons needs the size of an i32 plus the size of a List. To find the size of List, it looks at the variants again, starting with Cons, which holds an i32 and a List — and this process continues infinitely, as Figure 15.1 shows.
