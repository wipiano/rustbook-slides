Chapter 15 · 15.2 Treating Smart Pointers Like Regular References

Following the reference to the value

A regular reference is a type of pointer; think of a pointer as an arrow to a value stored somewhere else. Listing 15.6 creates a reference to an i32 and uses the dereference operator to follow it to the value.

Listing 15.6: Using the dereference operator to follow a reference to an i32 value — src/main.rs

fn main() {

    let x = 5;

    let y = &x;

 

    assert_eq!(5, x);

    assert_eq!(5, *y);

}

x holds the i32 value 5, and y is a reference to x. We can assert that x equals 5; but to make an assertion about the value in y, we must use *y to follow the reference to the value it points to (hence, dereference), so the compiler can compare the actual value with 5.
