Chapter 15 · 15.5 RefCell<T> and the Interior Mutability Pattern

Interior mutability to the rescue

We can’t modify the MockMessenger to keep track of the messages, because the send method takes an immutable reference to self.

We also can’t take the error text’s suggestion to use &mut self in both the impl method and the trait definition: we do not want to change the Messenger trait solely for the sake of testing. Instead, we need a way to make our test code work correctly with our existing design.

Example 15.15. This is a situation in which interior mutability can help! We store sent_messages within a RefCell<T>; then the send method — still taking &self — is able to modify sent_messages to store the messages we’ve seen. Listing 15.22 (next two slides) shows what that looks like.
