Chapter 15 · 15.2 Treating Smart Pointers Like Regular References

What deref coercion saves us from writing

In Listing 15.12, &m is a reference to a MyBox<String>. Because MyBox<T> implements Deref (Listing 15.10), Rust can turn &MyBox<String> into &String by calling deref. The standard library implements Deref on String to return a string slice (see the API documentation for Deref), so Rust calls deref again to turn &String into &str, which matches the definition of hello.

Without deref coercion, we would have to write the code in Listing 15.13 to call hello with a value of type &MyBox<String>.

Listing 15.13: The code we would have to write if Rust didn’t have deref coercion — src/main.rs

fn main() {

    let m = MyBox::new(String::from("Rust"));

    hello(&(*m)[..]);

}
