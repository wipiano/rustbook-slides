Chapter 15 · 15.6 Reference Cycles Can Leak Memory

Creating the cycle, and the counts it leaves

We modify a so that it points to b instead of Nil, creating a cycle: the tail method gets a reference to the RefCell<Rc<List>> in a, which we put in link. Then borrow_mut on the RefCell<Rc<List>> changes the value inside from an Rc<List> that holds Nil to the Rc<List> in b.
