Chapter 15 · 15.2 Treating Smart Pointers Like Regular References

Reading Listing 15.13, and the cost of coercion

  • (*m) dereferences the MyBox<String> into a String.
  • The & and [..] then take a string slice of the String that is equal to the whole string, to match the signature of hello.

This code without deref coercions is harder to read, write, and understand with all of these symbols involved. Deref coercion lets Rust handle these conversions for us automatically.

Example 15.8. The coercion chain behind hello(&m): &MyBox<String> → (MyBox’s deref) → &String → (String’s deref) → &str, the parameter type of hello. Two calls to Deref::deref are inserted.

When the Deref trait is defined for the types involved, Rust analyzes the types and uses Deref::deref as many times as necessary to get a reference that matches the parameter’s type. The number of insertions is resolved at compile time, so there is no runtime penalty for taking advantage of deref coercion!
