The scenario: a quota-tracking library

We’ll create a library that tracks a value against a maximum value and sends messages based on how close to the maximum the current value is. It could be used, for example, to keep track of a user’s quota for the number of API calls they’re allowed to make.

  • The library only provides the functionality of tracking how close to the maximum a value is, and what the messages should be at what times.
  • Applications that use it are expected to provide the mechanism for sending the messages: show the message to the user directly, send an email, send a text message, or something else. The library doesn’t need to know that detail.
  • All it needs is something that implements a trait we provide, called Messenger.
