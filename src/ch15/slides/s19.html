Chapter 15 · 15.2 Treating Smart Pointers Like Regular References

Using Box<T> like a reference

Rewriting Listing 15.6 to use a Box<T> instead of a reference: the dereference operator on the box works the same way as on the reference.

Listing 15.7: Using the dereference operator on a Box<i32> — src/main.rs

fn main() {

    let x = 5;

    let y = Box::new(x);

 

    assert_eq!(5, x);

    assert_eq!(5, *y);

}

The main difference from Listing 15.6: y is now an instance of a box pointing to a copied value of x, rather than a reference pointing to the value of x. In the last assertion we use the dereference operator to follow the box’s pointer in the same way we did when y was a reference.
