Chapter 15 · 15.2 Treating Smart Pointers Like Regular References

Customizing * with the Deref trait

Definition 15.6 (Dereference operator). The operator * (not to be confused with the multiplication or glob operator), which follows a reference to the value it points to.

Implementing the Deref trait lets you customize the behavior of the dereference operator. By implementing Deref so that a smart pointer can be treated like a regular reference, you can write code that operates on references and use that code with smart pointers too.

The plan for this section:

  1. See how the dereference operator works with regular references.
  2. Define a custom type that behaves like Box<T>, and see why the dereference operator doesn’t work like a reference on it.
  3. Implement Deref so the smart pointer works in ways similar to references.
  4. Look at Rust’s deref coercion feature and how it lets us work with either references or smart pointers.
