Chapter 15 · 15.5 RefCell<T> and the Interior Mutability Pattern

How the mock and the test work

  • MockMessenger has a sent_messages field, a Vec of String values, to keep track of the messages it’s told to send.
  • The associated function new conveniently creates MockMessenger values that start with an empty list of messages.
  • We implement Messenger for MockMessenger so we can give one to a LimitTracker. Its send takes the message passed in and stores it in sent_messages.

The test checks what happens when the LimitTracker is told to set value to more than 75 percent of max. We create a new MockMessenger (empty list of messages), then a new LimitTracker given a reference to it and a max of 100. We call set_value with 80, more than 75 percent of 100, then assert that the mock’s list of messages now has one message in it.
