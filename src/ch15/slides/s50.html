Chapter 15 · 15.4 Rc<T>, the Reference-Counted Smart Pointer

Watching the count go up and down

Listing 15.19 prints the following:

$ cargo run

   Compiling cons-list v0.1.0 (file:///projects/cons-list)

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.45s

     Running `target/debug/cons-list`

count after creating a = 1

count after creating b = 2

count after creating c = 3

count after c goes out of scope = 2

  • The Rc<List> in a has an initial reference count of 1; each time we call clone, the count goes up by 1.
  • When c goes out of scope, the count goes down by 1. No function call is needed to decrease it, unlike the Rc::clone call that increases it: the Drop implementation decreases the reference count automatically when an Rc<T> value goes out of scope.
