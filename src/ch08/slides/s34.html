Chapter 8 · 8.2 Storing UTF-8 Encoded Text with Strings

Iterating over strings: chars and bytes

Use caution when creating string slices with ranges, because doing so can crash your program. The best way to operate on pieces of strings is to be explicit about whether you want characters or bytes.

For individual Unicode scalar values, use chars. On “Зд” it separates out and returns two values of type char; iterate over the result to access each one:

for c in "Зд".chars() {

    println!("{c}");

}

This code prints:

З

д

Alternatively, the bytes method returns each raw byte, which might be appropriate for your domain:

for b in "Зд".bytes() {

    println!("{b}");

}

This prints the 4 bytes that make up this string:

208

151

208

180
