Chapter 8 · 8.1 Storing Lists of Values with Vectors

Vectors, and creating an empty one

The first collection type is Vec<T>, also known as a vector. Vectors are useful when you have a list of items, such as the lines of text in a file or the prices of items in a shopping cart.

Definition 8.1 (Vector). Vec<T>: a collection that stores more than one value in a single data structure, putting all the values next to each other in memory. A vector can only store values of the same type.

To create a new, empty vector, call the Vec::new function, as shown in Listing 8.1.

Listing 8.1: Creating a new, empty vector to hold values of type i32

fn main() {

    let v: Vec<i32> = Vec::new();

}
