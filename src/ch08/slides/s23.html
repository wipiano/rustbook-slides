Concatenating with the + operator

Often you’ll want to combine two existing strings. One way is the + operator, as shown in Listing 8.18.

Listing 8.18: Using the + operator to combine two String values into a new String value

fn main() {

    let s1 = String::from("Hello, ");

    let s2 = String::from("world!");

    let s3 = s1 + &s2; // note s1 has been moved here and can no longer be used

}

The string s3 will contain Hello, world!. Why s1 is no longer valid after the addition, and why we used a reference to s2, has to do with the signature of the method called when we use the + operator. It uses the add method, whose signature looks something like this:
