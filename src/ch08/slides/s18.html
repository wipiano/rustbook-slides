Chapter 8 · 8.2 Storing UTF-8 Encoded Text with Strings

Creating a new String

Many operations of Vec<T> are available with String too, because String is actually implemented as a wrapper around a vector of bytes with some extra guarantees, restrictions and capabilities. One function that works the same way for both is new, which creates an instance.

Often we want to start the string with some initial data. For that, use the to_string method, available on any type that implements the Display trait, as string literals do.

Listing 8.11: Creating a new, empty String

fn main() {

    let mut s = String::new();

}

This line creates a new, empty string called s, into which we can then load data.

Listing 8.12: Using the to_string method to create a String from a string literal

fn main() {

    let data = "initial contents";

 

    let s = data.to_string();

 

    // The method also works on a literal directly:

    let s = "initial contents".to_string();

}
