Chapter 8 · 8.3 Storing Keys with Associated Values in Hash Maps

Homogeneous keys and values; get

This HashMap has keys of type String and values of type i32. Just like vectors, hash maps store their data on the heap, and they are homogeneous: all of the keys must have the same type, and all of the values must have the same type.

We get a value out of the hash map by providing its key to the get method, as in Listing 8.21.

Listing 8.21: Accessing the score for the Blue team stored in the hash map

fn main() {

    use std::collections::HashMap;

 

    let mut scores = HashMap::new();

 

    scores.insert(String::from("Blue"), 10);

    scores.insert(String::from("Yellow"), 50);

 

    let team_name = String::from("Blue");

    let score = scores.get(&team_name).copied().unwrap_or(0);

}
