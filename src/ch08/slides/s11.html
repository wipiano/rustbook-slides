Dereferencing, and why iteration is safe

*i += 50;

To change the value that the mutable reference refers to, we have to use the * dereference operator to get to the value in i before we can use the += operator. The dereference operator is covered in “Following the Reference to the Value” in Chapter 15.

Iteration and the borrow checker

Iterating over a vector, whether immutably or mutably, is safe because of the borrow checker’s rules.
