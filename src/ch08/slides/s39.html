Chapter 8 · 8.3 Storing Keys with Associated Values in Hash Maps

What get returns

let score = scores.get(&team_name).copied().unwrap_or(0);

Here, score will have the value associated with the Blue team, and the result will be 10.

Table 8.1: How Listing 8.21 handles the Option that get returns

StepResult
get(&team_name)Option<&V>: None if there’s no value for that key
.copied()Option<i32> rather than Option<&i32>
.unwrap_or(0)sets score to zero if scores has no entry for the key
