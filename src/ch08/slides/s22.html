Chapter 8 · 8.2 Storing UTF-8 Encoded Text with Strings

push_str borrows; push adds one character

Listing 8.16: Using a string slice after appending its contents to a String

fn main() {

    let mut s1 = String::from("foo");

    let s2 = "bar";

    s1.push_str(s2);

    println!("s2 is {s2}");

}

If the push_str method took ownership of s2, we wouldn’t be able to print its value on the last line. However, this code works as we’d expect!

The push method takes a single character as a parameter and adds it to the String. Listing 8.17 adds the letter l to a String.

Listing 8.17: Adding one character to a String value using push

fn main() {

    let mut s = String::from("lo");

    s.push('l');

}

As a result, s will contain lol.
