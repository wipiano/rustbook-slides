Chapter 8 · 8.3 Storing Keys with Associated Values in Hash Maps

What Listing 8.24 prints; updating from the old value

Running the code in Listing 8.24 prints:

{"Yellow": 50, "Blue": 10}

  • The first call to entry inserts the key for the Yellow team with the value 50, because the Yellow team doesn’t have a value already.
  • The second call to entry does not change the hash map, because the Blue team already has the value 10.

Updating a value based on the old value

Another common use case for hash maps is to look up a key’s value and then update it based on the old value.
