Chapter 8 · 8.3 Storing Keys with Associated Values in Hash Maps

What Listing 8.25 prints, and why it works

This code will print:

{"world": 2, "hello": 1, "wonderful": 1}

You might see the same key-value pairs printed in a different order: recall from “Accessing Values in a Hash Map” that iterating over a hash map happens in an arbitrary order.

  • The split_whitespace method returns an iterator over subslices, separated by whitespace, of the value in text.
  • The or_insert method returns a mutable reference (&mut V) to the value for the specified key. We store it in count, so to assign to that value we must first dereference count using the asterisk (*).
  • The mutable reference goes out of scope at the end of the for loop, so all of these changes are safe and allowed by the borrowing rules.
