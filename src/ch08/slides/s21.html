Updating a String: appending with push_str

A String can grow in size and its contents can change, just like the contents of a Vec<T>, if you push more data into it. You can also conveniently use the + operator or the format! macro to concatenate String values.

We can grow a String by using the push_str method to append a string slice, as shown in Listing 8.15.

Listing 8.15: Appending a string slice to a String using the push_str method

fn main() {

    let mut s = String::from("foo");

    s.push_str("bar");

}

After these two lines, s will contain foobar. The push_str method takes a string slice because we don’t necessarily want to take ownership of the parameter. For example, in Listing 8.16 we want to be able to use s2 after appending its contents to s1.
