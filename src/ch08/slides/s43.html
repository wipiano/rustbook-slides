Chapter 8 · 8.3 Storing Keys with Associated Values in Hash Maps

Overwriting a value

Inserting a key and value, then the same key with a different value, replaces the value associated with that key. Listing 8.23 calls insert twice, but the hash map will only contain one key-value pair, because both times we insert the value for the Blue team’s key.

Listing 8.23: Replacing a value stored with a particular key

fn main() {

    use std::collections::HashMap;

 

    let mut scores = HashMap::new();

 

    scores.insert(String::from("Blue"), 10);

    scores.insert(String::from("Blue"), 25);

 

    println!("{scores:?}");

}

This code will print {"Blue": 25}. The original value of 10 has been overwritten.
