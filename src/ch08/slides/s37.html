Chapter 8 · 8.3 Storing Keys with Associated Values in Hash Maps

Creating a new hash map

One way to create an empty hash map is new, adding elements with insert. Listing 8.20 tracks the scores of two teams, Blue (starting with 10 points) and Yellow (starting with 50).

Listing 8.20: Creating a new hash map and inserting some keys and values

fn main() {

    use std::collections::HashMap;

 

    let mut scores = HashMap::new();

 

    scores.insert(String::from("Blue"), 10);

    scores.insert(String::from("Yellow"), 50);

}

We first use the HashMap from the collections portion of the standard library. As the least often used of the three common collections, it isn’t brought into scope automatically in the prelude, and it has less standard-library support: there’s no built-in macro to construct one, for example.
