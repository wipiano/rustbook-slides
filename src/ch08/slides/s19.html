Chapter 8 · 8.2 Storing UTF-8 Encoded Text with Strings

String::from, or to_string

Listing 8.12 creates a string containing initial contents. We can also use the function String::from to create a String from a string literal. Listing 8.13 is equivalent to Listing 8.12, which uses to_string.

Listing 8.13: Using the String::from function to create a String from a string literal

fn main() {

    let s = String::from("initial contents");

}

Because strings are used for so many things, there are many different generic APIs for strings, giving us a lot of options. Some of them can seem redundant, but they all have their place!

Remark. String::from and to_string do the same thing, so which one you choose is a matter of style and readability.
