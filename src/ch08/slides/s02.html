Chapter 8 · 8.1 Storing Lists of Values with Vectors

Type annotations and the vec! macro

Listing 8.1 needs a type annotation: because no values are inserted, Rust doesn’t know what kind of elements we intend to store. This is an important point. Vectors are implemented using generics (Chapter 10 covers using generics with your own types). For now, know that the standard library’s Vec<T> can hold any type, and the specific type goes within angle brackets: in Listing 8.1, the Vec<T> in v holds elements of the i32 type.

More often you create a Vec<T> with initial values and Rust infers the element type, so you rarely need the annotation. The vec! macro creates a new vector holding the values you give it. Listing 8.2 creates a Vec<i32> holding 1, 2 and 3; the type is i32 because that is the default integer type (“Data Types”, Chapter 3).

Listing 8.2: Creating a new vector containing values

fn main() {

    let v = vec![1, 2, 3];

}
