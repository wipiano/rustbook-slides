Chapter 8 · 8.1 Storing Lists of Values with Vectors

Updating a vector with push

Because Listing 8.2 gives initial i32 values, Rust infers that the type of v is Vec<i32>, and no annotation is needed. To create a vector and then add elements to it, use the push method (Listing 8.3).

Listing 8.3: Using the push method to add values to a vector

fn main() {

    let mut v = Vec::new();

 

    v.push(5);

    v.push(6);

    v.push(7);

    v.push(8);

}

  • As with any variable, to change its value we make it mutable with the mut keyword (Chapter 3).
  • The numbers placed inside are all of type i32; Rust infers this from the data, so the Vec<i32> annotation isn’t needed.
