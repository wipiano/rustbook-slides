Chapter 8 · 8.2 Storing UTF-8 Encoded Text with Strings

Slicing by byte range, and its panic

let hello = "Здравствуйте";

 

let s = &hello[0..4];

Here, s will be a &str that contains the first 4 bytes of the string. Each of these characters is 2 bytes, which means s will be Зд.

Slicing only part of a character’s bytes, with something like &hello[0..1], makes Rust panic at runtime, in the same way as if an invalid index were accessed in a vector:

$ cargo run

   Compiling collections v0.1.0 (file:///projects/collections)

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.43s

     Running `target/debug/collections`

 

thread 'main' (6017738) panicked at src/main.rs:4:19:

end byte index 1 is not a char boundary; it is inside 'З' (bytes 0..2 of string)

note: run with `RUST_BACKTRACE=1` environment variable to display a backtrace
