Chapter 13 · 13.1 Closures

sort_by_key takes an FnMut closure

The standard library method sort_by_key, defined on slices, shows how its bound differs from that of unwrap_or_else, and why it uses FnMut instead of FnOnce.

The closure gets one argument, a reference to the current item in the slice being considered, and returns a value of type K that can be ordered. This is useful when you want to sort a slice by a particular attribute of each item.

In Listing 13.7, a list of Rectangle instances is ordered with sort_by_key by their width attribute, from low to high.

Listing 13.7: Using sort_by_key to order rectangles by width — src/main.rs

#[derive(Debug)]

struct Rectangle {

    width: u32,

    height: u32,

}

 

fn main() {

    let mut list = [

        Rectangle { width: 10, height: 1 },

        Rectangle { width: 3, height: 5 },

        Rectangle { width: 7, height: 12 },

    ];

 

    list.sort_by_key(|r| r.width);

    println!("{list:#?}");

}
