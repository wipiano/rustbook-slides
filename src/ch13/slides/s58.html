The loop-based search function

Listing 13.21: The implementation of the search function from Listing 12.19 — src/lib.rs

pub fn search<'a>(query: &str, contents: &'a str) -> Vec<&'a str> {

    let mut results = Vec::new();

 

    for line in contents.lines() {

        if line.contains(query) {

            results.push(line);

        }

    }

 

    results

}

We can write this code more concisely using iterator adapter methods, which also lets us avoid a mutable intermediate results vector. The functional programming style prefers to minimize the amount of mutable state to make code clearer. Removing the mutable state might enable a future enhancement to make searching happen in parallel, because we wouldn’t have to manage concurrent access to the results vector.
