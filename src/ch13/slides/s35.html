Chapter 13 · 13.2 Processing a Series of Items with Iterators

Using an iterator in a for loop

The iterator is stored in the v1_iter variable. Once created, an iterator can be used in a variety of ways. Listing 3.5 iterated over an array using a for loop to execute some code on each item. Under the hood, this implicitly created and then consumed an iterator, but how exactly that works was glossed over until now.

Listing 13.11 separates the creation of the iterator from its use in the for loop. When the loop is called using the iterator in v1_iter, each element in the iterator is used in one iteration of the loop, which prints out each value.

Listing 13.11: Using an iterator in a for loop — src/main.rs

fn main() {

    let v1 = vec![1, 2, 3];

 

    let v1_iter = v1.iter();

 

    for val in v1_iter {

        println!("Got: {val}");

    }

}
