Chapter 13 · 13.1 Closures

Forcing ownership with move

This technique is mostly useful when passing a closure to a new thread, to move the data so that it’s owned by the new thread. Chapter 16 discusses threads and why you would want them in detail; for now, here is a brief look at spawning a new thread using a closure that needs the move keyword. Listing 13.6 modifies Listing 13.4 to print the vector in a new thread rather than in the main thread.

Listing 13.6: Using move to force the closure for the thread to take ownership of list — src/main.rs

use std::thread;

 

fn main() {

    let list = vec![1, 2, 3];

    println!("Before defining closure: {list:?}");

 

    thread::spawn(move || println!("From thread: {list:?}"))

        .join()

        .unwrap();

}
