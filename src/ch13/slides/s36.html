Chapter 13 · 13.2 Processing a Series of Items with Iterators

What iterators save you from writing

In languages whose standard libraries don’t provide iterators, you would likely write this same functionality by:

  1. starting a variable at index 0;
  2. using that variable to index into the vector to get a value;
  3. incrementing the variable value in a loop until it reached the total number of items in the vector.

Iterators handle all of that logic for you, cutting down on repetitive code you could potentially mess up. Iterators also give you more flexibility to use the same logic with many different kinds of sequences, not just data structures you can index into, like vectors.
