Chapter 13 · 13.1 Closures

Many immutable borrows at once

This example also shows that a variable can bind to a closure definition, and we can later call the closure by using the variable name and parentheses as if the variable name were a function name.

Because we can have multiple immutable references to list at the same time, list is still accessible before the closure definition, after the definition but before the call, and after the call. This code compiles, runs, and prints:
