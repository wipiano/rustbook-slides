Chapter 13 · 13.1 Closures

Capturing references or moving ownership

Closures can capture values from their environment in three ways, mapping directly to the three ways a function can take a parameter: borrowing immutably, borrowing mutably, and taking ownership. The closure decides which to use based on what its body does with the captured values. In Listing 13.4 it captures an immutable reference to the vector list, because that is all it needs to print the value.

Listing 13.4: Defining and calling a closure that captures an immutable reference — src/main.rs

fn main() {

    let list = vec![1, 2, 3];

    println!("Before defining closure: {list:?}");

 

    let only_borrows = || println!("From closure: {list:?}");

 

    println!("Before calling closure: {list:?}");

    only_borrows();

    println!("After calling closure: {list:?}");

}
