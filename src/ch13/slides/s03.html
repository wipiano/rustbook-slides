The shirt giveaway setup

There are many ways to implement this. Here, an enum ShirtColor has the variants Red and Blue (limiting the colors for simplicity). The company’s inventory is an Inventory struct with a field shirts holding a Vec<ShirtColor> of the shirt colors currently in stock. The method giveaway defined on Inventory gets the optional shirt color preference of the free-shirt winner and returns the shirt color the person will get.

Listing 13.1: Shirt company giveaway situation — src/main.rs

#[derive(Debug, PartialEq, Copy, Clone)]

enum ShirtColor {

    Red,

    Blue,

}

 

struct Inventory {

    shirts: Vec<ShirtColor>,

}
