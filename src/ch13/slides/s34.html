Chapter 13 · 13.2 Processing a Series of Items with Iterators

The iterator pattern, and laziness

The iterator pattern allows you to perform some task on a sequence of items in turn. An iterator is responsible for the logic of iterating over each item and determining when the sequence has finished. When you use iterators, you don’t have to reimplement that logic yourself.

Definition 13.7 (Lazy). In Rust, iterators are lazy: they have no effect until you call methods that consume the iterator to use it up.

For example, Listing 13.10 creates an iterator over the items in the vector v1 by calling the iter method defined on Vec<T>. This code by itself doesn’t do anything useful.

Listing 13.10: Creating an iterator — src/main.rs

fn main() {

    let v1 = vec![1, 2, 3];

 

    let v1_iter = v1.iter();

}
