Chapter 13 · 13.4 Performance in Loops vs. Iterators

Use iterators and closures without fear

  • In many cases, Rust code using iterators compiles to the same assembly you’d write by hand.
  • Optimizations such as loop unrolling and eliminating bounds checking on array access apply, and make the resultant code extremely efficient.

Now that you know this, you can use iterators and closures without fear! They make code seem like it’s higher level but don’t impose a runtime performance penalty for doing so.
