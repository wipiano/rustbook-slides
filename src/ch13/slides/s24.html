The definition of unwrap_or_else

Here is the definition of the unwrap_or_else method on Option<T> used in Listing 13.1:

impl<T> Option<T> {

    pub fn unwrap_or_else<F>(self, f: F) -> T

    where

        F: FnOnce() -> T

    {

        match self {

            Some(x) => x,

            None => f(),

        }

    }

}

Recall that T is the generic type representing the type of the value in the Some variant of an Option. That type T is also the return type of unwrap_or_else: code that calls unwrap_or_else on an Option<String>, for example, will get a String.
