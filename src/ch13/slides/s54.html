Remark. The standard library documentation for env::args shows that the type of the iterator it returns is std::env::Args, and that type implements the Iterator trait and returns String values.

The parameter args now has a generic type with the trait bounds impl Iterator<Item = String> instead of &[String]. This use of the impl Trait syntax (Chapter 10, “Using Traits as Parameters”) means that args can be any type that implements the Iterator trait and returns String items.

Because we’re taking ownership of args and will mutate it by iterating over it, we add the mut keyword to the args parameter to make it mutable.
