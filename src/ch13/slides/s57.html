How the new Config::build reads its arguments

  1. The first value in the return value of env::args is the name of the program. We want to ignore it, so we first call next and do nothing with the return value.
  2. Then we call next to get the value for the query field of Config. If next returns Some, a match extracts the value. If it returns None, not enough arguments were given, and we return early with an Err value.
  3. We do the same thing for the file_path value.
