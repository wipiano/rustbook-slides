Counting with an FnMut closure instead

Keeping a counter in the environment and incrementing its value in the closure body is a more straightforward way to count the number of times the closure is called. The closure in Listing 13.9 works with sort_by_key because it only captures a mutable reference to the num_sort_operations counter and can therefore be called more than once.
