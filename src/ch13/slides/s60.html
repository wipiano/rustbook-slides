Chapter 13 · 13.3 Improving Our I/O Project

Going further: return an iterator from search

For a further improvement, return an iterator from the search function, so that the function becomes an iterator adapter:

  • remove the call to collect;
  • change the return type to impl Iterator<Item = &'a str>;
  • note that you’ll also need to update the tests!

Search through a large file using your minigrep tool before and after making this change to observe the difference in behavior. Before the change, the program won’t print any results until it has collected all of the results. After the change, the results are printed as each matching line is found, because the for loop in the run function is able to take advantage of the laziness of the iterator.
