Chapter 13 · 13.4 Performance in Loops vs. Iterators

Benchmarking the two search versions

To decide between loops and iterators, you need to know which implementation is faster: the version of search with an explicit for loop or the version with iterators.

A benchmark loaded the entire contents of The Adventures of Sherlock Holmes by Sir Arthur Conan Doyle into a String and looked for the word “the” in the contents. Here are the results for the version of search using the for loop and the version using iterators:

test bench_search_for  ... bench:  19,620,300 ns/iter (+/- 915,700)

test bench_search_iter ... bench:  19,234,900 ns/iter (+/- 657,200)

The two implementations have similar performance! The benchmark code isn’t explained here, because the point is not to prove that the two versions are equivalent but to get a general sense of how they compare performance-wise.
