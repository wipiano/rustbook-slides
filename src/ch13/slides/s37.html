Chapter 13 · 13.2 Processing a Series of Items with Iterators

The Iterator trait and the next method

All iterators implement a trait named Iterator that is defined in the standard library. Its definition looks like this:

pub trait Iterator {

    type Item;

 

    fn next(&mut self) -> Option<Self::Item>;

 

    // methods with default implementations elided

}

Definition 13.8 (Associated type). The new syntax type Item and Self::Item defines an associated type with this trait (covered in depth in Chapter 20). Implementing Iterator requires that you also define an Item type, which is used in the return type of next: the Item type is the type returned from the iterator.

The Iterator trait only requires implementors to define one method: next, which returns one item of the iterator at a time, wrapped in Some, and, when iteration is over, returns None.
