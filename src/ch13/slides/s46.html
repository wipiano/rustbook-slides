filter with a closure that captures shoe_size

In Listing 13.16, filter is used with a closure that captures the shoe_size variable from its environment to iterate over a collection of Shoe struct instances. It returns only shoes that are the specified size.

Listing 13.16: Using the filter method with a closure that captures shoe_size — src/lib.rs

#[derive(PartialEq, Debug)]

struct Shoe {

    size: u32,

    style: String,

}

 

fn shoes_in_size(shoes: Vec<Shoe>, shoe_size: u32) -> Vec<Shoe> {

    shoes.into_iter().filter(|s| s.size == shoe_size).collect()

}
