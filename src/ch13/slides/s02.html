Chapter 13 · 13.1 Closures

Closures, and capturing the environment

Definition 13.2 (Closure). An anonymous function you can save in a variable or pass as an argument to other functions. Unlike functions, closures can capture values from the scope in which they’re defined.

You can create a closure in one place and then call it elsewhere to evaluate it in a different context. These features allow for code reuse and behavior customization.

Capturing the environment

First, how closures capture values from the environment they’re defined in for later use. The scenario: every so often, a T-shirt company gives away an exclusive, limited-edition shirt to someone on its mailing list as a promotion. People on the mailing list can optionally add their favorite color to their profile. If the person chosen for a free shirt has a favorite color set, they get that color; if not, they get whatever color the company currently has the most of.
