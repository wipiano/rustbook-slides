Chapter 4 · 4.2 References and Borrowing

calculate_length with a reference parameter

src/main.rs

fn main() {

    let s1 = String::from("hello");

 

    let len = calculate_length(&s1);

 

    println!("The length of '{s1}' is {len}.");

}

 

fn calculate_length(s: &String) -> usize {

    s.len()

}

Here is how you would define and use a calculate_length function that has a reference to an object as a parameter instead of taking ownership of the value.

  • All the tuple code in the variable declaration and the function return value is gone.
  • We pass &s1 into calculate_length and, in its definition, we take &String rather than String.

These ampersands represent references, and they allow you to refer to some value without taking ownership of it. Figure 4.6 depicts this concept.
