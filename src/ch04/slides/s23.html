So, what actually happens is shown in Figure 4.4. Table s1 is grayed out because s1 is no longer valid; only s2 can be used to access the heap data.

That solves our problem! With only s2 valid, when it goes out of scope it alone will free the memory, and we’re done.

There is also a design choice implied by this: Rust will never automatically create “deep” copies of your data. Therefore, any automatic copying can be assumed to be inexpensive in terms of runtime performance.
