Return values and scope: gives_ownership

Listing 4.4 (continued): Transferring ownership of return values — src/main.rs

fn gives_ownership() -> String {       // gives_ownership will move its

                                       // return value into the function

                                       // that calls it

 

    let some_string = String::from("yours"); // some_string comes into scope

 

    some_string                        // some_string is returned and

                                       // moves out to the calling

                                       // function

}

gives_ownership creates some_string and returns it; ownership of the returned value moves out to the caller, where it is bound to s1.
