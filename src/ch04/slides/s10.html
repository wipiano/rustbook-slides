Chapter 4 · 4.1 What Is Ownership?

String literals versus the String type

String literals, where a string value is hardcoded into the program, are convenient, but they aren’t suitable for every situation in which we may want to use text:

  • they’re immutable;
  • not every string value can be known when we write our code — for example, what if we want to take user input and store it?

For these situations Rust has the String type. It manages data allocated on the heap and as such can store an amount of text that is unknown to us at compile time. You can create a String from a string literal using the from function:

let s = String::from("hello");

The double colon :: operator lets us namespace this particular from function under the String type rather than using some sort of name like string_from. This syntax is discussed more in “Methods” (Chapter 5) and in “Paths for Referring to an Item in the Module Tree” (Chapter 7).
