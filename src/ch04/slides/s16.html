Chapter 4 · 4.1 What Is Ownership?

Variables and data interacting with move

Multiple variables can interact with the same data in different ways in Rust:

Listing 4.2: Assigning the integer value of variable x to y

fn main() {

    let x = 5;

    let y = x;

}

The String version

fn main() {

    let s1 = String::from("hello");

    let s2 = s1;

}

We can probably guess what Listing 4.2 does: “Bind the value 5 to x; then, make a copy of the value in x and bind it to y.” We now have two variables, x and y, and both equal 5. This is indeed what happens, because integers are simple values with a known, fixed size, and these two 5 values are pushed onto the stack.

The String version looks very similar, so we might assume it works the same way: that the second line makes a copy of the value in s1 and binds it to s2. But this isn’t quite what happens.
