Chapter 4 · 4.1 What Is Ownership?

Ownership: a third approach to managing memory

Definition 4.1 (Ownership). A set of rules that govern how a Rust program manages memory. The compiler checks the rules; if any of them is violated, the program won’t compile.

All programs have to manage the way they use a computer’s memory while running. There are three approaches:

  • Some languages have garbage collection that regularly looks for no-longer-used memory as the program runs.
  • In other languages, the programmer must explicitly allocate and free the memory.
  • Rust uses a third approach: memory is managed through a system of ownership with a set of rules that the compiler checks. None of the features of ownership will slow down your program while it’s running.

Ownership is a new concept for many programmers, so it takes some time to get used to. The more experienced you become with Rust and its ownership rules, the easier you’ll find it to naturally develop code that is safe and efficient. Keep at it! Understanding ownership gives a solid foundation for the features that make Rust unique; this chapter teaches it through examples that focus on a very common data structure: strings.
