Chapter 4 · Summary

Chapter summary

The concepts of ownership, borrowing, and slices ensure memory safety in Rust programs at compile time. The Rust language gives you control over your memory usage in the same way as other systems programming languages. But having the owner of data automatically clean up that data when the owner goes out of scope means you don’t have to write and debug extra code to get this control.

  • Ownership: each value has one owner; when the owner goes out of scope, the value is dropped. Assignment and passing to functions move heap data; Copy types are copied; clone deep-copies explicitly.
  • Borrowing: either one mutable reference or any number of immutable references at a time, and references must always be valid.
  • Slices: references to a contiguous part of a collection, tied to the underlying data (&str, &[i32]).

Remark. Ownership affects how lots of other parts of Rust work, so these concepts come up throughout the rest of the book. Next, Chapter 5 looks at grouping pieces of data together in a struct.
