Chapter 4 · 4.3 The Slice Type

Range shorthand: dropping the start, the end, or both

With Rust’s .. range syntax, you can leave out either bound:

To start at index 0, drop the value before the two periods. These are equal:

let s = String::from("hello");

 

let slice = &s[0..2];

let slice = &s[..2];

If your slice includes the last byte of the String, drop the trailing number. These are equal:

let s = String::from("hello");

 

let len = s.len();

 

let slice = &s[3..len];

let slice = &s[3..];

Drop both values to take a slice of the entire string. These are equal:

let s = String::from("hello");

 

let len = s.len();

 

let slice = &s[0..len];

let slice = &s[..];

Remark. String slice range indices must occur at valid UTF-8 character boundaries. If you attempt to create a string slice in the middle of a multibyte character, your program will exit with an error.
