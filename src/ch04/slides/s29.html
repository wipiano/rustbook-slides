Chapter 4 · 4.1 What Is Ownership?

Which types implement Copy?

You can check the documentation for the given type to be sure, but as a general rule, any group of simple scalar values can implement Copy, and nothing that requires allocation or is some form of resource can implement Copy.

Table 4.1: Some of the types that implement Copy

TypeExamples
All the integer typesu32
The Boolean type, booltrue and false
All the floating-point typesf64
The character typechar
Tuples, if they only contain types that also implement Copy(i32, i32) implements Copy, but (i32, String) does not
