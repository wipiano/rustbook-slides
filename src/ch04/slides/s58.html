Chapter 4 · 4.3 The Slice Type

Slices, and the first_word problem

Definition 4.13 (Slice). A reference to a contiguous sequence of elements in a collection. A slice is a kind of reference, so it does not have ownership.

A small programming problem: write a function that takes a string of words separated by spaces and returns the first word it finds in that string. If the function doesn’t find a space in the string, the whole string must be one word, so the entire string should be returned.

Remark. For the purposes of introducing slices, this section assumes ASCII only; a more thorough discussion of UTF-8 handling is in “Storing UTF-8 Encoded Text with Strings” in Chapter 8.
