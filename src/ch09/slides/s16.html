  • The value File::open returns inside the Err variant is an io::Error, a struct provided by the standard library. Its method kind gives an io::ErrorKind value.
  • The standard-library enum io::ErrorKind has variants representing the different kinds of errors an io operation might produce. We want ErrorKind::NotFound: the file we’re trying to open doesn’t exist yet.
  • So we match on greeting_file_result, but we also have an inner match on error.kind().
