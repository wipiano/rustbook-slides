Using ? on Option<T> values

The error message also mentioned that ? can be used with Option<T> values as well. As with using ? on Result, you can only use ? on Option in a function that returns an Option. The behavior of ? on an Option<T> is similar to its behavior on a Result<T, E>:

Table 9.3: What the ? operator does with each value

ValueEffect of ?
Ok(v)v is the resultant value of the expression; the function continues
Err(e)Err is returned early from the function (after conversion by From::from)
Some(v)v is the resultant value of the expression; the function continues
NoneNone is returned early from the function at that point
