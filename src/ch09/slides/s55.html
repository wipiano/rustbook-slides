Chapter 9 · 9.3 To panic! or Not to panic!

The value getter and the private field

Next, we implement a method named value that borrows self, doesn’t have any other parameters, and returns an i32.

Definition 9.16 (Getter). A method whose purpose is to get some data from its fields and return it.

  • This public method is necessary because the value field of the Guess struct is private.
  • It’s important that the field be private, so that code using the Guess struct is not allowed to set value directly: code outside the guessing_game module must use Guess::new to create an instance of Guess.
  • That ensures there’s no way for a Guess to have a value that hasn’t been checked by the conditions in Guess::new.

A function that has a parameter or returns only numbers between 1 and 100 could then declare in its signature that it takes or returns a Guess rather than an i32, and wouldn’t need to do any additional checks in its body.
