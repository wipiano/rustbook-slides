Chapter 9 · 9.2 Recoverable Errors with Result

Shortcuts for panic on error: unwrap

Using match works well enough, but it can be a bit verbose and doesn’t always communicate intent well. Result<T, E> has many helper methods for more specific tasks. The unwrap method is a shortcut implemented just like the match in Listing 9.4: if the Result is Ok, unwrap returns the value inside the Ok; if it is Err, unwrap calls the panic! macro for us.

use std::fs::File;

 

fn main() {

    let greeting_file = File::open("hello.txt").unwrap();

}

Run without a hello.txt file, it shows the error message from the panic! call that unwrap makes:

thread 'main' panicked at src/main.rs:4:49:

called `Result::unwrap()` on an `Err` value:

    Os { code: 2, kind: NotFound, message: "No such file or directory" }
