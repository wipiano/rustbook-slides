Chapter 9 · 9.2 Recoverable Errors with Result

The caller decides

The code that calls read_username_from_file will then handle getting either an Ok value that contains a username or an Err value that contains an io::Error. It’s up to the calling code to decide what to do with those values. If it gets an Err value, it could, for example:

  • call panic! and crash the program,
  • use a default username, or
  • look up the username from somewhere other than a file.

We don’t have enough information on what the calling code is actually trying to do, so we propagate all the success or error information upward for it to handle appropriately.

This pattern of propagating errors is so common in Rust that Rust provides the question mark operator ? to make it easier.
