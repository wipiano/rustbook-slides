Chapter 9 · 9.2 Recoverable Errors with Result

Chaining method calls after ?

? eliminates a lot of boilerplate; we can shorten further by chaining calls right after the ?:

Listing 9.8: Chaining method calls after the ? operator — src/main.rs

use std::fs::File;

use std::io::{self, Read};

 

fn read_username_from_file() -> Result<String, io::Error> {

    let mut username = String::new();

 

    File::open("hello.txt")?.read_to_string(&mut username)?;

 

    Ok(username)

}

The new String moved to the start. Instead of a variable username_file, we chain read_to_string directly onto File::open("hello.txt")?, keep its ?, and still return Ok(username) when both succeed: the same functionality as Listings 9.6 and 9.7, just more ergonomic.
