Chapter 9 · 9.2 Recoverable Errors with Result

Error E0277: ? in a function that returns ()

This code opens a file, which might fail. The ? operator follows the Result value returned by File::open, but this main function has the return type (), not Result. Compiling it gives this error:

$ cargo run

   Compiling error-handling v0.1.0 (file:///projects/error-handling)

error[E0277]: the `?` operator can only be used in a function that returns `Result` or `Option`

    (or another type that implements `FromResidual`)

 --> src/main.rs:4:48

  |

3 | fn main() {

  | --------- this function should return `Result` or `Option` to accept `?`

4 |     let greeting_file = File::open("hello.txt")?;

  |                                                ^ cannot use the `?` operator in a function

  |                                                  that returns `()`

  |

help: consider adding return type
