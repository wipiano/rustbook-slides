Chapter 9 · 9.2 Recoverable Errors with Result

main returning Result<(), Box<dyn Error>>

Listing 9.12: Changing main to return Result<(), E> allows the use of the ? operator on Result values. — src/main.rs

use std::error::Error;

use std::fs::File;

 

fn main() -> Result<(), Box<dyn Error>> {

    let greeting_file = File::open("hello.txt")?;

 

    Ok(())

}

  • The Box<dyn Error> type is a trait object, covered in Chapter 18 (“Using Trait Objects to Abstract over Shared Behavior”). For now, read Box<dyn Error> as “any kind of error.”
  • Using ? on a Result in a main with error type Box<dyn Error> is allowed because it allows any Err value to be returned early.
  • Even though this body only ever returns errors of type std::io::Error, specifying Box<dyn Error> keeps the signature correct even if code returning other errors is added to main.
