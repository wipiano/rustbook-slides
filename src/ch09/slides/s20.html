Shortcuts for panic on error: expect

Similarly, expect also lets us choose the panic! message. Used instead of unwrap with a good message, it conveys your intent and makes tracking down the source of a panic easier:

use std::fs::File;

 

fn main() {

    let greeting_file = File::open("hello.txt")

        .expect("hello.txt should be included in this project");

}

We use expect like unwrap: to return the file handle or call panic!. The message expect uses in its call to panic! is the parameter we pass to it, rather than the default message unwrap uses:

thread 'main' panicked at src/main.rs:5:10:

hello.txt should be included in this project:

    Os { code: 2, kind: NotFound, message: "No such file or directory" }
