Chapter 9 · 9.2 Recoverable Errors with Result

No mixing Result and Option; what main may return

You can’t mix and match

You can use ? on a Result in a function that returns Result, and on an Option in a function that returns Option, but you can’t mix and match. The ? operator won’t automatically convert a Result to an Option or vice versa; in those cases, use methods like ok on Result or ok_or on Option to do the conversion explicitly.

The return type of main

So far, all the main functions we’ve used return (). The main function is special because it’s the entry point and exit point of an executable program, and there are restrictions on what its return type can be for the program to behave as expected.
