Chapter 9 · 9.3 To panic! or Not to panic!

A Guess type that validates on creation

Instead, make a new type in a dedicated module and put the validations in a function that creates an instance of the type, rather than repeating them everywhere. Functions can then safely use the new type in their signatures and confidently use the values they receive.

Listing 9.13: A Guess type that will only continue with values between 1 and 100 — src/guessing_game.rs

pub struct Guess {

    value: i32,

}

 

impl Guess {

    pub fn new(value: i32) -> Guess {

        if value < 1 || value > 100 {

            panic!("Guess value must be between 1 and 100, got {value}.");

        }

 

        Guess { value }

    }
