Propagating errors with match (continued)

Listing 9.6 (continued)

    let mut username = String::new();

 

    match username_file.read_to_string(&mut username) {

        Ok(_) => Ok(username),

        Err(e) => Err(e),

    }

}

  • If this function succeeds without any problems, the calling code receives an Ok value that holds a String — the username that this function read from the file.
  • If it encounters any problems, the calling code receives an Err value that holds an instance of io::Error containing more information about what the problems were.
  • We chose io::Error as the error type because it happens to be the type of the error value returned by both fallible operations in the body: the File::open function and the read_to_string method.
