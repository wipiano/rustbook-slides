Two kinds of errors: recoverable and unrecoverable

Rust groups errors into two major categories:

Definition 9.1 (Recoverable error). An error such as a file not found error, where we most likely just want to report the problem to the user and retry the operation.

Definition 9.2 (Unrecoverable error). An error that is always a symptom of a bug, such as trying to access a location beyond the end of an array; we want to immediately stop the program.

Most languages don’t distinguish between these two kinds of errors and handle both in the same way, using mechanisms such as exceptions. Rust doesn’t have exceptions. Instead:

Table 9.1: How Rust handles each category

CategoryRust mechanism
RecoverableThe type Result<T, E>
UnrecoverableThe panic! macro, which stops execution
