Chapter 18 · 18.3 Implementing an Object-Oriented Design Pattern

Consuming the old state: self: Box<Self> and take

Post gets a public method request_review that takes a mutable reference to self. It calls an internal request_review method on the current state of Post, and this second request_review consumes the current state and returns a new state.

We add request_review to the State trait, so all implementing types must now implement it. Its first parameter is not self, &self, or &mut self but self: Box<Self>: the method is only valid when called on a Box holding the type. This syntax takes ownership of Box<Self>, invalidating the old state so that the Post’s state value can transform into a new state.

To consume the old state, request_review needs ownership of the state value. That is where the Option in Post’s state field comes in: we call take to take the Some value out of the state field and leave a None in its place, because Rust doesn’t let us have unpopulated fields in structs. This lets us move the state value out of Post rather than borrowing it. Then we set the post’s state to the result of this operation.
