Chapter 18 · 18.3 Implementing an Object-Oriented Design Pattern

Storing the text of the post content

Listing 18.11 calls a method named add_text and passes it a &str that is added as the text content of the post. We implement this as a method rather than exposing the content field as pub, so that later we can implement a method that controls how the content field’s data is read. add_text is straightforward; we add it to the impl Post block.

Listing 18.13: Implementing the add_text method to add text to a post’s content — src/lib.rs

impl Post {

    // --snip--

    pub fn add_text(&mut self, text: &str) {

        self.content.push_str(text);

    }

}

add_text takes &mut self because it changes the Post it is called on, and calls push_str on the String in content with the text argument. This behavior doesn’t depend on the post’s state, so it’s not part of the state pattern — add_text never touches the state field — but it is behavior we want to support.
