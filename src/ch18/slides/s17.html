Chapter 18 · 18.2 Using Trait Objects to Abstract over Shared Behavior

A library user adds a SelectBox

Fields differ between components: a TextField might have the same fields plus a placeholder. Each drawable type implements Draw but uses different code in draw to define how to draw itself. Button might also have an additional impl block with methods for when a user clicks it — methods that don’t apply to types like TextField.

A library user who implements a SelectBox struct with width, height, and options fields implements Draw on it as well.

Listing 18.8: Another crate using gui and implementing the Draw trait on a SelectBox struct — src/main.rs

use gui::Draw;

 

struct SelectBox {

    width: u32,

    height: u32,

    options: Vec<String>,

}

 

impl Draw for SelectBox {

    fn draw(&self) {

        // code to actually draw a select box

    }

}
