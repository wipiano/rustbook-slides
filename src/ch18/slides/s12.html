Chapter 18 · 18.2 Using Trait Objects to Abstract over Shared Behavior

The Draw trait and a Screen of trait objects

Listing 18.3 defines a trait named Draw with one method named draw; this syntax is familiar from Chapter 10.

Listing 18.3: Definition of the Draw trait — src/lib.rs

pub trait Draw {

    fn draw(&self);

}

Next comes new syntax: Listing 18.4 defines a struct Screen holding a vector named components of type Box<dyn Draw>, which is a trait object: a stand-in for any type inside a Box that implements the Draw trait.

Listing 18.4: Definition of the Screen struct with a components field holding a vector of trait objects that implement the Draw trait — src/lib.rs

pub struct Screen {

    pub components: Vec<Box<dyn Draw>>,

}
