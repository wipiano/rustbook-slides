Public methods guard the private fields

The struct is marked pub so other code can use it, but its fields stay private. That matters here: whenever a value is added to or removed from the list, the average must also be updated. We do this by implementing add, remove, and average methods on the struct.

Listing 18.2: Implementations of the public methods add, remove, and average on AveragedCollection — src/lib.rs

pub struct AveragedCollection {

    list: Vec<i32>,

    average: f64,

}

 

impl AveragedCollection {

    pub fn add(&mut self, value: i32) {

        self.list.push(value);

        self.update_average();

    }

    pub fn remove(&mut self) -> Option<i32> {

        let result = self.list.pop();

        match result {

            Some(value) => {

                self.update_average();

                Some(value)

            }

            None => None,

        }

    }
