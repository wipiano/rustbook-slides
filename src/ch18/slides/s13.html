Chapter 18 · 18.2 Using Trait Objects to Abstract over Shared Behavior

Screen::run calls draw on every component

On the Screen struct we define a method named run that calls the draw method on each of its components, as shown in Listing 18.5.

This works differently from defining a struct that uses a generic type parameter with trait bounds. A generic type parameter can be substituted with only one concrete type at a time, whereas trait objects allow multiple concrete types to fill in for the trait object at runtime.

Listing 18.5: A run method on Screen that calls the draw method on each component — src/lib.rs

pub struct Screen {

    pub components: Vec<Box<dyn Draw>>,

}

 

impl Screen {

    pub fn run(&self) {

        for component in self.components.iter() {

            component.draw();

        }

    }

}
