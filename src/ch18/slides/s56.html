Listing 18.21: Modifications to main to use the new implementation of the blog post workflow — src/main.rs

use blog::Post;

 

fn main() {

    let mut post = Post::new();

 

    post.add_text("I ate a salad for lunch today");

 

    let post = post.request_review();

 

    let post = post.approve();

 

    assert_eq!("I ate a salad for lunch today", post.content());

}

Remark. Each let post = binds the value returned by the transition to a new post of a different type: DraftPost, then PendingReviewPost, then Post.
