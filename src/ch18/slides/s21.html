Chapter 18 · 18.2 Using Trait Objects to Abstract over Shared Behavior

Trying a type that doesn’t implement Draw

Listing 18.10 shows what happens if we try to create a Screen with a String as a component.

Listing 18.10: Attempting to use a type that doesn’t implement the trait object’s trait — src/main.rs

use gui::Screen;

 

fn main() {

    let screen = Screen {

        components: vec![Box::new(String::from("Hi"))],

    };

 

    screen.run();

}

We get the error on the next slide because String doesn’t implement the Draw trait. It tells us that either we’re passing something to Screen we didn’t mean to pass and should pass a different type, or we should implement Draw on String so that Screen is able to call draw on it.
