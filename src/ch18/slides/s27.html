Chapter 18 · 18.3 Implementing an Object-Oriented Design Pattern

Attempting traditional object-oriented style

There are infinite ways to structure code to solve the same problem, each with different trade-offs. This section’s implementation is more of a traditional object-oriented style: possible to write in Rust, but not taking advantage of some of Rust’s strengths.

Later we demonstrate a different solution that still uses the object-oriented design pattern but is structured in a way that might look less familiar to programmers with object-oriented experience. Comparing the two solutions shows the trade-offs of designing Rust code differently than code in other languages.
