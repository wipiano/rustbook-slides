Chapter 18 · 18.3 Implementing an Object-Oriented Design Pattern

Post::content delegates to its state

Listing 18.17: Updating the content method on Post to delegate to a content method on State — src/lib.rs

impl Post {

    // --snip--

    pub fn content(&self) -> &str {

        self.state.as_ref().unwrap().content(self)

    }

    // --snip--

}

The goal is to keep all of these rules inside the structs that implement State. So we call a content method on the value in state, pass the post instance (that is, self) as an argument, and return what that method returns.

We call as_ref on the Option because we want a reference to the value inside it rather than ownership. As state is an Option<Box<dyn State>>, as_ref returns an Option<&Box<dyn State>>. Without as_ref we’d get an error, because we can’t move state out of the borrowed &self of the function parameter.
