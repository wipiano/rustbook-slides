Chapter 18 · 18.3 Implementing an Object-Oriented Design Pattern

Every new Post starts as a Draft

Listing 18.12 (continued) — src/lib.rs

trait State {}

 

struct Draft {}

 

impl State for Draft {}

The State trait defines the behavior shared by different post states. The state objects are Draft, PendingReview, and Published, and they will all implement State. For now the trait has no methods, and we define just the Draft state, because that is the state we want a post to start in.

When we create a new Post, we set its state field to a Some value holding a Box that points to a new instance of the Draft struct. So every new Post starts out as a draft — and because the state field is private, there is no way to create a Post in any other state! In Post::new we set the content field to a new, empty String.
