Designing the can_hold signature

We know we want a method, so it goes within the impl Rectangle block. Reading the calling code tells us the rest:

  • Name: can_hold.
  • Parameter: an immutable borrow of another Rectangle. rect1.can_hold(&rect2) passes in &rect2, an immutable borrow of rect2, an instance of Rectangle.
  • Why immutable: we only need to read rect2 (writing would need a mutable borrow), and we want main to retain ownership of rect2 so it can use it again after calling can_hold.
  • Return value: a Boolean.
  • Implementation: check whether the width and height of self are greater than the width and height of the other Rectangle, respectively.
