Chapter 5 · 5.1 Defining and Instantiating Structs

Defining unit-like structs

Definition 5.9 (Unit-like struct). A struct without any fields. It behaves similarly to (), the unit type (“The Tuple Type”, Chapter 3).

Unit-like structs are useful when you need to implement a trait on some type but don’t have any data you want to store in the type itself (traits: Chapter 10). Declaring and instantiating a unit struct named AlwaysEqual:

struct AlwaysEqual;

 

fn main() {

    let subject = AlwaysEqual;

}

  • Define it with the struct keyword, the name, then a semicolon: no curly brackets or parentheses. Create an instance the same way, with just the name.
  • Imagine later implementing behavior so every AlwaysEqual is always equal to every instance of any other type — perhaps for a known result in tests. That behavior needs no data! Chapter 10 shows how.
