Chapter 5 · 5.1 Defining and Instantiating Structs

Defining a struct, then making an instance

Listing 5.1 shows a struct that stores information about a user account.

Listing 5.1: A User struct definition — src/main.rs

struct User {

    active: bool,

    username: String,

    email: String,

    sign_in_count: u64,

}

Definition 5.3 (Instance). A value of a struct type, created by specifying concrete values for each of the struct’s fields.

  • Create an instance by stating the struct’s name, then curly brackets containing key: value pairs: the keys are the field names, the values the data to store in those fields.
  • The fields need not appear in the order in which they were declared in the struct.
