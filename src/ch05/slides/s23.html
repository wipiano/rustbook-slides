Chapter 5 · 5.2 An Example Program Using Structs

A win for clarity

  • area accesses the width and height fields of the Rectangle instance. Accessing fields of a borrowed struct instance does not move the field values, which is why you often see borrows of structs.
  • The signature now says exactly what we mean: calculate the area of Rectangle, using its width and height fields.
  • It conveys that width and height are related, and gives the values descriptive names instead of the tuple indexes 0 and 1.
