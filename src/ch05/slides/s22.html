Chapter 5 · 5.2 An Example Program Using Structs

area borrows a Rectangle

Listing 5.10 (continued): Defining a Rectangle struct — src/main.rs

fn area(rectangle: &Rectangle) -> u32 {

    rectangle.width * rectangle.height

}

We’ve defined a struct named Rectangle. Inside the curly brackets we defined the fields width and height, both of type u32. Then, in main, we created a particular instance of Rectangle with a width of 30 and a height of 50.

The area function now has one parameter, rectangle, whose type is an immutable borrow of a Rectangle instance. As in Chapter 4, we want to borrow the struct rather than take ownership of it: this way main retains ownership and can continue using rect1. That is why we use the & both in the function signature and where we call the function.
