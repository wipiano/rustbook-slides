Chapter 5 · 5.2 An Example Program Using Structs

Using dbg! on a field value and on the struct

#[derive(Debug)]

struct Rectangle {

    width: u32,

    height: u32,

}

 

fn main() {

    let scale = 2;

    let rect1 = Rectangle {

        width: dbg!(30 * scale),

        height: 50,

    };

 

    dbg!(&rect1);

}

Here (left) we want to see the value assigned to the width field, as well as the whole struct in rect1.

Remark. Calling dbg! prints to the standard error console stream (stderr), as opposed to println!, which prints to the standard output console stream (stdout). More on both in “Redirecting Errors to Standard Error”, Chapter 12.

  • We put dbg! around 30 * scale; because dbg! returns ownership of the value, width gets the same value as without the call.
  • We don’t want dbg! to take ownership of rect1, so the next call uses a reference, &rect1.
