Chapter 5 · 5.3 Methods

Methods versus functions

Definition 5.14 (Method). A function defined within the context of a struct (or an enum or a trait object), whose first parameter is always self, representing the instance of the struct the method is being called on.

Like functions, methods…

  • are declared with the fn keyword and a name;
  • can have parameters and a return value;
  • contain code that runs when the method is called from somewhere else.

Unlike functions, methods…

  • are defined within the context of a struct — or an enum (Chapter 6) or a trait object (Chapter 18);
  • always take self as their first parameter.
