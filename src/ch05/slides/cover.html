Chapter 5

Using Structs to Structure Related Data

A struct, or structure, is a custom data type that lets you package together and name multiple related values that make up a meaningful group. If you know an object-oriented language, a struct is like an object’s data attributes. The chapter compares and contrasts tuples with structs, to build on what you already know and show when structs are a better way to group data.

It shows how to define and instantiate structs, and how to define associated functions — especially the kind called methods — to specify behavior associated with a struct type. Structs and enums (Chapter 6) are the building blocks for creating new types in your program’s domain, to take full advantage of Rust’s compile-time type checking.
