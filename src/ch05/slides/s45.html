Implementing can_hold

Listing 5.15: Implementing the can_hold method on Rectangle that takes another Rectangle instance as a parameter — src/main.rs

impl Rectangle {

    fn area(&self) -> u32 {

        self.width * self.height

    }

 

    fn can_hold(&self, other: &Rectangle) -> bool {

        self.width > other.width && self.height > other.height

    }

}

Running this with the main function of Listing 5.14 gives the desired output.

Methods can take multiple parameters, added to the signature after the self parameter, and those parameters work just like parameters in functions.
