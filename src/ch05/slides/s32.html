More derivable traits; from function to method

Beyond Debug

  • Besides Debug, Rust provides a number of traits to use with the derive attribute that add useful behavior to custom types. They and their behaviors are listed in Appendix C.
  • Chapter 10 covers implementing these traits with custom behavior, and creating your own traits.
  • There are also many attributes other than derive: see the “Attributes” section of the Rust Reference.

Where the refactoring goes next

Our area function is very specific: it only computes the area of rectangles. It would help to tie this behavior more closely to our Rectangle struct, because it won’t work with any other type. So we continue refactoring by turning the area function into an area method defined on the Rectangle type.
