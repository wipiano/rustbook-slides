Chapter 5 · 5.2 An Example Program Using Structs

The rectangles program, with separate variables

To see when structs help, we write a program that calculates a rectangle’s area, starting with single variables and refactoring until we use structs. A new Cargo binary project, rectangles, takes the width and height in pixels and calculates the area:

Listing 5.8: Calculating the area of a rectangle specified by separate width and height variables — src/main.rs

fn main() {

    let width1 = 30;

    let height1 = 50;

 

    println!(

        "The area of the rectangle is {} square pixels.",

        area(width1, height1)

    );

}

 

fn area(width: u32, height: u32) -> u32 {

    width * height

}
