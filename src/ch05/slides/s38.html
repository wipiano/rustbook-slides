Chapter 5 · 5.3 Methods

A method with the same name as a field

A method may share a field’s name — here a width method on Rectangle (src/main.rs):

impl Rectangle {

    fn width(&self) -> bool {

        self.width > 0

    }

}

 

fn main() {

    let rect1 = Rectangle {

        width: 30,

        height: 50,

    };

 

    if rect1.width() {

        println!("The rectangle has a nonzero width; it is {}", rect1.width);

    }

}
