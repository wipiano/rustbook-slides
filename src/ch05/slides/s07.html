Creating instances from other instances

It’s often useful to create a new instance of a struct that includes most of the values from another instance of the same type, but changes some of them. You can do this using struct update syntax.

First, the regular way: user2 gets a new email but otherwise the same values as the user1 of Listing 5.2.

Listing 5.6: Creating a new User instance using all but one of the values from user1 — src/main.rs

fn main() {

    // --snip--

 

    let user2 = User {

        active: user1.active,

        username: user1.username,

        email: String::from("another@example.com"),

        sign_in_count: user1.sign_in_count,

    };

}
