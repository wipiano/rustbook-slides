A constructor: Rectangle::square

src/main.rs

impl Rectangle {

    fn square(size: u32) -> Self {

        Self {

            width: size,

            height: size,

        }

    }

}

The Self keywords in the return type and in the body of the function are aliases for the type that appears after the impl keyword — in this case, Rectangle.

To call this associated function, use the :: syntax with the struct name, for example let sq = Rectangle::square(3);. The function is namespaced by the struct: the :: syntax is used both for associated functions and for namespaces created by modules (Chapter 7).
