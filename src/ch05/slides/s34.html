Chapter 5 · 5.3 Methods

Method syntax: an impl block for Rectangle

Listing 5.13: Defining an area method on the Rectangle struct — src/main.rs

#[derive(Debug)]

struct Rectangle {

    width: u32,

    height: u32,

}

 

impl Rectangle {

    fn area(&self) -> u32 {

        self.width * self.height

    }

}

Definition 5.15 (impl block). An impl (implementation) block for a type: everything within it is associated with that type. To make area a method, we move the function inside the impl Rectangle curly brackets and change the first (here, only) parameter to self, in the signature and everywhere within the body.
