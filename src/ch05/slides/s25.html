Structs don’t implement Display

Compiling Listing 5.11 gives an error with this core message:

error[E0277]: `Rectangle` doesn't implement `std::fmt::Display`

Definition 5.11 (Display). The formatting println! uses by default for curly brackets {}: output intended for direct end user consumption.

  • The primitive types implement Display by default: there’s only one way you’d want to show a 1 or any other primitive type to a user.
  • Structs have more possibilities (commas? curly brackets? all fields?), so Rust doesn’t guess: structs have no provided Display to use with {}.

Reading on, the errors include this helpful note:

help: the trait `std::fmt::Display` is not implemented for `Rectangle`
