Chapter 5 · 5.1 Defining and Instantiating Structs

Struct update syntax moves data

..user1 must come last; before it, you can set as many fields as you want, in any order, regardless of the order of the fields in the struct’s definition.

Struct update syntax uses = like an assignment, because it moves the data, just as in “Variables and Data Interacting with Move” (Chapter 4).

Example 5.6. In Listing 5.7, which fields of user1 can still be used after creating user2?

  • user1 as a whole can no longer be used: the String in its username field was moved into user2.
  • user1.email can still be used, because its value was not moved out of user1.
  • active and sign_in_count are types that implement the Copy trait, so their values are copied (“Stack-Only Data: Copy”, Chapter 4), not moved.

Had we given user2 new String values for both email and username, and thus only used the active and sign_in_count values from user1, then user1 would still be valid after creating user2.
