Asking for Debug output with :?

Let’s try it! The call becomes println!("rect1 is {rect1:?}"); — the specifier :? inside the curly brackets tells println! to use an output format called Debug.

Definition 5.12 (Debug). A trait that lets you print a value in a way useful for developers while debugging.

Compile with this change. Drat! We still get an error:

error[E0277]: `Rectangle` doesn't implement `Debug`

But again, the compiler gives us a helpful note:

   |                        required by this formatting parameter

   |

Rust does include functionality to print debugging information, but we must explicitly opt in: add the outer attribute #[derive(Debug)] just before the struct definition (Listing 5.12).
