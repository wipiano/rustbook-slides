Keywords

Like other languages, Rust has a set of words that belong to the language itself.

Definition 3.1 (Keyword). A word reserved for use by the Rust language only. You cannot use keywords as names of variables or functions.

  • Most keywords have special meanings, and you’ll use them to do various tasks in your Rust programs (for example let, fn, if, loop).
  • A few have no current functionality but have been reserved for functionality that might be added to Rust in the future.
  • The full list of keywords is in Appendix A.
