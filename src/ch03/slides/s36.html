Chapter 3 · 3.3 Functions

Calling functions

We call any function we’ve defined by entering its name followed by a set of parentheses. Because another_function is defined in the program, it can be called from inside main. Note that it is defined after main; it could have been defined before as well. Rust doesn’t care where you define your functions, only that they’re defined somewhere in a scope that can be seen by the caller.

Start a new binary project named functions, place the example in src/main.rs, and run it:

$ cargo run

   Compiling functions v0.1.0 (file:///projects/functions)

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.28s

     Running `target/debug/functions`

Hello, world!

Another function.

The lines execute in the order in which they appear in main: first the “Hello, world!” message prints, and then another_function is called and its message is printed.
