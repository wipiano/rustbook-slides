Chapter 3 · 3.3 Functions

Blocks are expressions

src/main.rs

fn main() {

    let y = {

        let x = 3;

        x + 1

    };

 

    println!("The value of y is: {y}");

}

This expression:

{

    let x = 3;

    x + 1

}

is a block that, in this case, evaluates to 4. That value gets bound to y as part of the let statement.

Note the x + 1 line without a semicolon at the end, unlike most lines you’ve seen so far. Expressions do not include ending semicolons. If you add a semicolon to the end of an expression, you turn it into a statement, and it will then not return a value. Keep this in mind as you explore function return values and expressions next.
