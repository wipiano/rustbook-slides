Chapter 3 · 3.2 Data Types

Numeric operations

Rust supports the basic mathematical operations you’d expect for all the number types: addition, subtraction, multiplication, division, and remainder.

Integer division truncates toward zero to the nearest integer (-5 / 3 gives -1).

Each expression in these let statements uses a mathematical operator and evaluates to a single value, which is then bound to a variable.

Appendix B lists all the operators Rust provides.

fn main() {

    // addition

    let sum = 5 + 10;

 

    // subtraction

    let difference = 95.5 - 4.3;

 

    // multiplication

    let product = 4 * 30;

 

    // division

    let quotient = 56.7 / 32.2;

    let truncated = -5 / 3; // Results in -1

 

    // remainder

    let remainder = 43 % 5;

}
