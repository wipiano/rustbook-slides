Chapter 3 · 3.1 Variables and Mutability

Shadowing versus mut

When we run the shadowing program, it outputs the following:

$ cargo run

   Compiling variables v0.1.0 (file:///projects/variables)

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s

     Running `target/debug/variables`

The value of x in the inner scope is: 12

The value of x is: 6

Shadowing is different from marking a variable as mut: we’ll get a compile-time error if we accidentally try to reassign to this variable without using the let keyword. By using let, we can perform a few transformations on a value but have the variable be immutable after those transformations have completed.
