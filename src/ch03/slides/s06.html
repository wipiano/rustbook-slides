Chapter 3 · 3.1 Variables and Mutability

Running the mutable version

When we run the program now, we get this:

$ cargo run

   Compiling variables v0.1.0 (file:///projects/variables)

    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.30s

     Running `target/debug/variables`

The value of x is: 5

The value of x is: 6

We’re allowed to change the value bound to x from 5 to 6 when mut is used.

Remark. Ultimately, deciding whether to use mutability or not is up to you and depends on what you think is clearest in that particular situation.
