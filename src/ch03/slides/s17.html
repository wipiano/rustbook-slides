Chapter 3 · 3.2 Data Types

Signed and unsigned ranges

Each variant can be either signed or unsigned and has an explicit size.

Definition 3.10 (Signed and unsigned). Whether it’s possible for the number to be negative: whether the number needs a sign with it (signed), or will only ever be positive and can therefore be represented without a sign (unsigned).

It’s like writing numbers on paper: when the sign matters, a number is shown with a plus or minus sign; when it’s safe to assume the number is positive, it’s shown with no sign. Signed numbers are stored using two’s complement representation.

  • Each signed variant stores numbers from −(2ⁿ⁻¹) to 2ⁿ⁻¹ − 1 inclusive, where n is the number of bits the variant uses. So an i8 stores −(2⁷) to 2⁷ − 1, which equals −128 to 127.
  • Unsigned variants store numbers from 0 to 2ⁿ − 1, so a u8 stores 0 to 2⁸ − 1, which equals 0 to 255.
  • isize and usize depend on the architecture of the computer your program runs on: 64 bits on a 64-bit architecture and 32 bits on a 32-bit architecture.
