A for countdown over a range

Here’s what the countdown would look like using a for loop and another method not yet discussed, rev, to reverse the range:

src/main.rs

fn main() {

    for number in (1..4).rev() {

        println!("{number}!");

    }

    println!("LIFTOFF!!!");

}

This code is a bit nicer, isn’t it?

Example 3.31. 1..4 is the range 1, 2, 3 (it ends before 4); .rev() walks it as 3, 2, 1, so the program prints 3!, 2!, 1! and then LIFTOFF!!! — the same countdown as Listing 3.3.
