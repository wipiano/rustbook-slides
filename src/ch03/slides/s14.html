Chapter 3 · 3.2 Data Types

Every value has a data type

Definition 3.6 (Data type). What every value in Rust has: it tells Rust what kind of data is being specified, so that it knows how to work with that data. This section looks at two subsets: scalar and compound types.

Definition 3.7 (Statically typed). A language that must know the types of all variables at compile time. Rust is statically typed.

The compiler can usually infer the type we want from the value and how we use it. When many types are possible — such as converting a String to a numeric type with parse in Chapter 2’s “Comparing the Guess to the Secret Number” — we must add a type annotation, like this:

let guess: u32 = "42".parse().expect("Not a number!");

You’ll see different type annotations for other data types.
