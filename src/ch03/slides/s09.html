Chapter 3 · 3.1 Variables and Mutability

Shadowing

As you saw in the guessing game tutorial in Chapter 2, you can declare a new variable with the same name as a previous variable.

Definition 3.5 (Shadowing). Declaring a new variable with the same name as a previous one. Rustaceans say the first variable is shadowed by the second: the second variable is what the compiler sees when you use the name.

In effect, the second variable overshadows the first, taking any uses of the variable name to itself until either it itself is shadowed or the scope ends.

We shadow a variable by using the same variable’s name and repeating the let keyword, as the program on the next slide does.
