Chapter 3 · 3.3 Functions

Statements and expressions

Function bodies are made up of a series of statements optionally ending in an expression. So far, the functions covered haven’t included an ending expression, but you have seen an expression as part of a statement. Because Rust is an expression-based language, this is an important distinction to understand. Other languages don’t have the same distinctions, so let’s look at what statements and expressions are and how their differences affect the bodies of functions.

Definition 3.23 (Statement). An instruction that performs some action and does not return a value.

Definition 3.24 (Expression). Code that evaluates to a resultant value.

We’ve actually already used statements and expressions. Creating a variable and assigning a value to it with the let keyword is a statement: in Listing 3.1, let y = 6; is a statement.
