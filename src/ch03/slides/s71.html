Disambiguating with loop labels

If you have loops within loops, break and continue apply to the innermost loop at that point.

Definition 3.28 (Loop label). An optional name on a loop, which you can then use with break or continue to specify that those keywords apply to the labeled loop instead of the innermost loop. Loop labels must begin with a single quote.

The example on the next slide has two nested loops:

  • The outer loop has the label 'counting_up, and it counts up from 0 to 2.
  • The inner loop, without a label, counts down from 10 to 9.
  • The first break, which doesn’t specify a label, exits the inner loop only.
  • The break 'counting_up; statement exits the outer loop.
