Repetition with loops

It’s often useful to execute a block of code more than once. To experiment with loops, make a new project called loops.

Definition 3.27 (Loop). A construct that runs through the code inside the loop body to the end and then starts immediately back at the beginning. Rust has three kinds of loops: loop, while, and for.

Repeating code with loop

The loop keyword tells Rust to execute a block of code over and over again, either forever or until you explicitly tell it to stop. As an example, change src/main.rs in your loops directory to look like this:

fn main() {

    loop {

        println!("again!");

    }

}
