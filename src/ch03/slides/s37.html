Chapter 3 · 3.3 Functions

Parameters

Definition 3.21 (Parameter). A special variable that is part of a function’s signature. When a function has parameters, you can provide it with concrete values for them.

Definition 3.22 (Argument). Technically, a concrete value passed in for a parameter when you call a function. In casual conversation, people use parameter and argument interchangeably, for either the variables in a function’s definition or the concrete values passed in.

In this version of another_function we add a parameter:

fn main() {

    another_function(5);

}

 

fn another_function(x: i32) {

    println!("The value of x is: {x}");

}
