Why for is the most common loop

  • Running Listing 3.5 gives the same output as Listing 3.4.
  • More importantly, it increases the safety of the code and eliminates the chance of bugs from going beyond the end of the array or not going far enough and missing some items.
  • Machine code generated from for loops can be more efficient as well, because the index doesn’t need to be compared to the length of the array at every iteration.
  • If you changed the number of values in the array, you wouldn’t need to remember to change any other code, as you would with Listing 3.4.

The safety and conciseness of for loops make them the most commonly used loop construct in Rust. Even when you want to run some code a certain number of times, as in the countdown of Listing 3.3, most Rustaceans would use a for loop, with a Range.

Definition 3.30 (Range). A type provided by the standard library that generates all numbers in sequence, starting from one number and ending before another number.
