Chapter 3 · 3.2 Data Types

Scalar types: integers

Definition 3.8 (Scalar type). A type that represents a single value. Rust has four primary scalar types: integers, floating-point numbers, Booleans, and characters.

Definition 3.9 (Integer). A number without a fractional component.

Chapter 2 used the integer type u32: an unsigned integer (signed integer types start with i instead of u) that takes up 32 bits of space. Table 3.1 shows Rust’s built-in integer types; any of these variants can declare the type of an integer value.
