Chapter 3 · 3.2 Data Types

Integer literals and defaults

You can write integer literals in any of the forms in Table 3.2. Number literals that can be multiple numeric types allow a type suffix, such as 57u8, to designate the type. Number literals can also use _ as a visual separator to make the number easier to read: 1_000 has the same value as 1000.

Which integer type should you use? If you’re unsure, Rust’s defaults are generally good places to start: integer types default to i32. The primary situation in which you’d use isize or usize is when indexing some sort of collection.

Table 3.2: Integer literals in Rust

Number literalsExample
Decimal98_222
Hex0xff
Octal0o77
Binary0b1111_0000
Byte (u8 only)b'A'
