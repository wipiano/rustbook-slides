Chapter 3 · 3.2 Data Types

The Boolean type

Definition 3.15 (Boolean). A type with two possible values, true and false, as in most other programming languages. In Rust it is specified with bool, and Booleans are one byte in size.

For example:

src/main.rs

fn main() {

    let t = true;

 

    let f: bool = false; // with explicit type annotation

}

The main way to use Boolean values is through conditionals, such as an if expression. How if expressions work in Rust is covered in section 3.5, “Control Flow”.
