Chapter 3 · 3.5 Control Flow

Returning a value with break

fn main() {

    let mut counter = 0;

 

    let result = loop {

        counter += 1;

 

        if counter == 10 {

            break counter * 2;

        }

    };

 

    println!("The result is {result}");

}

Before the loop, we declare counter and initialize it to 0. Then we declare result to hold the value returned from the loop. On every iteration, we add 1 to counter and check whether it equals 10. When it does, we use break with the value counter * 2. After the loop, a semicolon ends the statement that assigns the value to result. Finally, we print result, which in this case is 20.

Remark. You can also return from inside a loop. While break only exits the current loop, return always exits the current function.
