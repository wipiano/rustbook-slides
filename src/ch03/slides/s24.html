Chapter 3 · 3.2 Data Types

The character type

Rust’s char type is the language’s most primitive alphabetic type. Some examples of declaring char values:

fn main() {

    let c = 'z';

    let z: char = 'ℤ'; // with explicit type annotation

    let heart_eyed_cat = '😻';

}

  • char literals use single quotation marks, as opposed to string literals, which use double quotation marks.
  • char is 4 bytes in size and represents a Unicode scalar value, so it can represent much more than ASCII: accented letters; Chinese, Japanese, and Korean characters; emojis; and zero-width spaces are all valid char values.
  • Unicode scalar values range from U+0000 to U+D7FF and U+E000 to U+10FFFF inclusive.
  • A “character” isn’t really a concept in Unicode, so your intuition for what a “character” is may not match what a char is in Rust. Chapter 8, “Storing UTF-8 Encoded Text with Strings”, discusses this in detail.
