Chapter 3 · 3.3 Functions

Defining functions

Functions are prevalent in Rust code. You’ve already seen one of the most important: main, the entry point of many programs. You’ve also seen the fn keyword, which declares new functions.

Definition 3.20 (Snake case). The conventional style for Rust function and variable names: all letters lowercase, with underscores separating words.

We define a function by entering fn followed by a function name and a set of parentheses. The curly brackets tell the compiler where the function body begins and ends.

A program with an example function definition — src/main.rs

fn main() {

    println!("Hello, world!");

 

    another_function();

}

 

fn another_function() {

    println!("Another function.");

}
